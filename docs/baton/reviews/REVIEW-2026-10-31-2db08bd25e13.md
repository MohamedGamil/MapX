## Findings

### P1, fixed in this review

#### P1: Console Kernel gets verified middleware edges (M0-05-R3, `src/frameworks/detectors/laravel.ts:791`)

- **Scenario:** a Laravel app with an HTTP Kernel (`auth`, `web`) and a Console Kernel. `app/Console/Kernel.php` got 4 `middleware` edges marked `verified`.
- **Reproduced:** yes, by this reviewer with a real scan.
- **Resolution:** hooks are emitted only for `app/Http/Kernel.php`. Regression test in `tests/legacy-hook-verifiability.test.ts`; 2 tests fail on the old code.

#### P1: webpack magic comment hides lazy route components (M3-06, `vue-navigation.ts` `componentSpecifier`, `vue-router.ts`)

- **Scenario:** `component: () => import(/* webpackChunkName: "about" */ '../views/AboutView.vue')` (the default `vue create` router) gives no route edge and no navigate edges.
- **Reproduced:** yes.
- **Resolution:** block comments are accepted before the specifier. Two tests (route table and detector) fail on the old code. A real scan now gives the route edge and both navigate edges.

#### P1: git sync indexes files scan never indexes (M0-02-R2, `src/core/scanner.ts` `_scanIncrementalForRepo`)

- **Scenario:** edit `.eslintrc.js`, `.storybook/main.ts`, `coverage/prettify.js` and a file under an `**/Controllers`-pruned folder, then `sync`. All four are indexed.
- **Reproduced:** yes.
- **Resolution:** `isScannablePath` (now aware of the repo folder) for every change and restore path; staleness passes the repo folder too.
  - Regression test in `tests/legacy-globs.test.ts`; sync equals `scan --force`.
  - Mutation (matcher only): the test fails.

#### P1: two Laravel apps resolve to the first app (M0-04-R2, M0-04-R5, `scanner.ts` namespaced branch and `resolvePhpFunction`)

- **Scenario:** `admin/` and `backend/` declare the same classes and functions. Backend's `new User()`, `format_money()` and route handler link to `admin/` files.
- **Reproduced:** yes.
- **Resolution:** the declaration nearest the caller wins (`closest`, as `resolvePhpImport` does).
  - Regression test in `tests/legacy-php-resolution.test.ts`.
  - Each spot was mutation-checked separately.

#### P1 (part): raw PHP in `Route::any` URIs (M1-03-R1, `laravel.ts` `verb !== 'ANY'` guard)

- **Scenario:** `Route::any("a/$unknownVar", …)` gives `/api/a/$unknownVar`.
- **Reproduced:** yes.
- **Resolution:** the guard is removed (`fallback()` sets no `uriExpr`). Two cases were added to the M1-03-R1 dynamic test, which fails on the old code. The routes scorer is unchanged.
