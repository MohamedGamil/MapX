# M2-06-R1 — HTTP pairing needs literal evidence; host affinity; honest pairing tests

## Identification

Milestone: M2; priority: P1; risk: medium; area: http. Role: static analysis, test design.

## Objective

A call pairs only with a route its literal path supports, on the right host.

## Dependencies

M2-06 (hard), M2-07 (hard). Both DONE.

## Scope

Review 2026-10-31 findings:

- **P1: no literal evidence.** A URL with no literal path segment (`${endpoint}?page=…`, `${base}/${id}`, `DELETE '/'` behind an unknown base) scores 0 and matches any route of its method. Pairing now requires at least one literal-to-literal segment match. The one exception is an exact match of the root path `/` with a known base.
- **P2: host ignored.** An absolute URL pairs only when its host is a local development host or one of the workspace's own hosts. Own hosts are hosts named in any `.env*` file of a registered repo, in `settings.http.clients[].baseURL`, or in the new `settings.http.hosts`.
- **P2: `{dynamic}` routes act as wildcards.** A `{dynamic}` segment (Laravel M1-03-R1) matches a segment but contributes no evidence, scoring below a real parameter. Such a route still needs a literal match.
- **P2: wrong `fetch` method.** `method` is read from the top level of the init object only. A method held in a variable, a shorthand `method`, a spread or a non-object init gives method `UNKNOWN`, which never pairs.
- **P2: `HTTP_SKIP` too broad.** It skipped any `public/`, `build/`, `dist/` or `vendor/` directory. Such directories are now skipped only outside `src/` and `resources/`; `node_modules`, `*.min.js` and `*.bundle.js` are always skipped.
- **P2: JSX closing tags mask calls.** `</a>` and `/>` are no longer read as regex literals.
- **Tests:**
  - the scan-order test re-scanned the frontend, so a pair-once mutant survived;
  - the scorer never compared the handler;
  - M2-07 AC4 lost its "< 1 s" bound, now restored as CPU time, which is robust to parallel load;
  - M2-03 AC2 and M2-05 AC2 were proven only manually; both get real-scan tests.
