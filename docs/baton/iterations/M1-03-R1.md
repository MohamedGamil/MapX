# M1-03-R1 — Laravel route-file walker: string/comment-aware lexing and brace-less groups

## Identification

Milestone: M1; priority: P1; risk: medium; estimate min/expected/max: 6/10/14 h; area: laravel, remediation.
Sources: `docs/baton/reviews/REVIEW-2026-10-31-fb75474ba377.md`, `docs/baton/reports/M1-03.md` (and the M1-06 COMPLETION DISPUTED section in `docs/baton/reports/M1-06.md`).

## Objective

Route files are read with a lexer that skips strings, comments and heredocs, and every group form is scoped correctly.

## Dependencies

M1-03 (hard), M1-06 (hard). No approval gate.

## Scope

- A PHP masking lexer in `laravel-mounts.ts` (`maskPhp`): same-length copies of a file with comments blanked, and with comments plus string/heredoc contents blanked. Offsets and line numbers stay aligned with the source.
- `walkRouteFile` scans the fully masked copy for structure (`{`/`}`, `Route::`, `require`/`include`, `;`) and slices argument text from the comment-free copy, so strings are never read as code and comments (`//`, `#`, `/* */`) never yield routes or mounts.
- Group frames end at the group call's closing parenthesis instead of at a brace depth, so `fn () =>` bodies, `->group(fn () => Route::get(…))` and the legacy `Route::group(attrs, <path>)` mount are all scoped. The legacy form becomes a mount carrying the group attributes.
- Interpolated double-quoted strings (`"$v/x"`, `"{$v}/x"`, `"${v}/x"`) are evaluated from local string variables, and variable prefixes (`->prefix($v)`, `'prefix' => $v`) likewise; anything unresolvable becomes `{dynamic}` with `metadata.dynamic = true`, never raw PHP text.
- RouteServiceProvider (and other service providers): comments are blanked and the bodies of methods not reachable from `boot`/`map`/`register` through `$this->`/`self::`/`static::` calls are ignored, so a commented-out `$this->mapLegacyRoutes()` or `Route::prefix(...)->group(...)` mounts nothing.

## Out of scope

- `module_path()`, `withRouting(then:)`, glob-loop and `DIRECTORY_SEPARATOR` mounts; registry dedup of overriding routes; attribute-route lines (M1-07-R1).
- Resource forms, array-handler attributes and group name prefixes (M1-05-R1).
