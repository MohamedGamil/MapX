# M7-07 — Landing media: dashboard screenshots generated from a fixture

## Identification

Milestone: M7; priority: P3; risk: low; estimate min/expected/max: 4/6/9 h; role: front-end and tooling.

## Objective

The landing page shows real screenshots of the dashboard, generated by a script from synthetic fixtures (never private code), so they can be regenerated after a UI change instead of being captured by hand.

## Dependencies

M7-03 (hard, DONE); the M4 dashboard harness and the M5-01 fixture it reuses.

## Decisions

- **Three views:** the Graph Explorer and the Architecture "Layer rules" view of the M5-01 TypeScript fixture (layers, violations and a baseline), and the HTTP Calls view of the multi-repo workspace (a Vue frontend paired with a Laravel backend). They show the three things the landing text claims: a code graph, architecture rules, and frontend-to-backend pairing.
- **Reused pieces:** `scripts/ui/workspace.ts` (`initAndScan`, `multiRepoWorkspace`, `serve`) and the dashboard's own readiness signal (`body[data-graph="ready"]`).
- **WebP by the browser.** Chromium takes the PNG screenshot and its canvas encodes WebP, so no image dependency is added. Quality 0.82; the size cap is 150 KiB each.
- **Stable pictures.** A fixed project folder name (the dashboard shows it), dark theme, reduced motion, animations disabled, a fixed viewport of 1280 x 800. The determinism criterion is measured, not assumed: the generator runs twice and the images are compared in the browser.
- **Metadata in one place.** `scripts/site/screenshot-list.ts` (file, alt text, caption, size) is imported by the generator and by `site-facts.ts`, so the landing, the tests and the generator cannot disagree.
- **Not on the first screen:** the images are below the hero and load lazily, so the home transfer budget does not count them (the `<img loading="lazy">` is outside the first viewport); the budget is raised only if the measured transfer rises.

## Scope

- `scripts/site/gen-screenshots.ts`, `scripts/site/screenshot-list.ts`, `npm run site:shots`.
- `site/public/img/*.webp` (committed output).
- A "See it" section in `Landing.vue`, fed from `facts.json`.
- Tests: `tests/site/screenshots.spec.ts` (twice-run pixel difference), additions to `tests/site-landing.test.ts`.

## Out of scope

- Light-theme or phone screenshots; video or animation.
- Milestone acceptance: **M7-98**.
