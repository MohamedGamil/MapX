# M5-24-R1: Ambient access is extracted: environment, globals and superglobals

## Identification

Milestone: M5; priority: P2; risk: medium; estimate min/expected/max: 4/8/12 h; role: parser and architecture rules.

## Objective

A scan records ambient-access references as `external_refs` rows with origin `ambient`, so the `ambient` selector of M5-24 matches them in every language, not only Go's cgo `C` and PHP's PECL names.

## Dependencies

M5-24 (hard, DONE). Sources: reports M5-24, M5-24-R4, M5-19, M5-21-R1 (PECL names as ambient), M5-23 (cgo `C` as ambient); research AR-04.

## Scope

**Granularity: one ambient element per concept name.** The element is the row's `package`:
- `env`: JS/TS `process.env`; PHP `$_ENV` and `getenv()`; Python `os.environ` and `os.getenv`; Go `os.Getenv`, `os.LookupEnv`, `os.Environ`. One name across languages, so `{ "ambient": "env" }` means "the environment" ("only Config may read env").
- `argv`: Python `sys.argv`; Go `os.Args`.
- Browser globals keep their name: `window`, `document`, `globalThis`, `localStorage`.
- PHP superglobals keep their name with the sigil: `$_GET`, `$_POST`, `$_SERVER`, `$_SESSION`, `$_COOKIE`, `$_FILES`, `$_REQUEST`, `$GLOBALS`; `{ "ambient": "$_*" }` matches the `$_` ones.

Selectors name the element (`{ ambient: "env" }`), never the source expression. `true` matches every ambient element. Ambient names compare case-insensitively, as M5-24 has it. Ambient access is never a package and never uncovered by default: it stays under `policy.uncovered.builtins`.

**Row shape:** `specifier` is the canonical access (`process.env`, `os.environ`, `$_GET`, `getenv`), whatever the import alias; `symbol` null; `kind` `call` (it keeps the default `scope.types`); `package` the element; `origin` `ambient`; `direct`, `dev`, `attribution` null. The candidate's metadata carries `{ ambient: <element> }`, so the end-of-run decision needs no attributor.

**Precision rules:**
- a name bound in the file shadows the global: a parameter, local, loop or catch variable, import, function, class (JS/TS); a Go local;
- JS `process` imported from `node:process` or `process` is the same ambient;
- Python `os` and `sys` must be bound by an import of that module (`import os as o`, `from os import environ` too);
- Go `os` must be the import of `"os"`;
- a PHP superglobal in a comment, a single-quoted string or a nowdoc is not an access (interpolated in a double-quoted string, a heredoc or backticks it is: review).

## Out of scope

- Vue and Svelte single-file components (their script blocks are parsed by other parsers).
- `process.argv`, `sessionStorage`, `$argv`, `System.getenv` and other languages (the element names are free to grow).
- A new edge type for ambient access.
