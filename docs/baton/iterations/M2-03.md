# M2-03 — HTTP client call-site extraction

## Identification

Milestone: M2; priority: P1; risk: medium; estimate min/expected/max: 10/14/16 h; area: parsers, http.
Sources: report §3 item 12 and §4 item 12; D008.

## Objective

Write a D008 record (`file`, `line`, `method`, `rawUrl`, `client`) for every HTTP call site in JS/TS/Vue files that goes through axios, `fetch`, an `axios.create` instance, a factory returning one (`Api()`), an alias of a factory call, or a receiver configured in `settings.http.clients`.

## Dependencies

M2-02 (fixture).

## Scope

- `src/frameworks/http/client-calls.ts` (pure, no I/O):
  - `collectProviders(files)`: exported instances (`export const http = axios.create(...)`), default-exported factories (`export default () => axios.create(...)`) and default-exported instances, each with its raw `baseURL` expression;
  - `extractHttpCalls(file, content, ctx)`: imports → local receivers (axios default import, local `axios.create` instances, imported instances, factory calls `F().get` and aliases `const api = F()`, configured receivers), then call sites `recv.(get|post|put|patch|delete|head|options)(` and `fetch(`/`window.fetch(` with `{ method }`; the first argument kept raw, even across lines.
- `src/frameworks/http/http-registry.ts`: load, save and per-file replace of `.mapx/http-calls.json`.
- `scanner.ts` `runPostScanAnalysis`: after routes, run extraction over the repo's JS-family files and replace that repo's records.
- `settings.http.clients: { receiver: string; baseURL?: string }[]` in the config types.

## Out of scope

- Evaluating URLs: constants and templates (M2-04), base URLs (M2-05). `url` stays unset.
- Pairing with routes, and `http` edges (M2-06).
- Calls through Vuex action names.

## Implementation plan

New `src/frameworks/http/{client-calls,http-registry}.ts`, a hook in `scanner.ts` (one appended post-scan step), and the config type in `src/types.ts`. Blast radius: `runPostScanAnalysis` is called by the full, incremental and hash-sync scans; the step only adds a file.

## Acceptance criteria

1. On the M2-02 fixture, call-site recall is 100% (32/32, right method), measured by `score-http.ts`. The fixture test floor `callSiteRecall` is raised to 1.
2. Removing `apiService` from `settings.http.clients` drops exactly the two configured-receiver labels (L28, L29); unit test in `tests/http-client-calls.test.ts`.
3. Plain member calls that are not HTTP clients (`map.get('x')`, `store.get('k')`) produce no record; unit test.
4. A second scan of an unchanged workspace yields the same records, with no duplicates (registry replace is per repo).

## Verification

- `npx vitest run tests/http-client-calls.test.ts`
- `npm run check`

## Recovery

Revert the new files and the scanner hook; delete `.mapx/http-calls.json`.
