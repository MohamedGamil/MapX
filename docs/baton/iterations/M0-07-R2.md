# M0-07-R2 — Binary build test writes outside the repo; package check rejects binaries

## Identification

Milestone: M0; priority: P2; risk: medium; estimate min/expected/max: 1/2/3 h; area: distribution.
Sources: `docs/baton/reviews/REVIEW-2026-10-31-fb75474ba377.md`, `specs/features/F13-npm-distribution.md`.

## Objective

`npm test` never writes build output into the repository.

## Dependencies

M0-07-R1 (hard). Releases stay owner-initiated (D007): nothing is published, packed to a registry or version-bumped.

## Scope

- `scripts/build-all.ts`:
  - `--outdir <dir>` (default `dist`) so a build can target a temporary directory;
  - `--dry-run`, which prints the `bun build` commands without running them, so the VERSION define and output paths are testable without bun.
- `tests/legacy-distribution.test.ts`:
  - the bun test runs `npm run build:linux -- --outdir <tmp>` and asserts the repo's `dist/mapx-linux-x64` is not created or modified;
  - a bun-independent test checks the dry-run command.
- `scripts/check-package.ts` fails when a packed file is a native executable, detected by magic bytes (ELF, Mach-O, PE). A test runs it on a temporary package containing a fake ELF file.

## Out of scope

- `package.json` `files` changes (not in this task's files; the check is the guard).
- Building or testing non-linux binaries.

## Implementation plan

See Scope. The tests use temp directories only.

## Expected outputs

Script changes, tests, `docs/baton/reports/M0-07-R2.md`.

## Acceptance criteria

1. The binary test builds into a temporary directory; check-package fails if a native binary is in the pack list.

## Verification

- `npx vitest run tests/legacy-distribution.test.ts`
- `npm run build:npm`
- `npx tsx scripts/check-package.ts`

Also `npx vitest run` and `npx tsc --noEmit`; mutation-check each new test.
