# M5-17-R1 — Presets use hierarchy selectors; remaining AR-15 presets

## Identification

Milestone: M5; priority: P3; risk: low; estimate min/expected/max: 4/8/12 h; role: architecture-rules engineer.

## Objective

Where a framework defines a layer by ancestry, its preset selects by it (M5-09's `extends`, `implements`, `inherits`), with the path selectors kept as the fallback where ancestry is absent. The AR-15 presets M5-17 left out are shipped, each proven on a synthetic fixture that fills every layer and plants exactly one violation.

## Dependencies

- M5-17 (hard, DONE): `mapx arch init`, the preset registry, `scripts/gen-arch-presets.ts`, the case test.
- M5-09 (hard, DONE): the hierarchy selectors.
- M5-24-R4 (DONE): packages are opt-in for uncovered; day one (`--baseline --write`, then `check --fail-on-uncovered`) must stay green for every preset.

## Scope

1. **Ancestry in the framework presets.**
   - `laravel`: Models also by `extends` of Eloquent's `Model` (and `Authenticatable`, `Pivot`); Jobs also by `implements ShouldQueue` outside the folders whose classes queue for other reasons (listeners, mail, notifications); Http also by the controller bases (`App\Http\Controllers\Controller`, `Illuminate\Routing\Controller`).
   - `nestjs`: the decorators M5-10 stores (`@Injectable`, `@Entity`) and the Nest enhancer interfaces (`implements CanActivate` and the like).
   - `django`: Models by `extends django.db.models.Model`; Views by the Django and REST framework view bases.
2. **The remaining AR-15 presets**: `onion`, `mvc`, `mvvm` (generic), and `symfony`, `express`, `fastapi`, `rails`, `spring`, `aspnet`, `flutter`, `nextjs`, `vue` (framework), each a `src/arch/presets/<id>.jsonc` with a comment on every layer, embedded by `scripts/gen-arch-presets.ts`.
3. **`--from framework`** maps the detectors MapX has for the new framework presets (`FRAMEWORK_PRESETS` in `src/arch/infer.ts`).
4. **Fixtures**: one synthetic app per new preset under `tests/fixtures/arch-init/`, and ancestry-only files added to the laravel11, nestjs and django fixtures (each in a folder no path selector covers).
5. **Docs**: the preset table and limits in `docs/architecture-rules.md`, the README count.

## Out of scope

- Per-slice FSD rules and ddd "only through Contracts" (unchanged limitation of M5-17).
- New detectors or parser changes (other lanes own `src/parsers/**`, `src/core/scanner.ts`).
