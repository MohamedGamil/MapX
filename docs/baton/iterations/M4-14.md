# M4-14 — Batched worker messages

## Identification
Milestone M4; P1; risk medium; estimate 4/8/14 h. Decision D025.

## Objective
Jobs go to workers in batches bounded by file count and source bytes, and results come back per batch:
- **Progress:** still per file. A worker reports parsed counts within a batch.
- **Hand-back:** still per file. A failing file is returned for the main thread, and the other results of its batch are kept.
