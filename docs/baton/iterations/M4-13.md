# M4-13 — Parse pool sizing from the work and the machine

## Identification
Milestone M4; P1; risk low; estimate 4/8/14 h. Decision D025.

## Objective
`poolSize({ files, cpus, freeMemory, perWorkerBytes, setting })` decides the number of workers. Its inputs are measured break-even and memory figures, not constants picked by hand.

## Scope
- **The function and its use:** a pure function plus the scanner's use of it.
- **Setting:** `settings.parseWorkers`, which is `"auto"` (the default), `0` for one thread, or a number as a cap.
- **Docs:** configuration.

- Distribution (M4-12).
- Batching (M4-14).
