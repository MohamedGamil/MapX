# M2-08-R1 — Import-bound calls: export-from barrels in sync, and no fallback past a project import

## Identification

Milestone: M2; priority: P2; risk: medium; estimate min/expected/max: 2/4/6 h; role: resolution and incremental scanning.

## Objective

Sync re-links the importers of `export … from` / `export *` barrels as `scan --force` does. A JS/TS call whose name is imported from a project module that neither declares nor re-exports it links nothing, never another file's same-named symbol. The 2026-11-02 review found both in M2-08.

## Dependencies

M2-08 (hard, DONE).

## Scope

- **`queries/{typescript,javascript}/references*.scm`:** `export_statement` with a `source` gives an `import` reference, so a barrel has import edges to the modules it re-exports. `Store.getImporters`, and through it `importerReferrers`, then reach a barrel's importers when a module behind it changes. The dependency and impact views see the barrel's dependency too.
- **`Scanner.findExport` (JS/TS):** returns "absent" when:
  - the name does not occur as a whole word in the module (comments stripped);
  - the module has no CommonJS or `export =` exports;
  - every `export *` target resolves within the project and is itself absent.

  `resolveImportedCall` maps absent to no edge. Anything uncertain (unresolved targets, depth, cycles, a name that occurs but isn't found) keeps the name-lookup fallback.

## Out of scope

- **Python:** `from m import x` where `m` lacks `x` (`__getattr__`, star imports); unchanged.

## Acceptance criteria

1. **Barrel sync:** a module behind an `export { run } from` barrel, and one behind an `export *` barrel, gains the imported name; sync then links the importer's call to it, and the call edges equal `scan --force` (`tests/import-bound-calls.test.ts`).
2. **Absent name:** a name imported from a project module that does not declare it gives no call edge (the test replaces the fallback assertion); before the module gains the name, the barrel importers have no edge either.
3. **No regression:** the edges, routes and HTTP scorers hold their floors (`npm run eval`).
