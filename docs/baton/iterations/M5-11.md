# M5-11 — Visibility rules: private selectors and internal markers

## Identification

Milestone M5; P2; risk medium; estimate 6/8/10 h; role: arch and parsers. Sources: `docs/research/deptrac/02-abstract-feature-model.md` AR-07 (visibility), AR-08 (evaluation order), AR-11 (`visibility` in the configuration); `01-deptrac-capabilities.md` §3. Decision D033: M5-04 already evaluates `private-layer`; this task adds internal markers and native markers, and its fixture criterion covers both rules.

## Objective

A symbol marked internal is reachable only from its own layer (rule `internal-element`, AR-07 §2). Markers are doc tags from `visibility.internalTags` (default `@internal`, `@mapx-internal`) and, opt-in through `visibility.nativeMarkers`, each language's own module-scoped visibility.

## Dependencies

- M5-04 (rule evaluator, `private-layer`): DONE, hard.
- M5-10 (doc tags in symbol metadata; `hasDocTag`, `docTagsOf`): DONE, hard.
- M5-06 (baselines): DONE. A baseline entry can skip an `internal-element` violation like any other.

## Scope

1. **Evaluation (AR-08 step 5).** After `disallowed-layer` and before `private-layer`: when the target is internal and the source layer is not one of the target's non-overlay layers, the dependency is a violation, rule `internal-element`, naming the target's layers. Same severity rules as the other violations (inferred → `warn` by default).
2. **What is internal:**
   - a symbol with a doc tag in `visibility.internalTags` (compared like the `docTag` selector: case-insensitive, `@` optional);
   - a member of an internal type (a method of an `@internal` class: the class is how it is reached);
   - a file whose top-level symbols are all internal (an import of the file names the internal class), or a file a native marker makes internal as a whole;
   - a Go package (import target) whose in-scope files are all internal;
   - with `nativeMarkers: true`, the native markers below.
3. **Native markers, decided per language** (off by default). Revised by the review: a native marker counts only for a reference the language itself refuses; where MapX cannot see the boundary, nothing is reported.

   | Language | Native marker | Refused when the referrer… |
   | --- | --- | --- |
   | Go | a file under `internal/` | is not rooted at the deepest `internal`'s parent (import paths) |
   | Python | a `_module` or `_package` (not dunder) | is outside the holding package and imports the private module itself (a re-export is public) |
   | Python | a `_name` symbol (not dunder) | is in another module (`from m import _x` names it) |
   | Dart | a `_name` symbol; `lib/src/` | is in another file that is not a `part of`; in another package (pubspec.yaml) |
   | Kotlin | `internal` | is in another module (build.gradle(.kts), pom.xml) |
   | C# | `internal`, `private protected`, a top-level type without access modifier (partial parts merged) | is in another .csproj project not named by InternalsVisibleTo |
   | Java | package-private | is in another package |
   | Rust | `pub(crate)`, `pub(self)`, `pub(super)`, `pub(in path)` | is outside the crate (Cargo.toml), module, parent module or path |
   | TS, TSX, JS | the `@internal` tag | is in another workspace package (package.json name) |
   | PHP and the rest | none | |

4. **Parsers.**
   - Go doc comments (`//` lines directly above a declaration, each starting its own line) give doc tags: `@tag` lines and Go's `Deprecated:` paragraph as `@deprecated`. The fixture's Go `@internal` rows need them.
   - Kotlin, C#, Java and Rust store the declared restricted visibility as `metadata.visibility` (`internal`, `package`, `pub(crate)` …), only when restricted.
   - `EXTRACTOR_VERSION` 9 → 10 (after rebasing onto M5-19, which took 9).
5. **Configuration.** `visibility.internalTags` entries must look like tags (`@?name`); the loader reports others. Schema descriptions and `docs/architecture-rules.md` describe markers, native markers per language and the evaluation step.
6. **Fixture.** New labelled rows only, no relabelling of existing rows:
   - Go: a module-root `internal/ledger` package (Domain through one added `path` selector), legal for the whole module (go-26, a negative either way), and `domain/internal/vault`, which Go refuses to `application/` (go-28, native violation), both used by a new `application/close_order.go`;
   - Python: a `_journal` module and a `_round_half_even` function used by a new `close_order.py` (python-26, python-27), and `round_amount` (python-28, a negative);
   - rows are labelled for the default configuration; `native` gives the label under `nativeMarkers: true`, and `edgeTypes` every edge type that carries the dependency.

## Out of scope

- Reading `tsconfig.json` `stripInternal` (the TS native marker is the `@internal` tag either way).
- External package visibility (`vendor-leak`, private `package` selectors): M5-19 … M5-24.
