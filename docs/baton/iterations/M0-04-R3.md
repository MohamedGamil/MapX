# M0-04-R3 — Laravel: ->middleware(X::class) route middleware edges via the route file use table

## Identification

Milestone: M0; priority: as registered in the plan; risk: low; role: Laravel/static-analysis engineer.

## Objective

Middleware named by class constant (`->middleware(EnsureX::class)`, `Route::middleware([EnsureX::class])->group(...)`) is a route's middleware (by FQN) and yields a route-file → middleware-class edge.

## Dependencies

M0-04-R2 (hard, DONE): namespace-strict PHP class resolution and no Kernel.php fallback for unresolved middleware.

## Scope

- `listArg` and `parseGroupAttributes` keep class constants (`X::class`, `\A\B::class`) next to quoted names.
- `walkRouteFile` names them through the route file's use table (whole name or first segment, aliases included) and namespace; an unimported class in a file without namespace is the global `\X`. Applied to every route the file produces and to mount frames it hands to required files.
- The scanner's existing route-middleware loop then resolves the FQN namespace-strictly (M0-04-R2).

## Out of scope

- Middleware declared in RouteServiceProvider `->middleware(...)` calls parsed by `parseRouteServiceProvider` (string-only regex, separate path).
- Controller-constructor middleware.

## Implementation plan

1. Failing e2e test in `tests/laravel-mounts.test.ts`: imported single and array class constants, a group, a namespace-alias partial name, an unimported class and an Illuminate class.
2. `src/frameworks/detectors/laravel.ts`: `listArg`/`parseGroupAttributes` tokens; `middlewareClassNames` in `walkRouteFile`.
3. Mutation check; routes scorer before/after; full suite and typechecks.

## Expected outputs

Code in `laravel.ts`; the e2e test; `docs/baton/reports/M0-04-R3.md`.

## Acceptance criteria

1. `Route::get(...)->middleware(EnsureX::class)` and `Route::middleware([EnsureX::class])->group(...)` with `use App\Http\Middleware\EnsureX;` give the route that middleware (FQN) and a route→middleware edge to app/Http/Middleware/EnsureX.php (e2e test).
2. A middleware class not imported or not indexed gives no edge and no Kernel.php fallback (test).
3. The routes scorer stays at 0 false positives with recall not lower than before.
