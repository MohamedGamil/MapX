# M4-09-R3 — external-refs tests remove every temp workspace, including unreadable ones

## Identification

Milestone: M4; priority: P2; risk: low; estimate min/expected/max: 0.5/1/2 h; role: test hygiene.

## Objective

`tests/external-refs.test.ts` leaves no `mapx-extrefs-*` entry in `os.tmpdir()` after a run. That includes the cases that make a lockfile or manifest unreadable, and the per-app fixture copies.

## Dependencies

M4-09-R2 (hard): the earlier temp-dir hygiene (`scripts/baton/check-test-cwd.mjs`).

## Scope

- **Reproduce first:** run the file with a private `TMPDIR` and list what is left.
  - Found at f171ddb: one `mapx-extrefs-sync-*` per run.
  - Its cause: the backport test of `pypi attribution of a scan` calls `p.create` twice, and `project().remove()` only removes the last root.
- **Tracking:**
  - Every temp workspace of the file comes from one helper, `tempDir(kind)`.
  - Its name carries a token for this run (`mapx-extrefs-<pid>-<kind>…`).
  - The helper records the folder.
- **Unreadable paths:** they come from `unreadable(path)`, which records the mode.
- **Top-level `afterEach`:** it restores every recorded mode and asserts that each path is readable again. Only then does it remove every recorded folder.
- **`afterAll`:** it counts this run's `mapx-extrefs-<pid>-*` entries in `os.tmpdir()`, before and after. It removes any leftover, then fails and names each one.

## Out of scope

- Removing the leftovers earlier runs put in `/tmp`. That is the owner's call.
- Other test files. `scripts/baton/check-test-cwd.mjs` (M4-09-R2) covers the whole suite.

## Implementation plan

The only file changed is `tests/external-refs.test.ts`:
- Add the helpers and hooks.
- Route every `mkdtempSync` and every `chmodSync(…, 0o000)` through them.
- Drop `project().remove()` and the per-describe `afterEach` that called it.

## Expected outputs

- `tests/external-refs.test.ts`
- `docs/baton/reports/M4-09-R3.md`

## Acceptance criteria

1. After `npx vitest run tests/external-refs.test.ts`, no new `mapx-extrefs-*` entry of the run exists in `os.tmpdir()`. The file's `afterAll` asserts this by counting before and after.
2. A test that makes a file or folder unreadable has its permissions restored in an `afterEach`, before removal. The test fails if the restore is removed (mutation check).
