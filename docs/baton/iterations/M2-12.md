# M2-12 — A method called on a new-expression gets a call edge (`new X().m()`)

## Identification

Milestone: M2; priority: P2; risk: medium; estimate min/expected/max: 2/4/8 h; role: parser and resolver engineer.

## Objective

In JS/TS, `new X().m()` gives a call edge to X#m (and keeps the instantiation edge to X), as `const x = new X(); x.m()` does. The languages that parse the construct the same way (PHP `(new X())->m()`, Java and C# `new X().m()`, Python `X().m()`) link the method the instantiated class declares, not a same-named method elsewhere.

## Dependencies

M2-09 (hard, DONE). Respects M2-08-R3 (import-bound externals).

## Scope

- Parsers record the instantiated class of a method call's receiver as `metadata.newClass`:
  - JS/TS: new query patterns for `new X().m()` and `(new X()).m()` (`queries/javascript`, `queries/typescript`, both TS grammars); `new ns.X()`, `new X<T>()`.
  - Java and C# (`new X().m()`, generic and qualified types) and Python (`X().m()`, CapWords) in `generic-wasm-parser.ts`, whose queries already capture every method call.
  - PHP (`(new X())->m()`, `new X()->m()`) in `php.ts`, as a fully qualified name.
- The scanner resolves such a call through its class: the class resolves as its instantiation does (an import, then by name), and the call links the method that class declares (verified). A class bound outside the project (M2-08-R3) or not found links nothing. A class that does not declare the method (inherited, magic) keeps name lookup, inferred.
- `EXTRACTOR_VERSION` 15 → 16.

## Out of scope

- Return-type inference for chained calls (`new A().b().c()`: only `b` is resolved).
- An instantiation edge for `new ns.X()` (none before; not this task).
- Inherited methods through the class's bases.

## Implementation plan

- `queries/javascript/references.scm`, `queries/typescript/references.scm`, `queries/typescript/references-tsx.scm`: the call pattern on a new-expression receiver.
- `src/parsers/generic-wasm-parser.ts`: `newReceiverClass(node, language)`, recorded as `metadata.newClass`.
- `src/parsers/languages/php.ts`: the same for a member call on an object creation.
- `src/core/scanner.ts`: `resolveNewReceiverCall`, before the general name lookup; `newClass` dropped from edge metadata.
- `src/core/extractor-version.ts`: 16.
