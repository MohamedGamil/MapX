# M3-12 — HTTP pass and vue-router detector use the shared alias resolver

## Identification

Milestone: M3; priority: P2; risk: low; role: import resolution.
Sources: `docs/baton/reports/M3-09.md` ("Findings outside this task").

## Objective

Every JS/TS import consumer resolves aliases through M3-09's resolver (`jsAliasTargets`) instead of guessing on its own.

## Dependencies

- M3-09 (hard): the shared resolver. DONE.
- Parallel: M3-11 (router navigation from JS modules) landed during this lane, so this lane was rebased onto it. The edits to `vue-navigation.ts` are limited to deleting `withSrcAlias`.

## Scope

- **HTTP pass.** `resolveImport` in `src/frameworks/http/client-calls.ts` resolves relative specifiers itself and sends every other specifier through `jsAliasTargets`. It reads alias configs through a `readText` that the scanner threads through `collectProviders`, `extractHttpCalls`, `importedConstants` and `visibleConstants` (`url-resolver.ts`).
  - The guess "`@/` and `~/` → the nearest `src` folder" is removed.
  - Without a reader (unit callers), the shared fallback applies.
- **vue-router.** `withSrcAlias` is deleted from `vue-navigation.ts`. The scanner gives the vue-router detector and the route table plain `resolveImportPath`, which already uses the shared resolver.
- **Shared fallback (`js-aliases.ts`).** When no alias matches, `@/x` resolves to `src/x` under the nearest package.json folder, then under the `src` folder that encloses the importing file, then under the workspace root. The middle step is what the HTTP pass and `withSrcAlias` used to guess; it now lives in one place and runs only when no config declares the alias.

## Out of scope

`~/` without a config (it is no longer guessed as `src/`), Nuxt aliases, and `package.json` `imports`.

## Acceptance criteria

1. An axios client imported through a Laravel `@` → `resources/js` alias (vite.config.js) is followed by the HTTP pass, and its base URL applies. Covered by an e2e test in `tests/http-client-calls.test.ts`.
2. vue-router route components imported through a configured alias resolve through the shared resolver, and `withSrcAlias` is removed. Covered by an e2e test in `tests/vue-navigation.test.ts`.
3. The edges, routes and HTTP scorers do not drop.
