# M5-18 — Dogfood: MapX architecture config, CI step and user docs

## Identification

Milestone: M5; priority: P2; risk: low; estimate min/expected/max: 4/6/8 h; role: maintainer (docs, CI, architecture rules).

## Objective

MapX checks its own architecture: `.mapx/architecture.jsonc` declares MapX's real layering, a baseline freezes today's violations, CI runs `mapx check` on every push, and docs/architecture-rules.md becomes the complete user guide (every selector, rule, reporter and exit code, each with an example that the real CLI accepts).

## Dependencies

M5-05 (hard, `mapx check`), M5-06 (hard, baselines and `--compare`), M5-07 (hard, CI reporters), M4-01 (interface: owns the CI layout in `.github/workflows/ci.yml`; the arch-check job follows it). No approval gate. D030: `.mapx/` stays gitignored; only the config and its baseline are committed through a narrow negation.

## Scope

- `.mapx/architecture.jsonc` for MapX, path-based layers from `docs/research/deptrac/03-mapx-gap-and-integration.md` §3.9, updated for what `src/` holds today (`src/arch/`, `src/branding.ts`), with a comment on each layer and rule.
- `.mapx/architecture.baseline.json`: today's violations (Languages → Parsers, Agents → Parsers and the others the first check finds), each choice (baseline or fix) recorded in the report.
- `.gitignore`: `!.mapx/architecture.jsonc` and `!.mapx/architecture.baseline.json` under `.mapx/*`; nothing else of `.mapx/` tracked.
- `.github/workflows/ci.yml`: an `architecture` job in the M4-01 layout (checkout, setup-node, `npm ci`, then init, scan, `mapx check`), with GitHub annotations and the SARIF report kept as an artifact.
- docs/architecture-rules.md completed; docs/cli-reference.md and docs/mcp-integration.md cross-linked; a README link.

## Out of scope

- Refactoring the layering itself (moving `maskCode`/`matchBracket`, `findAssetRoot`, `stripJsoncSyntax` into Shared): the baseline records the debt, and fixing it is follow-up work.
- Uploading SARIF to code scanning (needs `security-events: write`, which fork PRs do not get).
- Package, builtin and ambient selectors (M5-24), internal markers beyond what exists (M5-10/M5-11), the dashboard view (M5-15).

## Implementation plan

1. Build, `mapx init`, `mapx scan` on the repository; start from `mapx arch init` and replace its role layers with the §3.9 path layers.
2. Run `mapx check`; classify each violation as fix (only a one-line import move) or baseline; `mapx check --generate-baseline`.
3. Add the CI job; run its exact commands locally (exit 0); add a forbidden import in a throwaway worktree, rerun them (non-zero), discard.
4. Write the docs; run every example against the CLI on a scratch workspace.

## Expected outputs

`.mapx/architecture.jsonc`, `.mapx/architecture.baseline.json`, `.gitignore` negation, `.github/workflows/ci.yml` job, docs/architecture-rules.md, docs/cli-reference.md, docs/mcp-integration.md, README.md link, `docs/baton/reports/M5-18.md`.

## Acceptance criteria

1. The CI job's commands exit 0 on the committed tree; with one deliberate forbidden import added in a throwaway worktree they exit non-zero and name the finding (recorded in the report).
2. docs/architecture-rules.md documents every selector, rule form, policy key, reporter and exit code with an example, each example checked against the real CLI.
