## Scope

All three defects were reproduced with reviewer C's probes (`review-C/p8-impact.sh`, `p7-paths.sh`) and the review's `mapx status` observation.

- **`impact`:** a symbol that is its file's default export (`export default function formatDate`, `export default X`, `export { X as default }`) is imported under any local name. An importer whose default import names the import edge's specifier is listed as an import-only dependant (LOW). Other importers still need to mention the symbol's name.
- **`deps` and `mapx_dependencies`:** the file argument goes through `indexedPath` (backslashes, `./`, absolute paths), as for `edges` and `mapx_edges`, before the exact, glob and substring lookup.
- **`mapx status`:** the git-changes section keeps only the paths that `scannableFilter` (the staleness module's copy of the scanner's file rules, now exported) would index.
- **AC4:** the premise was false. A `.svelte` file yields no references, so the globals check is moot for it. The criterion is corrected (D016) and Svelte extraction is registered as M0-12-R8.
