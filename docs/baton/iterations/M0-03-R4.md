# M0-03-R4 — edges/deps parity: cross-repo incoming edges, unindexed-file message, MCP path matching

## Identification

Milestone: M0; priority: P2; risk: low; estimate min/expected/max: 2h/4h/6h; role: CLI/MCP engineer.

## Objective

`edges <file>` lists incoming cross-repo edges and says when a file is not indexed; `mapx_dependencies` accepts the same path forms as CLI `deps`.

## Dependencies

M0-03-R3 (hard, DONE: D012 edges shapes) and M0-05-R4 (hard, DONE: MCP harness for `mapx_dependencies`). No approval gate.

## Scope

- `mapx edges <file>` / `mapx_edges {file}`: the neighbourhood is no longer limited to the primary repo's edge rows. Edges stored under any registered repo that start or end at the file are listed. Incoming rows gain `sourceRepo` (the edge's repo when it differs from the file's repo, else `null`, mirroring `targetRepo`). Text shows a cross-repo source as `repo:path`, as outgoing rows already do.
- A file that is not in the index and has no edges: CLI prints `File "<file>" is not indexed …` on stderr and exits 1; MCP returns the same text with `isError: true`. A file that is indexed but has no edges keeps `No edges for <file>.` (exit 0).
- `mapx_dependencies {file}` resolves `file` with the CLI's `resolveFilePaths` (exact, glob, partial name), moved to a shared core module. Several matches each get a `── path ──` header, as in the CLI; no match returns the CLI's "not found in index" message with `isError: true`. `crossRepo` uses the resolved paths too.
- Docs: `docs/cli-reference.md`, `docs/mcp-integration.md`.

## Out of scope

- The flat edge list without a file keeps its per-repo scope.
- Partial-name resolution for `edges <file>` itself (not in the criteria).
- Unifying the CLI and MCP `deps` text renderers beyond the multi-match header.

## Implementation plan

- `src/core/edge-view.ts`: `sourceRepo` on `IncomingEdge`; text renders `repo:path` for incoming; `notIndexedMessage(file)`.
- `src/core/file-resolve.ts` (new): `resolveFilePaths` moved from `src/cli.ts`, plus the not-found message.
- `src/cli.ts`: `edges` drops the repo filter when a file is given and reports not-indexed files; `deps` imports the shared resolver.
- `src/mcp.ts`: same for `mapx_edges`; `mapx_dependencies` resolves paths.
- Tests: `tests/legacy-metrics-edges.test.ts` (two-repo workspace e2e, not-indexed CLI + MCP), `tests/legacy-laravel-surface.test.ts` (`mapx_dependencies` partial name and glob through an MCP client).
