# M4-28-R1 — Agent templates do not advertise `mapx explain --reclassify`

## Identification

Milestone: M4; priority: P2; risk: low; estimate min/expected/max: 0.5/1/2 h; role: CLI and agent-integration engineer.

## Objective

The agent templates in `src/agents/templates.ts` advertise only commands and flags the CLI has, so a generated AGENTS.md, CLAUDE.md block or rules file never tells an agent to run a flag that commander rejects.

## Dependencies

M4-28 (hard, DONE): its report found `src/agents/templates.ts:252` advertising `mapx explain <file> [--reclassify]`.

## Scope

- `tests/agents-template-commands.test.ts`: every `mapx …` command line in every template (code spans, and fenced lines that start with `mapx `) is resolved against `buildCLI()`. Each command path must exist, and each flag must be listed by the `--help` of the command it is written on (the program's own help for a flag written before the command).
- `src/agents/templates.ts`: drop `[--reclassify]`, and fix any other line the test finds.

## Out of scope

- Regenerating the root `CLAUDE.md` or `AGENTS.md` (integration owner). The root AGENTS.md still carries the old line.
- `mapx_*` MCP tool references in the templates; tests/docs-surface.test.ts covers the MCP docs.

## Implementation plan

1. Write the test; see it fail on `--reclassify`.
2. Edit the template line(s).
3. Mutation-check; run `npm run check`, the full vitest suite, `npx tsc --noEmit` and `npm run typecheck`.

## Expected outputs

`tests/agents-template-commands.test.ts`, the edited `src/agents/templates.ts`, `docs/baton/reports/M4-28-R1.md`.
