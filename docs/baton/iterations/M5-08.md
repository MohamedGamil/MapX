# M5-08 — Introspection: arch layers --why, which, unassigned, deps, unused, changed, allowed

## Identification

Milestone: M5; priority: P2; risk: low; estimate min/expected/max: 8/10/12 h; role: CLI and static-analysis engineer.

## Objective

Answer the questions a developer or an agent asks about the architecture configuration (docs/research/deptrac AR-13a–g, Deptrac's `debug:*` commands and `changed-files`) from the index, without running a whole check:

| AR | Subcommand | Question |
| --- | --- | --- |
| 13a | `mapx arch layers [layer] [--why]` | Which elements are in layer L, and through which selector? |
| 13b | `mapx arch which <element>` | Which layers is element E in, and why? |
| 13c | `mapx arch unassigned [--kind] [--path]` | What is in no layer? Exit 2 when anything is. |
| 13d | `mapx arch deps <from> [to]` | Which concrete edges go from L1 to L2 (file:line, type, verifiability, decision)? |
| 13e | `mapx arch unused [--limit N]` | Which allowances are used at most N times? |
| 13f | `mapx arch changed [files…] [--since <ref>] [--with-dependents]` | Which layers do these files touch, and which layers depend on them? |
| 13g | `mapx arch allowed <from> <to> [--type]` | Would a dependency A → B be allowed? Decision, rule and reason. |

Every subcommand has `--format text|json` (and `--json`), a documented JSON shape, and the AR-17 exit codes.

## Dependencies

- M5-04 (hard, DONE): membership, policy expansion, the evaluator.
- M5-05 (interface, DONE): `mapx check`, the exit contract and its index gate.
- No approval gate.

## Scope

- `src/arch/introspect.ts`: a library API that M5-14 (MCP `mapx_arch_layers`, `_allowed`, `_explain`) and M5-16 (dead and weak allowances) can call. It returns plain JSON-ready objects; the CLI only prints them.
- `src/arch/evaluate.ts`: the per-layer decision chain (AR-08 steps 3.1–3.6) is extracted into `decideLayers`, which the evaluator and `allowed` share, so a pre-flight answer cannot drift from `mapx check`.
- `src/cli.ts`: seven subcommands under `mapx arch`, and the index gate of `mapx check` factored into a helper they share. `mapx arch [path]` and its legacy flags keep their behaviour.
- Docs: `docs/cli-reference.md`, `docs/architecture-rules.md`.

## Out of scope

- MCP tools: M5-14.
- Dead/weak-allowance smells: M5-16 (it reuses `unusedAllowances`).
- `alternatives` that expose a matching symbol in an allowed layer (AR-19): M5-14 builds them on `allowedLayers`.
- Bootstrapping a configuration (AR-13h, `mapx arch init`): M5-17.
- Membership of files that are not indexed (a file an agent is about to create): only indexed elements and layer names resolve.
