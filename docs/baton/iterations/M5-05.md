# M5-05 — `mapx check` CLI: table/json reporters, exit contract, staleness

## Identification

Milestone M5; P1; risk medium; estimate 6/8/10 h; critical path. Sources: AR-16 (reporters) and AR-17 (exit contract) in `docs/research/deptrac/02-abstract-feature-model.md`; §3.4 of `03-mapx-gap-and-integration.md`. Depends on M5-04 (hard).

## Objective

`mapx check` evaluates `.mapx/architecture.jsonc` (or a `--view`) on the index, prints a table or the JSON report, and exits by AR-17.

## Scope

- **`src/arch/check.ts`:**
  - `selectFindings` (`--layer`, `--rule`; configuration errors always stay);
  - `shownReport` (uncovered, skipped and allowed are hidden unless `--report-*` asks for them; counts keep them);
  - `exitCode`, with precedence 4 > 3 > 1 > 2.
- **Reporters:**
  - `src/arch/reporters/table.ts`: grouped by source layer, with rule, severity, elements, edge type, `file:line` and reason, then a counts line;
  - `src/arch/reporters/json.ts`: pretty, stable JSON.
- **`schemas/arch-report.schema.json`:** the report's JSON Schema, shipped with the package.
- **The `check` command in `src/cli.ts`:**
  - options `--view`, `--format`, `--output`, `--report-uncovered`, `--fail-on-uncovered`, `--report-skipped`, `--report-allowed`, `--fail-on`, `--layer`, `--rule` and `--sync`;
  - 3 for no or an invalid configuration, or a bad option;
  - 4 for no index, a stale index (`findStaleFiles`) without `--sync`, or an internal error.
- **`scripts/eval/score-arch.ts`:** now runs the real `mapx check` (with `--report-uncovered --report-skipped`) instead of the in-process fallback.
- **Docs:** `docs/cli-reference.md` (`mapx check`), `docs/architecture-rules.md` and the CHANGELOG.

**Plan correction:** the registered command `npm run build` does not exist. The test builds `src/` with tsup into a temporary layout (symlinks to `node_modules`, `wasm`, `queries`, `VERSION`, `package.json`, `schemas`), so it runs the built CLI and leaves the checkout untouched (M4-09-R1).

Out of scope:
- `--compare` and `--generate-baseline` (M5-06);
- SARIF, GitHub, CodeClimate and JUnit reporters (M5-07);
- `mapx arch init` (M5-17), which the missing-config hint names;
- MCP `mapx_arch_check` (M5-14);
- `arch validate-config` (M5-02-R1).

## Acceptance criteria

1. **Exit codes from the built binary** (`tests/arch-cli.test.ts`):
   - 0: a clean app;
   - 1: a strict view, and an advisory view with `--fail-on warn`;
   - 2: `--fail-on-uncovered`;
   - 3: a `+` cycle, no configuration, or a bad `--format`;
   - 4: no index, or a stale one; `--sync` repairs it.
2. **JSON:** the output of the PHP fixture validates against `schemas/arch-report.schema.json` (ajv), as do a configuration-error report and an `--output` file. Two runs give byte-identical output.
3. **No configuration:** exit 3, with stderr naming `` `mapx arch init` ``.

## Verification commands

- `npx vitest run tests/arch-cli.test.ts`
- `npm run check`
