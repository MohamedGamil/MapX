# M5-25-R4 — Go: a parenthesised receiver type is indexed

## Identification

Milestone: M5; priority: P3; risk: low; estimate min/expected/max: 1/2/3 h; role: parser engineer.

## Objective

`func (b (Box[T])) Paren()` and `func (b (*Box)) M()` give methods scoped `Box`, as the unparenthesised forms do, with no duplicate symbols.

## Dependencies

M5-25-R2 (hard, DONE): generic receivers (`Pair[K, V]`, `*Pair[K, V]`) are matched by the method pattern of `queries/go/symbols.scm`.

## Cause

Recorded in `reports/M5-25-R2.md` (Limitations). The receiver type of a parenthesised receiver is a `parenthesized_type` node: `(parenthesized_type (generic_type …))` for `(Box[T])`, `(parenthesized_type (pointer_type (type_identifier)))` for `(*Box)`, and `(pointer_type (parenthesized_type …))` for `*(Box)`. No alternative of the method pattern matches it, so the method is no symbol.

## Scope

- `queries/go/symbols.scm`: the method pattern also takes a receiver type in one pair of parentheses, outside or inside the pointer, for a plain and a generic type.
- `src/parsers/generic-wasm-parser.ts`: `goTypeParameter` looks through pointers and parentheses of the receiver type, so a type parameter of a parenthesised generic receiver (`[]T{}` in `func (b (Box[T])) M()`) is not taken for a type named `T`.
- `src/core/extractor-version.ts`: `EXTRACTOR_VERSION` 21 (19 on develop; Lane F takes 20).
- `tests/go-qualified-instantiation.test.ts`: one synthetic workspace, scanned with the real CLI.

## Out of scope

- Doubly parenthesised receivers (`((Box))`). gofmt rewrites them and no code base writes them; a query matches one level only.
- Interface methods as symbols (M5-25-R2 limitation).

## Implementation plan

1. Write the failing test: symbols of `gen/box.go` and `plain/box.go` (kind `method`, exact name and scope), calls from another package, and the instantiation edges of a body that uses the receiver's type parameter.
2. Extend the query; make `goTypeParameter` unwrap the receiver type.
3. Bump the extractor version.
4. Mutation-check; `npm run eval` before and after; registered commands and the full suite.

## Expected outputs

Changed `queries/go/symbols.scm`, `src/parsers/generic-wasm-parser.ts`, `src/core/extractor-version.ts`, `tests/go-qualified-instantiation.test.ts`; `reports/M5-25-R4.md`.

## Acceptance criteria

1. `func (b (Box[T])) Paren()`, `func (b (*Box[T])) PtrIn()`, `func (b *(Box[T])) PtrOut()` in `gen/box.go`, and `func (b (*Box)) M()`, `func (b (Box)) V()`, `func ((Box)) Unnamed()`, `func (b *(Box)) N()` in `plain/box.go` give exactly one method symbol each, scoped `Box`. Test "a parenthesised receiver type …".
2. Calls on qualified literals of those types from another package link the methods. Same test.
3. `npm run eval` holds every floor.
