# M0-12-R6 — Language count after fish (23) in templates and docs; lang list flags missing grammars

## Identification

Milestone: M0; priority: P2; risk: medium; estimate min/expected/max: 1/2/3 h; role: language-registry and agent-template maintainer.

## Objective

Language counts in templates and docs agree with the registry (23 after fish), and `mapx lang list` / `mapx_lang_list` say when a grammar file is missing.

## Dependencies

M0-12-R5 (hard, DONE), M0-09-R4 (hard, DONE). Source: `docs/baton/reports/M0-12-R5.md` (limitations and outside finding).

## Scope

1. **Derived count.** `supportedLanguageCount()` in `src/languages/registry.ts`: languages with a grammar (static file types are not languages; TSX counts as TypeScript). `src/agents/templates.ts` interpolates it instead of hard-coding 22.
2. **Docs match.** README and `docs/**` (outside `docs/baton/`) say 23; the `docs/configuration.md` tier table matches the registry's tiers. A test fails when any "N languages" in README, docs, the agents stub or a template disagrees with the registry, or when the tier table disagrees.
3. **Missing grammars.** `isLanguageInstalled` checks that a grammar language's WASM file exists; `formatLanguageList` (shared by the CLI and MCP) reports `status: missing` for such a language and says so in its header.

## Out of scope

- The generated root files (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `AIDER.md`, `.clinerules`, `.github/copilot-instructions.md`, `.windsurf/`, `.zed/`): the owner regenerates them.
- `ROADMAP.md` ("all 20 languages" is a checked-off historical item) and `specs/` (frozen, D001).
- The "33 MCP tools" counts.
