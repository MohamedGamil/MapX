# M0-02-R6 — git sync re-parses a file whose working-tree edit was reverted to HEAD

## Identification

Milestone: M0; priority: P1 (raised by review 2026-10-31); risk: low; estimate 1/2/3 h; role: scanner / incremental indexing.
Sources: `docs/baton/reviews/REVIEW-2026-10-31-2db08bd25e13.md` ("P1, remediation registered").

## Objective

After an edit is synced and then reverted to HEAD's content, the next git sync restores HEAD's symbols and edges.

## Dependencies

M0-02-R5 (hard): blob ids stored for re-indexed files, the blob skip, and HEAD's tree read once per sync (`getGitBlobHashes`). DONE.

## Scope

Git sync compares two trees, the last scanned commit and the working tree (plus the index and untracked files). An edit reverted to HEAD while HEAD is still the last scanned commit is in neither diff, so the edited content stayed indexed and `mapx status` called the file stale. Git sync already reads HEAD's tree once to find removed files; the same loop now lists, as modified, every indexed file of the repo whose stored blob id is not HEAD's blob and that still exists. The blob skip that follows re-parses it only when its bytes are not the indexed ones.

Blast radius: `_scanIncrementalForRepo` only (private; called by `scanIncremental`).

## Out of scope

- Gitignored indexed files, which are not in HEAD's tree: M0-02-R7 (scan and sync agreement on gitignored files).
- Other sync sequences (folder repos, moved targets, rename plus copy): M0-02-R7. Cross-repo edges: M0-10-R4.

## Implementation plan

- `src/core/scanner.ts` `_scanIncrementalForRepo`: the HEAD-tree loop adds the reverted-file case.
- `tests/legacy-globs.test.ts`: describe "git sync: an edit reverted to HEAD", two e2e tests comparing files, edges and symbols with the fresh index and with `scan --force`.

## Acceptance criteria

1. Edit a committed file (adds a symbol and a `param_type` edge), sync, `git checkout -- f`, sync: files, edges and symbols equal the fresh scan and `scan --force` (e2e).
2. The same for a staged edit reverted with `git reset` and `git checkout` (e2e).

## Verification

- `npx vitest run tests/legacy-globs.test.ts`
- Also: `npm run check`.

## Recovery

Revert the commit; the index heals on `scan --force`.
