# M5-22 — External references: pip/Poetry/uv package attribution and builtins

## Identification

Milestone: M5; priority: P2; risk: medium; estimate min/expected/max: 4/5/8 h; role: scanner and package manifests.

## Objective

Every pypi row of the `external_refs` view (M5-19) says what it belongs to: the distribution that provides the imported module (`flask`, `pyyaml` for `yaml`, `pillow` for `PIL`), or the Python standard library (`python:os`); whether a manifest of the file lists it (direct) or only a lockfile holds it (transitive); whether it is dev-only; and whether a lockfile backed the answer (`lock`) or the manifests alone did (`manifest`). Gap G9 of `docs/research/deptrac/03-mapx-gap-and-integration.md` for pip, Poetry and uv; the data of the AR-04 `package` and `builtin` selectors (M5-24). Decomposed from epic M5-12 (D019). Mirrors M5-20 (npm) and M5-21 (Composer).

## Dependencies

M5-19 (hard, DONE): the candidates table, its attribution columns, the end-of-run decision pass. M5-01 (fixture): `tests/fixtures/arch-rules`. M5-20 and M5-21 (same pass, columns, recorded inputs, scorer section) are DONE. No approval gate.

## Scope

- **Manifests**, from the file's folder up to its repo's root (never above it, M5-20 P1):
  - `pyproject.toml`: PEP 621 `[project] dependencies` and `[project.optional-dependencies]` (production), PEP 735 `[dependency-groups]` (dev), Poetry `[tool.poetry.dependencies]` (production, `python` excluded), `[tool.poetry.dev-dependencies]` and `[tool.poetry.group.<name>.dependencies]` (dev; group `main` is production), uv's legacy `[tool.uv] dev-dependencies` (dev);
  - `*requirements*.txt` in the folder: `requirements.txt` production, a file whose qualifier names dev, test, lint, docs, typing, ci and the like dev, any other production; `-r` includes are followed within the repo.
  - Names are normalised per PEP 503. A name listed for production and dev is production.
- **Lockfiles**: the nearest folder holding `uv.lock` or `poetry.lock`. A lockfile that is there but cannot be read ends the walk (M5-21 review P2, M5-20-R1): the manifests answer, flagged `manifest`.
  - `uv.lock`: the workspace members (`source` editable or virtual) are the roots: their dependencies and extras production, their dependency groups dev; dev-ness is reachability, production winning, following requested extras.
  - `poetry.lock`: `groups` (lock 2.1), else `category` (lock 1.x), else reachability from the lock folder's pyproject.
- **Import name → distribution**: MapX reads no site-packages or venv, so the distribution is found by name: for each module prefix, longest first (`google.cloud.storage` → `google-cloud-storage`), the PEP 503 form of the import name and a small documented table of well-known mismatches (`yaml` → `pyyaml`, `PIL` → `pillow`, `sklearn` → `scikit-learn`). A candidate counts only when an input (manifest or lock) names it. Several confirmed candidates are told apart by the manifests (production, then dev), else the row is unknown (package null): never an arbitrary pick (M5-21 review P1-1). A table entry with one distribution that no input names gives that distribution, unlisted (direct 0, dev null). Anything else is unknown.
- **Stale lock** (M5-21 review P2): a required name the lock lacks is attributed from the manifests, flagged `manifest`.
- **`replace`/`provide`** (M5-21 review P2): Python lockfiles have no such field; nothing to do, recorded.
- **Standard library**: a module whose top-level name is in `sys.stdlib_module_names` of Python 3.10 … 3.15 (union) is `builtin`, package `python:<top-level>`. The list is generated (`scripts/gen-python-stdlib.py`, `src/core/manifests/python-stdlib.ts`).
- **Inputs, skip, staleness, sync**: the reads join M5-20's recorded inputs. The requirements listing of a folder is recorded as a glob input, so a new requirements file makes the index stale and a sync re-attributes.
- **Fixture**: `tests/fixtures/arch-rules/python` gains PEP 621 dependencies, a dependency group and a hand-written `uv.lock` with real public packages, plus new imports; every pypi row of `expected-externals.json` is labelled.

## Out of scope

- `Pipfile`/`Pipfile.lock`, `pdm.lock`, `setup.py`/`setup.cfg`, pip-tools' compiled `requirements.txt` as a lock, conda `environment.yml`.
- Go modules: M5-23 (concurrent lane). Selectors over the columns: M5-24.
- The `CHANGELOG.md` entry: the integration owner writes it.
