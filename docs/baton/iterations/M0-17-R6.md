## Identification

Milestone: M0; priority: P2; risk: medium; estimate min/expected/max: 4/6/9 h; role: parsers and resolution.

## Objective

Close four heuristic gaps recorded by the 2026-11-01 reviews: the M0-02-R8 report (reviewer O, P2-3), the M3-11-R1 report (reviewer O, P2-5/P2-6), D017 (Laravel module `@/`) and the M0-17-R5 report (reviewer L, P2-11).

## Scope

1. **Rename survives as text** (`removedSymbolReferrers`, `src/core/scanner.ts`). Whether a declared name is still in a changed file is now judged on the file's code with comments and string literals blanked: `#` comments and docstrings for Python, Ruby and shell; `//` and `/* */` for the rest. A rename whose old name survives only in a comment or string therefore re-parses the callers.
2. **Vue Router heuristics** (`src/parsers/languages/vue-navigation.ts`):
   - **Guard returns.** A nested function's return type of any shape is skipped when finding nested bodies: an object type, a literal union, a function type or a generic. So that function's `return` is not the guard's.
   - **`next`.** A guard's `next` rebound inside a nested function or arrow, as a parameter or a local, is not the guard's `next`.
   - **`push`/`replace`.** A destructured `push`/`replace` rebound in a function by a parameter or a local is not the router's.
   - **Templates.** A template name bound by `v-for` or `v-slot` hides the `<script setup>` binding of the same name.
3. **Laravel module `@`** (`src/core/js-aliases.ts`). When the nearest app root is a Laravel module folder (`Modules/<Name>`) and its own bundler aliases do not match the import, the next enclosing app's bundler aliases apply.
4. **Factory bindings** (`src/parsers/generic-wasm-parser.ts`). A module-level binding to a call, a name or a member is promoted to a `function` symbol only when it is exported (`export`, `export { … }`, `module.exports`) or the file calls it by name. For Python: when it is public (no leading underscore) or the file calls it. Otherwise it stays a value: `const app = createApp(App); app.mount()`.

## Acceptance criteria

1. A function renamed while its old name stays in a comment or string of the file drops its callers' edges on sync, as `scan --force` does (e2e, `tests/heuristic-followups.test.ts`).
2. Vue Router (unit tests, `tests/heuristic-followups.test.ts`):
   - no navigate edge for a `next` or `push` shadowed by a parameter or local, or a template `v-for`/`v-slot` alias;
   - a nested function's return with an object, literal-union or function return type is not the guard's.
3. A `Modules/Blog` folder with its own vite config declaring no `@` alias resolves `@/x` through the root app's `@` (test).
4. `const app = createApp(App); app.mount()` gives `app` a value symbol, while `export const useX = factory()` and a called binding stay functions (test). The M0-17-R5 tests still pass.
