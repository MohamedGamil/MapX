# M4-19 — Browser test harness for the dashboard

## Identification

Milestone M4; P1; risk medium; estimate 6/10/16 h. Decision D027.

## Objective

Real-browser tests (Playwright) load every dashboard tab on fixture workspaces and guard against console errors, failed API calls and render-time regressions.

## Background

D027: @playwright/test is accepted as a dev dependency (Apache-2.0).

## Dependencies

- M4-16 (hard)

## Out of scope

Visual redesign (M4-17); new views (M4-21 to M4-23).

## Acceptance criteria

1. npm run test:ui builds the dashboard, scans a fixture workspace, serves it on a free port, and opens every tab in Chromium: each tab's main panel renders content, with no console error, page error or failed /api request (tests/ui/smoke.spec.ts).
2. A render budget test fails when the graph tab takes more than the M4-16 baseline plus 20% to render the ~500-node fixture (tests/ui/perf.spec.ts).
3. CI runs the UI tests after installing Chromium; without a browser the tests skip with a message saying so.
4. Breaking one tab's loader makes the smoke test fail (mutation check in the report).

## Verification

- `npm run test:ui`
- `npm run check`
