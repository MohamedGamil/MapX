# M5-21 — External references: Composer package attribution and builtins

## Identification

Milestone: M5; priority: P2; risk: medium; estimate min/expected/max: 3/4/7 h; role: scanner and package manifests.

## Objective

Every Composer row of the `external_refs` view (M5-19) says what it belongs to: the Composer package whose autoload covers the class or function (`guzzlehttp/guzzle` for `GuzzleHttp\Client`), or the PHP extension that defines a built-in (`ext-date` for `DateTime`, `ext-pdo` for `PDO`, `ext-standard` for `str_contains`); whether a `composer.json` of the file lists the package (direct) or only `composer.lock` holds it (transitive); whether it is dev-only; and whether the lock backed the answer (`lock`) or the manifests alone did (`manifest`). Gap G9 of `docs/research/deptrac/03-mapx-gap-and-integration.md` for Composer; the data of the AR-04 `package` and `builtin` selectors (M5-24). Decomposed from epic M5-12 (D019). Follows M5-20's design for npm.

## Dependencies

M5-19 (hard): the candidates table, its attribution columns, the end-of-run decision pass, PHP externality per name. M5-01 (fixture): `tests/fixtures/arch-rules`. M5-20 (same pass, same columns, recorded inputs, scorer section) is DONE. No approval gate.

## Scope

- **Columns filled** for Composer candidates decided external, by the end-of-run decision pass:
  - `origin`: `builtin` for a PHP built-in class or function (a static list), else `package`;
  - `package`: `ext-<extension>` for a built-in (Composer's platform package name, which cannot collide with a `vendor/name` package), else the Composer package name, or null when no input names one;
  - `direct`: 1 when a `composer.json` from the file's folder up to its own repo's root lists the package in `require` or `require-dev`, 0 when not; null for a built-in and when the package is unknown;
  - `dev`: from the nearest manifest that lists it (`require` wins); for a transitive package from the lock (`packages-dev`); null when unknown and for a built-in;
  - `attribution`: `lock` when a readable `composer.lock` was used, `manifest` otherwise (criterion 2's flag); null for a built-in.
- **Class → package** with a lock: each locked package's `autoload` `psr-4` and `psr-0` prefixes, the longest prefix winning (case-insensitive, as PHP names are). A namespaced function is attributed by the same prefixes (a package's `files` define functions in its namespace by convention). `classmap` and `files` name paths, not classes: MapX reads no `vendor/` (as M5-20 reads no `node_modules`), so a name no prefix covers is matched by Composer naming convention against the lock's packages that load by `classmap`/`files`; if none matches it is unknown (package null) when such packages exist, else unlisted (`direct` 0).
- **Without a readable lock**: the same naming convention against the manifests' direct requirements (`psr/log` ↔ `Psr\Log\…`, `nesbot/carbon` ↔ `Carbon\…`); unmatched rows have an unknown package. Flagged `manifest`. Never a crash.
- **Platform requirements** (`php`, `php-64bit`, `hhvm`, `ext-*`, `lib-*`, `composer-plugin-api`, `composer-runtime-api`, `composer`) are not packages: never matched.
- **Facades**: attribution uses the class the file names (the facade, `Illuminate\Support\Facades\DB`), as its `use` import row does, so both rows agree. Only when that class maps to no package (a global alias such as `DB` in a non-namespaced routes file) does the facade's target class (`metadata.facadeTarget`) decide.
- **Built-ins**: a generated static list (`src/core/manifests/php-builtins.ts`) of every internal class, interface, trait, enum and function of the extensions bundled with php-src, by reflection of PHP 8.1, 8.2 and 8.4 (union), with its source recorded; the generator is `scripts/gen-php-builtins.php`. PECL extensions are not built-ins.
- **Inputs, caching, staleness, sync parity**: the composer reads join M5-20's recorded inputs (paths and md5), so the skip, the stale gate and sync = `scan --force` cover `composer.json` and `composer.lock`.
- **Fixture**: `tests/fixtures/arch-rules/php` gains requirements in `composer.json`, a synthetic `composer.lock`, and further references in `HttpGateway.php`; every Composer row of `expected-externals.json` (php and workspace apps) is labelled.
- **Scorer**: the externals section scores Composer once its rows carry `origin`; a class `unknown` (package null) is added to the breakdown.

## Out of scope

- pip/Poetry/uv and Go attribution: M5-22, M5-23. Selectors and smells over the columns: M5-24.
- Reading `vendor/` (installed.json, autoload_classmap.php, package sources): a policy change from M5-20; recorded as a limitation.
- PECL extension symbols (`Redis`, `Imagick`) as `ambient`: no list ships; they stay package rows of unknown package.
- The M5-19 storage of a fully qualified facade alias (`\Cache::get()` in a namespaced file is stored under the file's namespace): reported, not changed.
