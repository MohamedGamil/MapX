# M0-12-R3 — Linear-time import resolution; shebang scripts resolve references; D010 docs

## Identification

Milestone: M0; priority: P1; risk: medium; estimate min/expected/max: 4/6/9 h; role: scanner and language-registry maintainer.

## Objective

Import resolution scales to large repos, shebang scripts take part in the graph, and docs match D010.

## Dependencies

M0-12-R1 (hard), M0-12-R2 (hard). Source: review 2026-10-31 (`reviews/REVIEW-2026-10-31-fb75474ba377.md`), `specs/features/F20-language-expansion.md`.

## Scope

1. **Linear import resolution.** `src/core/import-resolvers.ts` gets an index built once per file set (exact-basename and lower-case-basename buckets, Go package directories). `bySuffix`, the Go resolver and the PHP resolver look up a bucket instead of scanning every indexed file per import. The scanner builds a fresh file set for each resolution phase, so a long-lived scanner (watch, MCP) never resolves against a stale set.
2. **Shebang scripts in reference resolution.** The scanner records each file's language (discovery and store) and uses it when a path has no extension, so a `#!/usr/bin/env python3` script's `main` → `helper` call gets its edge, as source and as target. `#!/usr/bin/env ts-node` (and `tsx`) map to typescript.
3. **D010 docs and MCP parity.** README, generated agent templates and `docs/mcp-integration.md` stop describing language installation. `mapx_lang_list` reports "bundled" like the CLI; `mapx_lang_info` matches `mapx lang info`; unknown-language errors set `isError`.
4. **F20 file names.** `Rakefile` and `Gemfile` index as Ruby; `.fish` is indexed (as a file without symbols: no fish grammar is bundled, and the bash grammar mis-parses fish).
5. **Worker shebang path.** A fixture above the parallel threshold proves worker-parsed shebang scripts keep their language.

## Out of scope

- Per-language import precision (Java top-dir preference, C# store fallback, Kotlin/Scala e2e): M0-12-R4.
- PHP `Illuminate\…` resolution and `$listen` parsing: M0-04-R2.

## Implementation plan

- `src/core/import-resolvers.ts`: `ImportIndex`, cached per `files` Set in a WeakMap; resolvers use it.
- `src/core/scanner.ts`: per-phase file set; `fileLanguages` map; `languageOf(path)` used by reference, import and symbol resolution.
- `src/languages/registry.ts`: `filenames` on `LanguageDefinition` (Rakefile, Gemfile); `fish` static language; ts-node/tsx shebangs.
- `src/mcp.ts`, `src/agents/templates.ts`, `README.md`, `docs/mcp-integration.md`, `docs/cli-reference.md`.
- `scripts/bench/import-resolution.ts`: synthetic generated benchmark (temp dir, no real code).

## Expected outputs

Code above, tests in `tests/legacy-imports.test.ts` and `tests/legacy-languages.test.ts`, benchmark script, `reports/M0-12-R3.md`.

## Acceptance criteria

- Resolution builds its indexes once per scan; a 2,000-file Java repo with 10 imports per file scans within 1.5× the time without imports (measured by `scripts/bench/import-resolution.ts`, recorded in the report).
- A python shebang script with main calling helper gets the call edge (e2e test).
- No doc or generated template describes installing a language; MCP and CLI agree on lang list/info (tests).
- `.fish`, Rakefile and Gemfile are indexed (e2e test).
