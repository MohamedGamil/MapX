# M4-09-R2: tests remove the temp directories they create

## Identification

Milestone: M4; priority: P2; risk: low; estimate min/expected/max: 0.5/1/2 h; role: test hygiene.

## Objective

A test run leaves no new directory in the system temp folder, and `check-test-cwd` proves it.

## Dependencies

M4-09-R1 (hard, DONE).

## Scope

- **`scripts/baton/check-test-cwd.mjs`:**
  - gives the run a private `TMPDIR`, `TMP` and `TEMP`;
  - fails, naming each entry, when anything other than a tool cache is left there;
  - ignores two tool caches: Node's compile cache and tsx's per-user cache.
- **`tests/mcp-coverage.test.ts`:** removes its `mapx-stale-*` directory in a `finally`.

## Out of scope

Removing directories earlier runs left in `/tmp`. That is the owner's decision, and the existing leftovers are not touched.

## Acceptance criteria

1. **Whole suite:** a run under the check leaves no new entry in the temp directory. The check exits 0 (`node scripts/baton/check-test-cwd.mjs`).
2. **The check:** it fails, naming the entry, when the command leaves a temp directory. It passes when the command removes the directory or leaves only a tool cache (`tests/check-test-cwd.test.ts`).
3. **The leak:** `tests/mcp-coverage.test.ts` removes its directory, also when an assertion fails.

## Verification

- `npx vitest run tests/check-test-cwd.test.ts tests/mcp-coverage.test.ts`
- `node scripts/baton/check-test-cwd.mjs`
- `npm run check`

## Recovery

Revert the task commit.
