# M4-09-R1 — The whole test suite leaves the checkout untouched

## Identification

Milestone: M4; priority: P1; risk: low; estimate min/expected/max: 1/2/3 h; role: test infrastructure.

## Objective

`npx vitest run` in a checkout holding `.mapx/config.json` and `.mapx/mapx.db` changes no file of the checkout, and `scripts/baton/check-test-cwd.mjs` would notice if it did. This remediates M4-09, which the 2026-11-02 review found FALSELY COMPLETE.

## Dependencies

M4-09 (hard, DONE, completion disputed).

## Scope

- **`scripts/baton/check-test-cwd.mjs`:**
  - snapshots `git status --porcelain=v1 --untracked-files=all --ignored`, plus a content hash of every listed file and every file under `.mapx/`, before and after the run;
  - with no test files named, it runs the whole suite;
  - `--cmd <command…>` runs another command instead of vitest, for its own tests.
- **`tests/mcp-coverage.test.ts`:** runs from a temporary directory, as `tests/cli.test.ts` does, so that `UiEventBus` appends to a temporary `.mapx/tool-calls.jsonl`.
- **Other suite files that write into the checkout:** found by the strengthened check and fixed the same way.

## Out of scope

`tests/fixtures/**` being committable (`tests/fixtures-tracked.test.ts`, review 2026-11-02).

## Acceptance criteria

1. `node scripts/baton/check-test-cwd.mjs` (the whole vitest suite) exits 0 in a clean clone holding sentinel `.mapx/config.json` and `.mapx/mapx.db` files.
2. The check exits 1, naming the path, when the command run:
   - edits an existing top-level tracked file;
   - creates a new nested file;
   - appends to `.mapx/tool-calls.jsonl`;
   - edits an already-modified file.

   Shown by `tests/check-test-cwd.test.ts`.

## Verification

- `npx vitest run tests/check-test-cwd.test.ts tests/mcp-coverage.test.ts`
- `node scripts/baton/check-test-cwd.mjs` (in a clean clone with sentinels)
- `npm run check`

## Recovery

Revert the task commit.
