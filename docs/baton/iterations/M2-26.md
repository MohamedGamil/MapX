# M2-26 — A class destructured from a call result never links a same-named class elsewhere

## Identification

Milestone: M2; priority: P1; risk: medium; estimate min/expected/max: 2/4/6 h; role: parser and resolver engineer.

## Objective

`const { Database } = load('bun:sqlite'); new Database()` (a binding from a call result, not an import) gets no edge to a same-named project class, and `const { render } = load(); render()` none to a same-named function.

## Dependencies

M2-08-R3 (hard). Shares its mechanism, `boundLocally`, with M2-25.

## Scope

M2-25 and M2-26 share one mechanism, so the code (`destructuresLocal` in `src/parsers/generic-wasm-parser.ts`, `EXTRACTOR_VERSION` 22) shipped in M2-25's commit. This commit adds M2-26's tests (`describe('names destructured from a call result')` in `tests/local-binding-calls.test.ts`) and its report, and no extractor bump: the extractor did not change after 22.

Behaviour the tests pin: a destructuring from a call given a package or builtin specifier links nothing, in a function and at module level; from any other call result it keeps the by-name edge, marked inferred; an imported class or function of that name, a name destructured from `require('./m')` or `await import('./m')` of a project module, and a name destructured from the result of an imported function (`const { build } = make()`) still link.

## Out of scope

Destructured parameters; a destructuring from an imported function's result of an external package (kept as before, since an import's origin is not known in the parser).

## Implementation plan

Tests and report only (see M2-25 for the code).

## Expected outputs

`tests/local-binding-calls.test.ts` (second describe), `docs/baton/reports/M2-26.md`.

## Acceptance criteria

1. The repro (`const { Database } = load('bun:sqlite'); new Database()`, and `const { render } = load(); render()`) gives no edge to `other/Database.ts#Database` or `other/ui.ts#render`; an imported class of that name still links (`tests/local-binding-calls.test.ts`).
2. `npm run eval` holds.
