# M4-09 — Tests never write to or delete files in the repository checkout

## Identification

Milestone: M4; priority: P2; risk: low; estimate 1/2/4 h; role: test infrastructure.
Sources: `docs/baton/reports/M2-06-R2.md` and `docs/baton/reports/M0-09-R5.md` (findings outside the task).

## Objective

`npx vitest run` leaves the developer's checkout untouched. No `.mapx/` file is created, changed or deleted outside temporary workspaces.

## Dependencies

None.

## Scope

- **`tests/cli-coverage.test.ts`** created `.mapx/` in the process working directory (the repo root) and, in `afterAll`, deleted `.mapx/mapx.db` and `.mapx/config.json`. That wiped a developer's MapX index of the repo.
- **`tests/cli.test.ts`** runs `init` and `uninit` against `.`.
- **Fix.** Both files now run from a temporary directory: `process.chdir` in `beforeAll`, and restore and delete in `afterAll`. vitest's `forks` pool allows `chdir`. `cli.test.ts` creates the one indexed file its store mocks name (`src/main.ts`), which its staleness tests used to find in the checkout.
- **Check.** `scripts/baton/check-test-cwd.mjs` hashes every file under `.mapx/` and lists the top-level entries before and after running the given test files, and exits 1 on any difference.
- **Registered command.** The task's command was changed to that check while the task was in progress; it was `npx vitest run tests/cli-coverage.test.ts tests/cli.test.ts`.

## Out of scope

Other tests that write to the working directory were not found by the check, which runs only the two named files. A full-suite run under the check is possible but slow.

## Acceptance criteria

1. With `.mapx/config.json` and `.mapx/mapx.db` present in the checkout, running the two test files leaves both, and every other `.mapx/` file, byte-identical, and adds no top-level entry (`node scripts/baton/check-test-cwd.mjs tests/cli.test.ts tests/cli-coverage.test.ts` exits 0).
2. The CLI test files run their commands from a temporary working directory (the hooks at the top of both files; the mutation check below).

## Verification

- `node scripts/baton/check-test-cwd.mjs tests/cli.test.ts tests/cli-coverage.test.ts`

## Recovery

Revert the commit.
