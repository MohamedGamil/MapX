# M0-07-R7 — install.sh reads the installed version without GNU grep -P (macOS)

## Identification

Milestone: M0; priority: P2; risk: low; estimate min/expected/max: 1/1/2 h; role: packaging engineer.

## Objective

On macOS, where BSD grep has no `-P`, the existing-install check reports the installed version instead of `(vunknown)`. Only POSIX tools are used.

## Dependencies

M0-07-R5 (hard, DONE).

## Cause

M0-07-R5 found this; it predates that task. `check_existing` in `scripts/templates/install.sh` ran `"$target" --version | grep -oP '[\d.]+' || echo unknown`. BSD grep rejects `-P`, so the pipeline fails and the warning always says `(vunknown)`.

## Scope

- Read the version with POSIX `sed -n 's/^[^0-9]*\([0-9][0-9.]*\).*/\1/p' | head -n 1`.
- Default to `unknown` when nothing matches.
- Keep `|| true`: the script runs under `set -euo pipefail`, and a binary whose `--version` fails must not abort the install.

## Out of scope

- An empty custom prefix: M0-07-R6 (P3, held).
- Other macOS differences in `install.sh`: none were found by reading it.

## Acceptance criteria

1. Setup: a PATH whose `grep` rejects `-P`, and an existing stub `mapx` that prints `mapx 0.3.8`. Running `install.sh --prefix <dir> --force` warns `(v0.3.8)` and replaces the binary. Test: "names the installed version when grep has no -P".
2. An existing binary whose `--version` exits 3 is reported as `(vunknown)` and replaced, with exit 0. Test: "an installed binary whose --version fails …".
3. `install.sh` contains no `grep -P`. Test: "install.sh uses no GNU-only grep -P".
