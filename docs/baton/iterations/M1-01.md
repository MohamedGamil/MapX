# M1-01 — Laravel route fixture and recall/precision scorer

## Identification

Milestone: M1; priority: P0; risk: medium; estimate min/expected/max: 6/10/14 h; area: frameworks, quality.
Sources: `docs/reports/2026-10-30-laravel-vue-coverage-findings.md`.

## Objective

A synthetic Laravel app covering every declaration form and mount in the report, with labelled expected routes and a scorer that prints recall and precision.

Report §4 item 18. Labels pin method, URI and handler per route; negative cases (unmounted file, overridden duplicate, conditional mount) carry `null` expectations. The scorer reports per-pattern recall and precision; this task records the 0.3.5 baseline without fixing anything.

## Dependencies

none.

## Scope

Contracts first: `labels.json` schema `{ id, pattern, method, uri, handler: 'Fqcn@method' | null, file, reachable?, overridden? }` and the scorer's JSON output `{ pattern: { labelled, found, handlerFound, falsePositives } }`. Then a synthetic Laravel 12 app under `tests/fixtures/laravel-routes/` (no pilot code) with: `routes/web.php`, `routes/api.php`, `routes/api/*.php` mounted by `require` inside groups, a module provider using `loadRoutesFrom` under `Route::prefix(...)->group(...)`, `bootstrap/app.php` `withRouting(...)`, every declaration form from report §2 (`['uses' => ...]`, `[C::class, 'm']`, `Route::controller()->group()`, `Route::match`, `Route::resource` incl. hyphenated and irregular names, `$base.'/x'`, closures), and negatives (an unmounted file, a duplicate method+URI where the later wins, an `if (...) require`). The scorer runs `LaravelDetector` over the fixture through the real scanner path (`mapx scan` into a temp copy), so mounts and providers are exercised.

## Out of scope

Any detector fix (M1-02…M1-09). Vue/HTTP fixtures (M2-02). CI wiring (M4-01).

## Implementation plan

- `tests/fixtures/laravel-routes/**` — synthetic app.
- `scripts/eval/score-routes.ts` — runs a scan into a temp dir, reads `mapx routes --json`, matches labels (method set match, `{id}` ≡ `{slug}`), prints per-pattern table or `--json`; optional `--min-recall`/`--max-fp` flags exit 1 below thresholds (used by M1-98).
- `tests/laravel-routes-fixture.test.ts` — asserts the scorer runs, labels are well-formed, and snapshots the baseline numbers (`it.fails` or explicit expected-baseline objects, not passing assertions on wrong behaviour).

Before editing, run `mapx_impact` (or `npx tsx src/main.ts impact <symbol>`) on the symbols you change and note the blast radius in the report.

3. The baseline numbers recorded in reports/M1-01.md reproduce the report's failure classes: uses-array handler recall 0, require-mounted prefix recall 0, ≥1 false positive on negatives.
