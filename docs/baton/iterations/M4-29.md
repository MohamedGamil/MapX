# M4-29 — The installer replaces a running mapx binary

## Identification

Milestone: M4; priority: P2; risk: low; estimate min/expected/max: 0.5/1/2 h; role: packaging engineer.

## Objective

An upgrade with `install.sh` (and the self-extracting installer that embeds it) succeeds while `mapx serve` processes run the old binary, and those processes keep working.

## Dependencies

None. Source: D037, whose install note records `./mapx-0.3.9-linux-x64-installer.sh --local --force` failing with "cp: cannot create regular file ~/.local/bin/mapx: Text file busy".

## Cause

`scripts/templates/install.sh` installs with `cp "$binary" "$PREFIX/mapx"`. `cp` opens the existing file for writing, and Linux refuses a write to an executable that a process is running (ETXTBSY).

## Scope

- `scripts/templates/install.sh`: write the binary to a temp file in the target folder (`mktemp "$PREFIX/.mapx.XXXXXX"`), `chmod 755` it, then `mv -f` it over `$PREFIX/mapx`. The rename is atomic within the folder; running processes keep the old inode. The temp file is removed when a step fails.
- `scripts/templates/install.ps1`: Windows refuses to overwrite or delete a running `.exe` but lets it be renamed. Move the old `mapx.exe` aside under a unique `mapx.exe.<id>.old` name, copy the new one in (moving the old one back if the copy fails), and remove the `.old` files that nothing runs any more (the next install removes the rest).
- `tests/installer-replace.test.ts`: a temp prefix holding a copy of the system `sleep` as `mapx`, running; `install.sh --prefix <tmp> --force` and a self-extracting installer built by `scripts/make-installer.sh sh` from a tiny archive.

## Out of scope

- Uninstalling while the binary runs (`rm -f` already works on Linux and macOS; Windows uninstall is unchanged).
- Bun-compiling a real binary; the test uses a copy of `sleep` (old) and a shell script (new).
- The PowerShell change cannot be run here (no `pwsh` on this machine).

## Implementation plan

1. Write the test; see it fail with "Text file busy".
2. Change install.sh; then install.ps1.
3. Mutation-check; run `npm run check`, the full vitest suite, `npx tsc --noEmit`, `npm run typecheck`.

## Expected outputs
