# M0-12-R11 — Svelte template names scoped per block; quoted handlers

## Identification

Milestone: M0; priority: P2; risk: low; estimate min/expected/max: 1/2/4 h; role: parsers. Source: review 2026-11-02 (`reviews/REVIEW-2026-11-02-b2558df592cf.md`, M0-12-R10 DEFECTIVE).

## Objective

Svelte template-local names hide references only inside their block, as in `.vue` templates, and quoted event handlers link.

## Dependencies

M0-12-R10 (hard, DONE). No approval gate.

## Scope

**Scoped template locals in `svelteTemplateReferences` (`src/parsers/languages/svelte.ts`).** Today `locals` is one set per file, so `{#each items as close}` hides `<button on:click={close}>` anywhere in the template. The template walk keeps a stack of scopes instead:
- a block (`{#each}`, `{#await}`, `{#if}`, `{#key}`, `{#snippet}`) opens a scope at its `{` and closes it at its `{/…}`;
- a branch (`{:else}`, `{:else if}`, `{:then}`, `{:catch}`) closes the current branch's scope and opens the next, so an each alias does not reach `{:else}` and a `{:then}` value does not reach `{:catch}`;
- an element that is neither void nor self-closing opens a scope that its closing tag closes; a block close also closes elements left open inside it (`<li>` without `</li>`);
- each aliases hide from their pattern on (the each source expression is read outside them, as a Vue `v-for` source is); `{:then}` / `{:catch}` values and snippet parameters from their header; `{@const}` names in their whole enclosing block; `let:` names in their element, attributes included; a snippet name in its parent scope, before its declaration too (snippets are hoisted).

A call is hidden when a binding of its name covers its offset. The ranges are computed during the walk and applied at the end.

**Quoted handlers.** A quoted attribute value that is exactly one `{…}` (`on:click="{close}"`, `onclick="{save}"`) is read like the unquoted `{…}`, so a handler named by itself is a call of it.

## Out of scope

- Calls in template literals, nested quotes or nested braces in quoted attributes: recorded M0-12-R10 limitations, not this task. (Destructuring keys were fixed after the independent review.)
- Default-imported functions and namespace member calls in templates (as in Vue).
