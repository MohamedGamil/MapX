# M7-02 — Documentation section built from docs/ with sidebar, search and link rewriting

## Identification

Milestone: M7; priority: P1; risk: low; estimate min/expected/max: 5/8/12 h; role: docs tooling.

## Objective

The 11 user-facing guides in `docs/` publish under `/docs/` with a sidebar, local search, "Edit this page" links and the package version. Links to repo files that are not published become GitHub URLs, and a link to a file that does not exist fails the build.

## Dependencies

M7-01 (hard, DONE).

## Scope

- **Guide metadata:** `GUIDES` in `scripts/site/sync-docs.ts` becomes a list of `{ name, label, group }`, in sidebar order. `docs/` stays the single source of truth; the allowlist stays explicit.
- **Link rewriting:** `rewriteLinks(markdown, guide, root, published)` (exported; it reads the repo to check targets). For each Markdown link outside code fences and inline code:
  - external, `#anchor` and `mailto:` links are left alone;
  - a link to another allowlisted guide (`x.md`, `./x.md`, with or without `#fragment`) is left alone;
  - an image under `./images/` is left alone (it is copied);
  - any other relative path is resolved against `docs/`: when the file exists and git tracks it (an ignored file has no GitHub page) it becomes `https://github.com/MohamedGamil/mapx/blob/main/<path>` (keeping the fragment); when it does not exist the sync throws with `docs/<guide>.md:<line>`.
  - reference-style definitions (`[x]: ../README.md`) are handled the same way;
  - fenced code, inline code and HTML comments are not links and are left untouched (the guides keep five commented-out diagram images).
- **Heading anchors:** the site uses GitHub's slugs (`githubSlug` in `site/.vitepress/base.ts`). Found by the crawl test: VitePress's default slugs differ for headings with an apostrophe, a slash or a plus sign, which broke 8 in-site links such as `#mapxs-own-rules`.
- **Config:** `ignoreDeadLinks` off; `themeConfig.sidebar` from `site/.vitepress/sidebar.ts` (generated from the same metadata, no second list); `search: { provider: 'local' }`; `editLink` pattern `https://github.com/MohamedGamil/mapx/edit/main/:path` (the generated index sets `editLink: false`); a nav entry `v<VERSION>` linking to the changelog on GitHub.
- **Sidebar footer:** the M7-01 CSS override gets its browser test.
- **Playwright for the site:** `playwright.site.config.ts` (own config, so `npm run test:ui` is unchanged) and a tiny static server over the built output under the base path. M7-06 reuses both.

## Out of scope

- Rewriting the guides' content. Only the nested-fence defect of M7-01 was edited in `docs/`.
