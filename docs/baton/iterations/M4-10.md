# M4-10 — Workers load only the grammars of the files they parse, once per thread

## Identification
Milestone M4; P1; risk medium; estimate 4/8/14 h; role: scanner, parsers. Decision D025.

## Objective
A parse worker loads a tree-sitter grammar only when it parses a file of that language. Each grammar file and each compiled query exists once per thread. Worker activity is measurable.

## Scope
1. **Drop the pre-warm.** `parse-worker.ts` drops `initLanguages()`, which pre-warmed all grammars. The fallback capture walk uses `wasm-parser.ts` `loadLanguage` and `compiledQuery`, the language parsers' own caches, instead of a second copy.
2. **Memoise `loadLanguage`.** `wasm-parser.ts` memoises `loadLanguage` per resolved grammar path, as a promise, so concurrent first uses share one load. `vue-ast.ts` and the TypeScript parser then share one TypeScript `Language`.
3. **Statistics.** `MAPX_WORKER_STATS=1` prints one stderr line per parallel run: workers started, files parsed per worker, grammars loaded per worker, hand-backs and the process's peak RSS. The workers report what they loaded.
4. **Bench.** `scripts/bench/workers.ts` generates a mixed-language workspace from synthetic code only (TS, PHP, Vue, Python, Go, Ruby). It runs the real CLI with and without `--no-parallel` and prints wall time, peak RSS and the statistics line, and checks that the two indexes are identical.

## Out of scope

- Sizing (M4-13).
- Distribution (M4-12).
- Batching (M4-14).
