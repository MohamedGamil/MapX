# M5-13 — Layer graph reporters: DOT, SVG, Mermaid and layer DSM

## Identification

Milestone: M5; priority: P2; risk: low; estimate min/expected/max: 4/6/8 h; role: CLI and visualisation engineer.

## Objective

`mapx arch graph --format dot|svg|mermaid|dsm|json` draws the layer graph of the architecture configuration (AR-16, Deptrac's `graphviz-*` and `mermaidjs` formatters): one node per layer, edges labelled with dependency counts, violations red, advisory (warn-level) violations orange, skipped (baselined) dependencies dashed, groups as subgraphs, hidden layers left out of the drawing but kept in the counts, and edges into a layer named like its group pointing at the group.

## Dependencies

- M5-04 (hard, DONE): the evaluator and the report's `layerEdges`.
- M5-05/M5-07 (interface, DONE): `mapx check`, its reporters and its index gate.
- M5-08 (interface, DONE): `openArchitecture` and the `mapx arch` subcommand helper.
- No approval gate.

## Scope

- **A library model, not only printing.** `src/arch/reporters/graph.ts`: `layerGraph(report, config)` builds a JSON-ready `LayerGraph` from the report `mapx check` builds (`buildReport`), so every count and status comes from the same decisions (`decideEdge`). M5-15 (dashboard) consumes it.
- **The report gains `layerEdges[].warnings`:** of a pair's violations, those reported at `warn` (advisory allowance, or inferred under `policy.inferred: "warn"`). Counted per pair, so a multi-layer source keeps each pair's own severity. Additive; schema updated.
- **Renderers:** `dot.ts`, `mermaid.ts`, `dsm.ts` (text matrix plus `layerDsm` data) and `svg.ts` (Graphviz when installed, else a built-in renderer: no runtime dependency).
- **Config:** `report.pointToGroups` (boolean), next to the existing `report.groups`, `report.hidden`, `layer.group`, `layer.color`.
- **Reuse:** DOT quoting exported from `src/exporters/dot-exporter.ts`; the `dot -Tsvg` call and XML escaping exported from `src/exporters/svg-exporter.ts`; the cluster DSM text printer of `mapx arch --dsm` extracted into `src/core/metrics.ts` (`formatDsmText`) and shared. Their output is unchanged (the M5-08 legacy golden of `mapx arch --dsm` guards it).
- **CLI:** `mapx arch graph` through the M5-08 `archQuestion` helper, with `-o/--output`, `--baseline`, `--no-graphviz`.
- **Docs:** `docs/cli-reference.md`, `docs/architecture-rules.md`.
