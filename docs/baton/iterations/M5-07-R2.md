# M5-07-R2 — CI reporters: baselines outside the repository and submodule workspaces

## Identification

Milestone: M5; priority: P3; risk: low; estimate min/expected/max: 1/2/3 h; role: architecture reporters.

## Objective

A finding located on a file outside the repository (a stale entry of `--baseline ../../outside/bl.json` from `repo/sub`, or a `--config` outside it) is reported in SARIF without a `..` URI that leaves `%SRCROOT%`, and the SARIF still validates. Decide whether a workspace inside a git submodule needs a superproject-relative prefix (M5-07-R1 limitations).

## Dependencies

M5-07-R1 (hard): `pathPrefix`, `repoPath`, `locate`. M4-30: the built CLI the reporter tests use. No approval gate.

## Scope

- **CI formats:** a location whose path from the repository root (or the workspace, outside git) leaves it (`..`, `../…`, or absolute) is replaced by the configuration file, at the line naming the baseline (else 1); the message names the file, and SARIF's `properties.outsideRoot` carries it (amended after review: GitHub requires a location on every result). Every other result is unchanged, so the goldens hold.
- **Decision on submodules:** recorded in the report, with a real-git test of what a workspace in a submodule gets.
- Docs: `docs/cli-reference.md` and `docs/architecture-rules.md` (CI formats).

## Out of scope

- GitHub annotations, CodeClimate and JUnit keep their relative paths (CodeClimate requires a path; an annotation on a file outside the checkout is shown unattached). Listed in the report.
- Messages shared with `table` and `json` stay workspace-relative.

## Implementation plan

- `src/arch/reporters/context.ts`: `outsideRoot(path)`.
- `src/arch/reporters/sarif.ts`: no physical location for such a path, the message and property.
- `tests/arch-reporters.test.ts`: a real repository with the workspace in `sub/` and the baseline in a folder outside the repository; the SARIF validates against the OASIS schema and has no URI with a `..` segment. The existing outside-workspace cases are updated to the new SARIF form.
