# M0-12-R5 — Fish shell grammar: functions and calls (D014)

## Identification

Milestone: M0; priority: P2; risk: medium; estimate min/expected/max: 2/4/6 h; role: language-registry and grammar maintainer.

## Objective

`.fish` files yield `function` symbols and call edges, from a bundled, licence-compatible tree-sitter fish grammar (D014, F20).

## Dependencies

M0-12-R4 (hard, DONE). Sources: `docs/baton/DECISIONS.md` (D014), `docs/baton/reports/M0-12-R3.md` (which made `.fish` a static, symbol-less language), `specs/features/F20-language-expansion.md`.

## Scope

1. **Grammar.** Build `wasm/tree-sitter-fish.wasm` from the upstream grammar `ram02z/tree-sitter-fish` at tag 3.7.0 (Unlicense) with the repo's own `tree-sitter-cli` 0.23.2 (`tree-sitter build --wasm`, emscripten in docker), and check it loads with the `web-tree-sitter` 0.26.9 in `node_modules`. `scripts/build-wasm.ts` learns to rebuild it from the pinned upstream tarball, since the grammar is not on npm.
2. **Queries.** `queries/fish/symbols.scm`: `function name … end` → `function`. `queries/fish/references.scm`: every command name is a call (command substitutions included); `source FILE` / `. FILE` is an import.
3. **Registry.** `fish` moves from `static` to `bundled` with the grammar, the queries and `nodeMappings.function = 'function_definition'`. Fish stays its own language (fish calls never resolve to bash or other languages).
4. **Docs.** README language table and feature line, `docs/adding-languages.md` (bundled list and grammar provenance).

## Out of scope

- Fish variables (`set`), abbreviations and `alias` as symbols: not asked for by D014.
- The "22 languages" counts in generated agent templates (`src/agents/templates.ts`) and the generated root files: M0-09-R4 is rewriting those templates in parallel; the count is left for the integration owner.

## Implementation plan

- `wasm/tree-sitter-fish.wasm` (new, built as above).
- `queries/fish/symbols.scm`, `queries/fish/references.scm` (new).
- `src/languages/registry.ts`: `fish` entry.
- `scripts/build-wasm.ts`: a `tarball` source for grammars not published to npm.
- `tests/legacy-languages.test.ts`: lang list/info report fish as bundled; e2e scan of a fish workspace (main-thread path); the existing 19-file worker fixture now expects fish symbols.
- `package.json` is listed as affected, but no npm package of the upstream grammar exists and the WASM is committed like every other grammar, so no dependency is added.

## Expected outputs

Files above and `docs/baton/reports/M0-12-R5.md` with the grammar licence, provenance and the package size before and after.

## Acceptance criteria

- A licence-compatible fish grammar is bundled (licence recorded in the report) and `mapx lang list` / `lang info fish` report it (test).
- `function deploy; build; end` in a `.fish` file gives `function:deploy` and a call edge deploy → build, also across files (e2e test).
- Package check passes and the dashboard/package size ceilings hold; the size added by the grammar is measured and reported.
- If no usable WASM grammar exists, the task records that with evidence and D014's fallback is documented instead.
