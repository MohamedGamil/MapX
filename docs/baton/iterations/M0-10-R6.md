# M0-10-R6 — Unknown --repo is an error; git sync counts indexed files

## Identification

Milestone: M0; priority: P2; risk: low; estimate min/expected/max: 1/2/4 h; role: CLI, MCP, incremental scanning.

## Objective

`mapx scan` and `mapx sync` with `--repo <name>` naming no registered repo fail with a message listing the registered repos; the MCP `mapx_scan` and `mapx_sync` tools report the same. A git sync reports the files it re-indexed, as the hash sync does, not every path git listed.

## Dependencies

M0-10-R5 (hard, DONE).

## Scope

- **`Scanner.reposToScan`:** throws `Unknown repo "<name>". Registered repos: <names>.` for a name not in the config. This is shared by `scanFull` and `scanIncremental`, so it reaches the CLI and MCP alike.
- **CLI (`src/main.ts`):** prints that error as `Error: …` with exit 1, as it does for the lock error, instead of a stack trace.
- **MCP:** already returns `Scan failed: …` / `Sync failed: …`.
- **Git sync's `filesScanned`:** `toReindex.length` instead of `changes.length`.

## Out of scope

The no-change paths: they already report 0.

## Acceptance criteria

1. `mapx scan --repo nope` and `mapx sync --repo nope` exit 1, and stderr names `nope` and the registered repos, with no stack trace; MCP `mapx_scan` and `mapx_sync` with `repo: "nope"` answer with the same message (`tests/workspace-default-scope.test.ts`).
2. A git sync of one edited file, with ten untracked noise files listed, reports `filesScanned` 1 (`tests/scan-redundancy.test.ts`).

## Verification

- `npx vitest run tests/workspace-default-scope.test.ts tests/scan-redundancy.test.ts`
- `npm run check`
