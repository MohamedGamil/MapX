# M1-07-R3 — Laravel route files mounted as arrays; loop and conditional prefix variables

## Identification

Milestone: M1; priority: P2; risk: low; estimate min/expected/max: 1/2/4 h; area: remediation (laravel).
Source: `docs/baton/reviews/REVIEW-2026-11-02-b2558df592cf.md` (finding 8, verdicts on M1-07-R2 and M1-03-R2).

## Objective

`->group([file, file])` mounts each file, as Laravel's `Router::group` does through `Arr::wrap`. A prefix variable bound by `foreach` or reassigned under a condition evaluates to `{dynamic}`, never to one definite and possibly wrong value.

## Dependencies

M1-07-R2 and M1-03-R2 (hard, both DONE). No approval gate.

## Reproduction (develop@28dc907)

- `Route::prefix('x')->group([base_path('routes/a.php'), base_path('routes/b.php')])`, in the RouteServiceProvider or in a route file: the walker skips a single array argument, as if it were a group's attribute array. Nothing is mounted, so `a.php` and `b.php` are reported unreachable. The legacy `Route::group($attributes, [a, b])` evaluates the whole array as one path and records it unresolved, which makes every unmounted file of the app `unknown`.
- `$p = 'v0'; foreach (['v1', 'v2'] as $p) { Route::prefix($p)->group(...); }`: the loop variable is not a binding, so the earlier `'v0'` is used. The mounted routes get the definite prefix `v0`.
- `$p = 'admin'; if ($x) { $p = 'staff'; } Route::prefix($p)->group(...)`: the last assignment before the call wins, so the prefix is a definite `staff`.

## Scope

- `laravel.ts`, `walkRouteFile`: when the routes argument of a group is an array literal, `->group([…])` or the legacy two-argument `Route::group($attributes, […])`, each element is mounted in order, as `Arr::wrap` loads them. The elements are evaluated like any mount path, each with its own sub-position, so a later file overrides an earlier one. An element that cannot be evaluated records the statement's line as unresolved, once per statement. Closure elements are group bodies: the files still mount, and the group is walked for the closures' routes. A literal spread is flattened. `static::f()` is a call, not a closure (review 2026-11-02).
- `laravel-mounts.ts`, `stringAssignments`:
  - each variable a `foreach (… as [$k =>] $v)` head binds (including `list()`/`[…]` destructuring and `&$v`) is unknown from the head to the end of its function;
  - an assignment under a condition or loop holds only until that block ends (the brace-less statement's end, or the closing brace of the innermost conditional block). After it, the variable is unknown. As in the walker, `if (! $this->app->routesAreCached())` is not a condition. Nor is a `do` body (review 2026-11-02);
  - a variable assigned anywhere in a loop body is unknown from the body's start, since the next pass sees it (review 2026-11-02).

## Out of scope

- Expanding a `foreach` over a literal array into one mount per value. The prefix is `{dynamic}` instead, and fixture label L150 is a placeholder until loops are expanded.
- Route domains as hosts (M2-06-R4).
