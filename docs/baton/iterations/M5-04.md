# M5-04 — Policy expansion and rule evaluator (handler chain, findings, fingerprints)

## Identification

Milestone M5; P1; risk medium; estimate 10/12/16 h; critical path. Sources: `docs/research/deptrac/02-abstract-feature-model.md` AR-05, AR-06, AR-07 (private selectors only), AR-08, AR-09, AR-12; `01-deptrac-capabilities.md` §4.

## Objective

Given a loaded `ArchitectureConfig` and a scanned index, produce an `ArchReport` (AR-09):
- violations of the expanded allow policy;
- private-layer violations;
- uncovered targets;
- `allowed` records;
- multi-layer and empty-layer warnings;
- configuration errors;
- stable fingerprints and the layer-to-layer matrix.

## Scope

1. **`src/arch/policy.ts`:** `expandPolicy(config)` gives, per non-overlay source layer, the allowed target layers. Each allowed target carries its severity and an optional edge-type scope.
   - **Forms:** `"L"`, `"+L"` (L's own allowances, transitively), `"!L"` (deny), `"*"` (every non-overlay layer), and the objects `{allow:[…], severity?, types?}` and `{to, types?, severity?}`.
   - **Defaults key:** `"*"` as a key is merged into every source layer.
   - **Precedence:** `!` > explicit > `+` > `*`.
   - **Errors:** an unknown layer, or an overlay used as a source, is reported as a configuration error. The loader already rejects both; this is defence in depth.
2. **`src/arch/evaluate.ts`:** `evaluate(store, dir, config, options)` reads the stored edges and maps each end to its finest element. An end is the symbol named by `source_symbol`/`target_symbol` when it resolves in that file (exact qualified name, then `Scope::name`/`Scope.name`, then a unique name); otherwise it is the file element.
   - **Out of scope:** the edge type is not in `scope.types`, either end's path is excluded by `scope.include`/`scope.exclude`, or the edge is inferred under `policy.inferred: "ignore"`. Self-edges are out of scope too.
   - **Then, once per non-overlay source layer (AR-12):** the source in no layer → ignored (no finding).
   - **Uncovered:** the target is in no non-overlay layer → `uncovered` (rule `uncovered`).
   - **Same layer:** the source layer is among the target's layers → nothing.
   - **`disallowed-layer`:** no target layer is allowed for this edge type, or one is denied.
   - **`internal-element`:** not evaluated; doc tags arrive with M5-10.
   - **`private-layer`:** the target is private to a layer other than the source layer.
   - **Otherwise:** `allowed`.
   - **`private-layer` and M5-11:** this step is AR-08's, and M5-04's objective names it. M5-11 keeps internal markers, native markers and their fixture rows.
   - **Severity:** `error`, or the allowance's severity. Inferred edges are `warn` under the default `policy.inferred: "warn"`; `"error"` keeps their severity.
3. **`src/arch/report.ts`:** `buildReport(...)` gives the AR-09 `ArchReport`:
   - **`counts`;**
   - **`findings`:** sorted deterministically;
   - **`layers`:** elements and files per layer;
   - **`layerEdges`:** from, to, allowed, violations, skipped;
   - **`configErrors`;**
   - **warnings:** `multi-layer` (one per top-level symbol, or symbol-less file, in more than one non-overlay layer; an error under `strictLayers`) and `empty-layer`;
   - **error findings:** the loader's `+` cycle errors, as `error` findings with rule `plus-cycle` and the layer;
   - **dependency findings:** one per (kind, rule, source element, target element, edge type), naming every source layer it applies to, counting the edges it covers (one per source layer before the review of M5-04). `fingerprint` = sha256(rule, source element, target element, edge type), first 16 hex characters, with no line number.
   - **Element granularity of a finding:**
     - lifted to top-level declarations: a method's dependency is its class's, and a file-level import belongs to the file's only top-level symbol;
     - the target of an `http` or `route` edge stays the handler method;
     - a Go import names a package, so its target is the package (named by its import path, with the union of its directory's layers). It is dropped when a finer finding from the same source of the same kind and rule reaches a type of that package.
   - **`runArchitecture(dir, store?, options)`:** loads the config, evaluates, and returns the report. M5-05's `mapx check` will call it.
4. **`scripts/eval/score-arch.ts`:** when the CLI has no `check` command yet, build the report in-process with `runArchitecture` on the scanned temp copy. The registered scorer command then measures M5-04 before M5-05 exists.
5. **Tests:** `tests/arch-evaluate.test.ts`; `tests/arch-fixture.test.ts` (its 0.0-baseline test becomes the real score).
6. **Fixture correction:** the workspace app's `backend/routes/api.php` imports `Api\OrderController`. That is Backend → PublicApi, which the app's own rules forbid (`Backend: []`), but M5-01 left it unlabelled. It is added as row `workspace-03`, with a note. The configuration and the other rows are unchanged.

## Acceptance criteria

1. **Fixture score (task criterion: violation and allowed recall/precision 1.0, excluding baseline, visibility, external and decorator rows owned by later tasks):** `npx tsx scripts/eval/score-arch.ts tests/fixtures/arch-rules --json` must give:
   - **Misses:** exactly the rows later tasks own: `skipped` and `stale-baseline` (M5-06), and `internal-element` (doc tags, M5-10/M5-11);
   - **No hits on negatives:** no finding on any `allowed`/`none` row;
   - **`uncovered` and `warning`:** recall and precision 1.0;
   - **`violation`:** precision exact except one finding, php-07, the dependency the baseline will skip in M5-06.

   `tests/arch-fixture.test.ts` asserts this.
2. **Line-stable fingerprints:** blank lines inserted at the top of every PHP fixture file, then `mapx sync`, leave the set of fingerprints unchanged.
3. **Inferred edges:** an inferred edge across a disallowed pair is `warn` under the default policy, `error` under `policy.inferred: "error"`, and absent under `"ignore"`.
4. **Policy expansion:** `+` is transitive (A: `+B`, B: `+C`, C: `D` → A allows B, C and D). `*` allows every non-overlay layer. `!` beats `*` and `+`. `"*"` as a key merges defaults. A `types`-scoped allowance allows only those edge types. A `severity: "warn"` allowance downgrades to warn. Each has its own unit test.
5. **Matrix and multi-layer:** `layerEdges` counts allowed and violating dependencies per layer pair on the PHP fixture. An element in two layers is evaluated once per source layer.
