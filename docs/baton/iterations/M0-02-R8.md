# M0-02-R8 — Sync re-links referrers of renamed or removed symbols, and re-resolves after manifest changes

## Identification

Milestone: M0; priority: P2; risk: medium; estimate 3/5/8 h; role: scanner / incremental indexing.
Sources: the last independent review round of the 2026-10-31 remediation (reviewer L), recorded in `docs/baton/reports/M0-02-R7.md`, `M0-17-R4.md` and `M0-11-R3.md`.

## Objective

After a sync, the referrers of a symbol renamed or removed in a changed file, and files whose resolution depends on a changed `package.json` or config, have the edges `scan --force` gives. `mapx status` reports an edit git does not list.

## Dependencies

M0-02-R7 and M0-17-R4 (hard), both DONE.

## Scope

- **Renamed or removed symbols** (`removedSymbolReferrers`). Before a changed file is re-parsed, its stored symbol names are compared with its new text. Unchanged files whose edges target a name the text no longer holds are re-parsed with it. This runs in the full, git and hash paths, for tracked and gitignored files.
- **Resolution configs** (`configReferrers`).
  - `meta js_configs:<repo>` keeps a signature of `package.json`, `tsconfig.json`, `jsconfig.json` and the bundler configs in every folder above an indexed JS/TS/Vue/Svelte file.
  - When a signature changes, the files below that folder are re-parsed.
  - The record is refreshed after every scan or sync run, and git sync checks it before its early return (an untracked config that is deleted is in no diff).
- **Status** (`indexableChanges`). Indexed files edited since the scan that git does not list (gitignored) are added as modified, through `findStaleFiles`. This covers the CLI, MCP and the dashboard.

## Out of scope

- Calls resolved by name instead of through the file's named import (pre-existing).
- `node_modules` contents changing.

## Acceptance criteria

1. Renaming `alpha` to `alphb` in a changed file drops `usea.js → a.js#alpha`, so sync equals `scan --force`, for a tracked and a gitignored `a.js` (`tests/legacy-globs.test.ts`).
2. Adding `axios` to `package.json` makes `axios.create()` stop linking the project `create`, so sync equals `scan --force` (same file).
3. `mapx status` lists `~ gen/x.ts` after an edit to a gitignored indexed file (same file).
