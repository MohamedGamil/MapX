# M0-12-R10 — Svelte templates: calls, event handlers and child components

Date: 2026-11-01. Base: `develop@33c7cb4`. Owner: claude. Iteration: `docs/baton/iterations/M0-12-R10.md`.

## Delivered

### `svelteTemplateReferences` (`src/parsers/languages/svelte.ts`)

It reads the template with the scripts, `<style>`, comments and `<svelte:head>` scripts blanked, and returns call and render references carrying the Vue resolution hint.

Calls come from:
- `{expr}` blocks;
- block headers: `{#if}`, `{:else if}`, `{#each}`, `{#await}`, `{#key}`, `{@const}`, `{@render}`;
- attribute values;
- `use:`/`transition:`/`in:`/`out:`/`animate:` directives.

A handler named by itself (`on:click={save}`, or Svelte 5 `onclick={save}` for a DOM event) is a call of it.

Never resolved: each-block aliases, `let:` names, `{@const}` names, `{:then}`/`{:catch}` values and snippets. `{@html}` and `{@debug}` are skipped.

Renders come from capitalised and dotted tags, and from `<svelte:component this={X}>`.

### Scanner render branch (`src/core/scanner.ts`)

- It accepts `.svelte` targets (`COMPONENT_FILE`).
- A non-default import that resolves to a barrel is followed with `moduleMember`, or `defaultReExport` for `export { default as X } from './X.svelte'`. That applies to Vue too: a Vue tag imported from a non-`.vue` barrel now gets its render edge (tested).

### Docs

`README.md` and `docs/getting-started.md` describe what Svelte templates now give.

## Independent review

One fresh agent reviewed the change in its own copy. It confirmed that these forms work:
- `{:else if}`, destructured each items with an index and key, `{#await}`/`{:then}`/`{:catch}`;
- snippets, `let:`, spread, `class:` and `style:`;
- event modifiers, `bind:this`, event forwarding, `<svelte:window>`;
- `<` and `>` inside expressions;
- closing and lowercase dotted tags, aliased imports, line numbers.

Findings:
- **P1:** an escaped quote inside `{…}` made the brace matcher swallow the rest of the template, which revived `{@html}` calls and resolved aliases. Fixed with escape-aware string skipping, and tested.
- **P2s fixed and tested:**
  - block words dropped from call names;
  - `online={…}` taken for a handler;
  - transitions and `<svelte:component>` missed;
  - a renamed default re-export not followed;
  - a quadratic `lineAt` (8,000-line template: 8.8 s);
  - the untested Vue barrel change.
- **P2s recorded as limitations,** below.

## Limitations

- **Template locals are template-wide.** An each alias `t` hides a `{t('…')}` call anywhere in the same template, and a destructuring key such as `name: label` counts `name`.
- **Not read:**
  - calls inside template literals in an expression;
  - a quoted attribute holding nested quotes or nested braces;
  - default-imported functions and namespace member calls (`{utils.fmt()}`), as in Vue templates.
