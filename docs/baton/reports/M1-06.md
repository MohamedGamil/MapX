# M1-06 — Resolve local string variables in route paths

Date: 2026-10-30. Delivered together with M1-02 … M1-09 as one detector rework (`src/frameworks/detectors/laravel.ts`, the new `laravel-mounts.ts`, and the scanner's route pass). This report covers this task's part.

## Delivered

Route URIs are evaluated as PHP from the raw argument: literals, concatenation and string variables assigned earlier in the file (`stringAssignments` + `varsAt`). An expression that can't be resolved gives `{dynamic}` in the path and `metadata.dynamic = true`, instead of raw PHP text.

## Acceptance

1. $base = 'notices'; Route::get($base.'/x', …) yields /notices/x.
2. An unresolvable dynamic path is emitted with metadata.dynamic = true instead of the raw PHP text.
3. The M1-01 scorer shows no regression in any other pattern.

All are met. They are covered by `tests/laravel-mounts.test.ts` (end-to-end scans through the real CLI) and by the M1-01 fixture, now with floors at 100% and exact parameter names.
