# M0-18-R1 — TSX anonymous default class method scope

Date: 2026-10-31. P2 from the M0-41 legacy audit (I18).

## Fixed

`generic-wasm-parser.ts`: when a default-exported anonymous class, function or arrow is named after its file, that name is also recorded against its node (`nameByNodeId`). Members are then scoped to it. Before, `export default class { go() {} }` in `AnonClass.tsx` produced `go` with scope `null`.

## Evidence

| Command | Exit | Result |
| --- | ---: | --- |
| `npx vitest run tests/legacy-tsx.test.ts` | 0 | 1 passed: `go` and `stop` scoped `AnonClass`; a named default class still scopes to its name |
| Mutation: do not record the derived name | 1 | caught |
| `npx vitest run` | 0 | full suite green |

The other I18 finding (untracked new files missed by `sync`) was fixed in M0-11-R1.
