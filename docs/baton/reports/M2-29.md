# M2-29 report: Laravel migrations, seeders, factories and views are indexed by default

## Cause

This was an owner decision (D043, 2026-11-05). Since M2-23, migrations, seeders, factories and Blade views give edges when they are indexed. `LARAVEL_DEFAULT_EXCLUDES` still left them out of every Laravel repo, and `mapx init`'s Laravel suggestion wrote them into `excludePatterns`. As a result, the `laravel` preset's Database and Views layers were empty unless the user opted in.

## Delivered

- **Defaults (`src/core/config.ts`):** `LARAVEL_DEFAULT_EXCLUDES` is now `storage/**`, `bootstrap/cache/**`, `public/**` and `vendor/**`. `database/migrations/**`, `database/seeders/**`, `database/factories/**`, `resources/views/**` and `**/*.blade.php` move to `LARAVEL_FORMER_DEFAULT_EXCLUDES`.
- **Init (`src/cli.ts`):** `mapx init`'s Laravel suggestion lists the four remaining patterns, and says that `database/` and the views are indexed.
- **Config report (`src/core/config-report.ts`):** it still labels the former defaults `default` when an earlier init wrote them into `excludePatterns`.
- **Existing indexes:** an index built with the old defaults picks up the files on its next `scan` or `sync`. The effective excludes are part of `meta scan_filters:<repo>` (M0-02-R1), so the change takes the full-scan path once. The result equals `scan --force`, under both git and hash sync (test).
- **Docs:** `docs/configuration.md`, `docs/architecture-rules.md` and `docs/framework-integration.md`, plus the root CHANGELOG under Unreleased.

## Independent review

None. This is a small change to a default list made on an owner decision; the integration owner reviewed it. Every reader of `LARAVEL_DEFAULT_EXCLUDES` was checked: `effectiveExcludesFor`, `Config.init`, the config report and init's prompt text.

## Limitations

- A `.mapx/config.json` written by an earlier `mapx init` lists the former defaults in `excludePatterns` and keeps them excluded. MapX does not rewrite a user's config. The docs and the CHANGELOG say to remove those patterns.
