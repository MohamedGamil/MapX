# M0-05-R1 — Persist reference metadata and route edge verifiability

Date: 2026-10-31. P0 from the M0-41 legacy audit (I05 was FALSELY COMPLETE).

## Fixed

- **`src/core/scanner.ts`:**
  - Reference edges now keep the parser's `ref.metadata`, plus `startLine`. Before, the scanner replaced it with `{ startLine }`, so every relationship type and method, binding type and phase, concrete class, facade alias and dispatch detail was lost.
  - Route edges take verifiability from the route's confidence (`declared` → `verified`) and keep `resourceType`. Before, every route edge was hard-coded `inferred`, so `metrics --verified-only` removed every Laravel route.
- **`src/frameworks/detectors/laravel.ts`:** routes whose handler is a class constant (`[C::class, 'm']`, `Route::resource('x', C::class)`) are `declared`. String handlers (`'C@m'`) stay `inferred`.
- **`src/parsers/languages/php.ts`:** a binding's `concreteClass` is set only when the argument names a class (a class constant or a string). A closure or factory gives `null`; before, it gave the closure's source text.
