# M2-03-R1 — Fix HTTP extraction defects found in the M2 review

Date: 2026-10-30. Post-acceptance defects of M2-03, found by an independent review of M2-03 … M2-06. Each one was reproduced by the reviewer, then by a new regression test here.

## Fixed

| Severity | Defect | Fix |
| --- | --- | --- |
| P0 | Records of deleted files stayed in `http-calls.json` forever: `replaceFiles` only dropped files still listed for the repo | `HttpCallRegistry.dropMissing(existing)`: before replacing a repo's records, records whose file the store no longer has are dropped (`scanner.ts` `scanHttpCalls`) |
| P1 | `window.axios = require('axios')` (Laravel's bootstrap.js) and `const x = require('axios')` were not clients | `collectProviders` sets `globalAxios` when any file assigns `window`/`globalThis.axios`, so bare `axios` (and `window.axios`) become receivers everywhere; `require('axios')` bindings are receivers |
| P1 | Calls inside comments or strings were extracted | Calls are searched in a **masked** copy of the source (`maskCode`): comments and string, template and regex-literal bodies are replaced by spaces of the same length, so indices and lines are unchanged. For `.vue`/`.svelte`, everything outside `<script>` is masked too (`maskSource`) |
| P1 | A quote in an argument comment or a regex literal dropped the call | `callArguments` takes its bracket bounds and top-level commas from the masked source, and its text from the original (comments stripped) |
| P2 | `async fetch(id) {}`, `function fetch()` and class methods named `fetch` were recorded as calls | A `fetch(` preceded by `function`/`async`/`get`/`set`, or followed by `{`, `=>` or a typed body, is a definition |

## Limitations

- Regex-literal detection is heuristic (it decides from the preceding token); a division directly after `)` stays division.
- `import` statements are still read from raw source, so a commented-out `import axios` counts.
