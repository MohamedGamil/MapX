# M0-12-R6 — Language count after fish (23) in templates and docs; lang list flags missing grammars

Date: 2026-10-31. Found by M0-12-R5: the language counts still said 22 after fish was bundled, and `mapx lang list` said "bundled" even when a grammar's WASM file was missing.

## Delivered

| Acceptance criterion | Change | Proof |
| --- | --- | --- |
| Every language count in templates, README and docs is derived from or matches the registry (23); a test fails if a hard-coded count disagrees | `registry.ts`: `supportedLanguageCount()` counts every language with a grammar, with TSX counted as TypeScript and static file types (Markdown, HTML, …) excluded. Today that is 23. `src/agents/templates.ts` interpolates it (`${LANGUAGE_COUNT}`) in all 11 places that said 22. The four `docs/research/deptrac/*.md` files say 23. The `docs/configuration.md` tier table matches the registry's tiers: built-in PHP, JavaScript, TypeScript, Python, Go, Rust, Java, C# (8); bundled Ruby … Fish, Pascal (15). It previously said built-in 4 / bundled 19, with Vue built-in and Python, Go, Rust, Java and C# bundled. README and the other docs already said 23 (M0-12-R5). | `tests/legacy-languages.test.ts` "language counts match the registry (M0-12-R6)" has three parts. First, the count is 23. Second, for README, `src/agents.stub.md`, every `docs/**/*.md` outside `docs/baton/` and every template, each "N languages" / "N supported languages" equals the registry count ("Tier 1 languages" is skipped). Third, each configuration-table row's count equals its listed names and the registry's tier size. `tests/legacy-agent-templates.test.ts` "states the registry language count in generated files" covers real `mapx agents generate` output: `CLAUDE.md` and `AIDER.md` say `across **23 languages**`, and `.zed/mapx-instructions.md` says `(23 languages,`. |
| `mapx lang list` and `mapx_lang_list` report a grammar whose WASM file is missing as missing, not bundled | `installer.ts`: `isLanguageInstalled` now also requires a grammar language's WASM file to exist; static types need none. `formatLanguageList`, shared by the CLI and MCP, prints `status: missing` for such a language. Its header then reads `Supported languages (1 grammar file is missing; reinstall MapX):` (plural for several). The old `unavailable` status, which could never appear, is gone. | `tests/legacy-languages.test.ts` "reports a grammar whose WASM file is missing as missing, in both". The real CLI runs with a preload fixture (`tests/fixtures/languages/hide-grammar.mjs`, via `NODE_OPTIONS`) that makes `tree-sitter-fish.wasm` look missing. It prints `- fish (.fish \| tier: bundled \| status: missing)` while bash stays `bundled`, under the new header. The in-memory MCP server, with the same fixture applied in-process, returns exactly the CLI text. After restoring, MCP reports fish as bundled again. |

The fixture patches `fs.existsSync` and calls `syncBuiltinESMExports`, so the `import { existsSync } from 'node:fs'` bindings in the source see the patch. Nothing on disk is deleted. `tests/helpers/e2e.ts` gains `mapxEnv(cwd, env, ...args)` to pass `NODE_OPTIONS` to the CLI.

## Limitations

- The generated root files (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `AIDER.md`, `.clinerules`, `.github/copilot-instructions.md`, `.windsurf/rules/mapx.md`, `.zed/mapx-instructions.md`) still say 22. Per the owner's instruction they are left for regeneration with `mapx agents`, which now writes 23.
- `ROADMAP.md` ("all 20 languages", a checked-off historical item) and the `docs/baton/` records are not checked, because they quote counts as they were.
- The docs check catches counts written as "N languages" / "N supported languages". Other phrasings, such as "twenty-three" or a count in a table cell other than the configuration tier table, are not covered.
- "33 MCP tools" counts are out of scope.
- The missing-grammar status is proven by hiding the file through the fixture. A real broken install, with the file actually deleted, goes through the same `existsSync` check; M0-12-R5's mutation M5 deleted the file and showed `lang info` reporting `(missing!)`.

Changelog: `mapx lang list` and `mapx_lang_list` now report a language whose grammar file is missing as missing, and generated agent files state the language count from the registry (23) (M0-12-R6).
