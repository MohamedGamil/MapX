# M2-05 — Base URL resolution

Date: 2026-10-30. Delivered together with M2-04 as one URL evaluator, `src/frameworks/http/url-resolver.ts`, which the scanner's `scanHttpCalls` uses to fill `url` on every D008 record.

## Delivered

**M2-05 (this task):** base expressions go through the same evaluator, plus `process.env.X` / `import.meta.env.X`.
- **Env values** come from `.env.local`, `.env.development.local`, `.env.development`, `.env` and `.env.production` (`envCandidates`), searched from the directory of the file defining the client up to the workspace root, nearest first. They are parsed by `parseDotenv` and read from disk with a cache, since dotenv files are not indexed.
- **Joining:** `joinURL` follows axios `combineURLs`: an absolute request URL wins, and one `/` joins base and path. `fetch` has no base.
- **Unresolvable base:** `url` is left relative and `baseURLUnresolved: true` is set, for M2-06.
