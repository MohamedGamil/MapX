# M0-03-R2 — Metrics and edges surface

Date: 2026-10-31. Decomposed from the M0-03-R1 epic per D010 ("implement everything"). Source: docs/baton/reviews/REVIEW-2026-10-30-legacy-audit.md.

## Delivered

- **`mapx metrics --format json --top N`:**
  - `rankMetrics` (`src/core/metrics.ts`) ranks by total degree (Ca + Ce), then PageRank, then path. Each entry adds `totalDegree` and `pagerank`, taken from the graph's ranked files.
  - JSON output is always ranked this way; `--top` also ranks the text table. Without `--top`, the text table keeps its instability order.
  - `mapx_metrics` takes `format` and `top`.
- **`mapx edges <file>`:**
  - The positional argument is now a file. A directory is still taken as the target directory, so existing calls keep working.
  - Absolute paths are relativised to the workspace (`indexedPath`).
  - `--direction outgoing|incoming|both`; `--type` accepts a comma list (`IN (…)`); `--verified-only`; `--format json`, with the `EdgeView` shape from `src/core/edge-view.ts`.
  - JSON output skips the staleness banner, so stdout stays valid JSON.
  - `store.queryEdges` gained `file`, `direction`, `verifiedOnly` and a type list, plus a stable order.
- **`mapx_edges`:** JSON by default (`format: "text"` for the old listing); takes `file`, `direction` and `verifiedOnly`.
- **Help and stub:**
  - `mapx status --help` ends with a pointer to `mapx metrics`.
  - `src/agents.stub.md` lists all 32 MCP tools (it listed 5), plus `edges` and `metrics` examples and the JS kinds from M0-17-R1.

## Limitations

- `--direction` only applies with a file argument; `--from` / `--to` stay substring filters.
- PageRank values are the graph's file scores (all repos), not recomputed under `--verified-only`.
