# M4-28-R2 report — `mapx_status` honours its exclude and include parameters

Base: develop@ec44845, on top of M4-28-R1 (c8c4321). Changed: `src/core/staleness.ts` (`filterChanges`), `src/cli.ts` (`mapx status`), `src/mcp.ts` (`mapx_status`), `docs/cli-reference.md` and `docs/mcp-integration.md`. New: `tests/mcp-status-filters.test.ts`.

## Delivered, per acceptance criterion

**AC1 — `mapx_status` with `exclude: ["src/**"]` reports no changed file under src/ while one exists. Met.**
- The test uses a git workspace scanned with the real CLI: `src/a.ts` and `lib/b.ts` are edited after the scan, and `src/new.ts` is added.
  - Without patterns, `mapx_status` lists `lib/b.ts`, `src/a.ts` and `src/new.ts` ("3 changed files").
  - With `exclude: ["src/**"]` it lists only `lib/b.ts` ("1 changed files"). The comma-separated string form (`"src/**, docs/**"`) does the same.
  - `include: ["src/**"]` keeps only the two src files. With `include: "src/**"` and `exclude: "src/new.ts"`, only `src/a.ts` is kept: an exclude wins.
  - When the patterns leave no changed file, the result says "No changes since last scan (✓ index is current)".
  - Test: `tests/mcp-status-filters.test.ts`, 4 tests.
- **How:**
  - `mapx_status` now lists the changed files under its git status, one `+`/`~`/`-`/`>` line each, as `mapx status` does. Before, it gave only a count, so the two could not be compared.
  - The schema declares `exclude` and `include` as string arrays; a comma-separated string still works. This follows `mapx_edges` `type`.

**AC2 — equals the CLI with the same option. Met.**
- `mapx status --exclude/--include` now narrows the changed files it lists, as M4-28 found it did not; before, it only printed the patterns.
- Both use one helper, `filterChanges` in src/core/staleness.ts. It applies `buildPathFilter` (the export-time matcher) to each change's workspace path.
- Each test case compares the files `mapx_status` lists with those the CLI lists for the same patterns: none, `--exclude 'src/**'`, `--include 'src/**'`, include plus exclude, and two excludes.
