# M2-02 — Vue 2.7 and Vue 3 HTTP client fixture with labels

Date: 2026-10-30. Fixture, labels and scorer only; no `src/` change. Contract: D008 (`.mapx/http-calls.json`).

## Delivered

- **`tests/fixtures/vue-http/`:** two synthetic front ends (all code invented).
  - `vue2/` (Vue 2.7): `.env` `VUE_APP_ROOT_API=/api`; an `Api()` factory around `axios.create`; a service object using `Api()` and an alias `const api = Api()`; an imported constant and a template literal; a split-line argument; a conditional URL; an Options-API SFC calling `axios.get` directly and through a local constant; a Vuex module whose actions call `Api()`.
  - `vue3/` (Vue 3): `.env` `VITE_API_URL=/api`; an exported `axios.create` instance; `fetch` with and without a method option; a `<script setup>` SFC using a project wrapper (`apiService`) that MapX can only recognise through configuration (`http-config.json`, merged into `.mapx/config.json` settings by the scorer).
- **`labels.json`:** 32 labels over 15 patterns. 29 expect a pairing with a live route of `tests/fixtures/laravel-routes`, including the overridden `GET /api/dup` (which must pair with the winner). 3 expect no route: two unserved URLs, and the unmounted `GET /ghost`.
- **`scripts/eval/score-http.ts`:**
  - composes a parent-folder workspace (`backend/` = Laravel fixture, `frontend-vue2/`, `frontend-vue3/`), runs the real `init` + `scan`, and reads `.mapx/http-calls.json`;
  - matches a label to a record by file, method and line (±2), preferring an equal URL;
  - reports per pattern: found, URL resolved, paired correctly, unmatched correctly, wrong pairs;
  - totals: call-site recall, URL recall, pairing recall, pairing precision;
  - flags: `--json`, `--min-recall` (pairing), `--min-precision`.
- **`tests/http-pairing-fixture.test.ts` (10 tests):**
  - label coverage, every label pointing at its marked line, and every expected route being live in the Laravel labels;
  - scorer unit tests (normalisation, `{id}` ≡ `{slug}`, wrong pairs on null labels, file/method/line matching, empty records);
  - a real-scan floor test.

## Limitations

- Vuex dispatch-by-name (`services[payload.service](...)`, report item 12) is not labelled, because it cannot be resolved statically without runtime data.
- Labels pin the line of the call expression; a multi-line call is labelled at the line where the call starts.
