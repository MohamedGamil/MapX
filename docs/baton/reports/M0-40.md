# M0-40 — Type-check tests and scripts

Date: 2026-10-30. Resolves risk R04 (D009).

## Delivered

- `tsconfig.check.json` extends `tsconfig.json` and covers `src/`, `tests/` and `scripts/` with Node and vitest global types. It excludes `tests/fixtures/`, whose files are inputs for scanning, not project code. `tsconfig.json`, which the build uses, is unchanged.
- `npm run typecheck` is now `tsc -p tsconfig.check.json`, and the CI type-check job runs `npm run typecheck`.
- Fixed the 19 errors this exposed in 9 test files:
  - **A real test bug:** `tests/store.test.ts` passed `size_bytes` to `upsertFile`, which expects `sizeBytes`, so the stored size was `undefined`; it also omitted required fields. It now passes the proper fields.
  - **Incomplete `upsertFile` inputs** in `store-coverage` and `cli-coverage` tests: the required fields are added.
  - **Mock shapes:** `process.stderr.write` mocks return `true`; MCP `MockTransport` and `discoverFiles` mocks are cast explicitly; mock symbols carry `signature`/`metadata`; access to the private `parallel` field is cast.
  - **Implicit `any` callback parameters** are typed.
  - **`DiscoveredFile`** is exported from `src/core/scanner.ts` (a type-only change) so tests can name it.
