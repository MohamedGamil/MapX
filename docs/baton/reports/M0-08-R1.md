# M0-08-R1 — Clusters, cluster export and trace defects

Date: 2026-10-31. P1 from the M0-41 legacy audit (I08).

## Fixed

- **Leiden merged two cliques joined by one edge.**
  - Root cause: `buildGraph` skipped self-loops, so aggregation threw away each community's internal weight. At the next level, two meta-nodes joined by a single edge always gained from merging.
  - Self-loops now count in degrees and total weight, and aggregation carries them over.
  - The local-moving gain now compares a move against staying put: the node is removed from its community first, and staying wins ties. Before, any positive gain moved the node.
  - Refinement merges only singletons. Node order is fixed instead of `Math.random()`, so the same graph gives the same communities.
- **`--depth 0` behaved like `--depth 1`.**
  - `export --format dot --cluster auto --depth 0` now renders the F15 cluster-level view: one `folder` node per cluster, labelled with its file count.
  - It emits one edge per cluster pair, labelled `N edges (types)`, with `penwidth = min(5, log(N) + 1)`.
  - A cluster with no files of its own stands for its children, so the PHP `App` namespace shows as `App / Models`, `App / Services`, … as in the spec example.
  - Files outside any cluster are left out of this view.
- **Class-level trace returned 0 edges.**
  - Edge source symbols are `Scanner::scanFull`, while the matcher only accepted exactly `Scanner`. A container symbol now also matches `X::member` and `X.member`.
  - The trace's edge count was per file pair while its node count was per symbol, so every same-file call collapsed into one edge. It is now per symbol. On a self-scan of `src/`, `trace Scanner --direction down` goes from 1 node and 0 edges to 133 nodes and 132 edges.
- **Fallback SVG drew dispatch and notify like imports** (they had no style entry).
  - Dispatch is now bold magenta (stroke-width 2) and notify is dotted pink (`1,3`).
  - The fallback follows the DOT convention from M0-01-R1: only inferred edges are dashed (`5,5`). Verified implements and binding become solid, and call, instantiation, middleware and render dotted.
  - **Deviation from F12** ("dispatch dashed"): as in M0-01-R1, F01's meaning of dashed (inferred) takes precedence.
- **Empty PHP directory clusters (`app.Models [0 files]`).**
  - Directory clusters were created from every file, but namespaced files are always claimed by namespace clusters first.
  - Directory clusters are now built only from files without a namespace.
- **Found while testing: fresh parallel scans lost every PHP namespace.**
  - The scanner's worker message handler copied symbols, references and errors, but dropped `fileMetadata`. That field carries the namespace.
  - Any first scan of more than 10 files therefore had no namespace clusters. A second scan of the same files kept the stored value, which hid the bug in manual probes.
  - This is a leftover of M0-06-R1, whose worker test compared edges and roles but not file metadata.

## Limitations

- The cluster-level view is DOT; SVG gets it through Graphviz. The fallback grid SVG still draws file cards inside cluster cards; a cluster-only fallback layout is not implemented.
- Member matching is by name prefix (`X::`, `X.`). A function `foo` with an unrelated `foo.bar` edge symbol would also match; no such case was seen in the scanned sources.
