## Delivered

**`src/arch/policy.ts`: `expandPolicy(config)` and `decide(policy, source, target, edgeType)`**
- **Forms:** `L`, `+L` (transitive), `!L`, `*`, a `"*"` defaults key, `{allow|to, types?, severity?}`.
- **Precedence:** `!` > explicit > `+` > `*`. For one target, only the strongest form's grants count.
- **Inheritance through `+`:** inherited grants keep the `+`'s edge-type scope (intersected) and advisory severity.
- **`severity: "warn"`:** the pair is advisory, so its dependencies are reported as warn-level violations.
- **Defence in depth:** unknown layers and overlay sources are reported as configuration errors.

**`src/arch/evaluate.ts`: `evaluateEdges`, `endResolver`, `reportElement`**
- **Edges in:** every stored edge in `scope.types` that passes `scope.include`/`exclude` and the verifiability policy.
- **End resolution:** each end maps to its finest element, trying in order:
  - the exact qualified name;
  - `Scope::name`, `Scope.name`, `Scope#name` or `Scope@name`;
  - Laravel `Class@method`;
  - a unique trailing name;
  - otherwise the file.
- **The AR-08 chain:**
  - per non-overlay source layer: uncovered → same layer → `disallowed-layer` → `private-layer` → allowed;
  - `internal-element` waits for doc tags (M5-10/M5-11).
- **Severity:** inferred edges are `warn` by default, `error` under `policy.inferred: "error"`, and skipped under `"ignore"`.
- **Go imports:** an import of a Go package (stored symbol = the package path) is a package end. Its layers are the union of its directory's files' layers.

**`src/arch/report.ts`: `buildReport`, `runArchitecture`, `configErrorReport`, `fingerprint`**
- **One finding per (kind, rule, source element, target element, edge type),** naming every source layer it applies to, with an edge count and the first line.
  - **Elements:** lifted to the top-level declaration (a method → its class; an import → the file's only top-level symbol). `http` and `route` targets stay the handler method.
  - **Package-level findings:** dropped when a finer finding of the same kind and rule, from the same source, reaches a type of that package.
- **`fingerprint`:** sha256 of `[rule, source, target, edgeType]`, 16 hex characters, with no line.
- **Warnings and errors:**
  - `multi-layer`: per top-level declaration, or a symbol-less file that is a dependency end; an error under `strictLayers`;
  - `empty-layer`;
  - `plus-cycle` and `config`, from an invalid configuration.
- **`layers`, `layerEdges` (counted per dependency, not per edge), `counts`.** Findings are sorted deterministically.

## Limitations

- **Member-level multi-layer:** a member that is in more layers than its type gets no `multi-layer` warning of its own (warnings are per top-level declaration).

- **Package-qualified Go calls** (`domain.NewOrder()`) still resolve by name (M5-25 limitation). A package imported only for such calls is reported at package level.
- **`uncovered.externals` / `builtins`:** have no effect yet, because edges to out-of-workspace targets are not stored (M5-19 … M5-24).
- **`inheritDependencies`:** not implemented (M5-09).
- **End resolution:** an edge end naming a symbol that is ambiguous within its file falls back to the file element.
