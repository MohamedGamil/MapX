# M0-12-R2 — Language tiers: all bundled (amend spec), lang info, shebang detection

Date: 2026-10-31. P0 from the M0-41 legacy audit (I12). Resolved per owner decision **D010**: all grammars are bundled, which amends I12/F20's Tier-3 "installable" model.

## Delivered

- **`src/languages/installer.ts`, rewritten:**
  - every supported language counts as installed;
  - `installLanguage` / `uninstallLanguage` validate the name and return an explanatory message ("bundled; nothing to install" / "cannot be uninstalled; use an exclude pattern"). They no longer copy files into `~/.mapx/grammars`, which nothing ever read;
  - `describeLanguage` backs a new **`mapx lang info <lang>`** (tier, extensions, resolved grammar and query paths, and a missing-file warning).
- **`mapx lang list`:** reports every language, `tsx` included (previously "Not Installed"), as `bundled`.
- **MCP:** `mapx_lang_install` / `mapx_lang_uninstall` return the same messages; descriptions updated.
- **Shebang detection:**
  - `languageFromShebang` (bash/sh/zsh, python, node/deno/bun, ruby, php, lua, elixir; handles `env -S` and flags);
  - discovery reads at most 256 bytes of an extensionless file;
  - the language is carried as `FileInfo.language` into both parse paths (`getParserForFile(…, languageName)`; worker jobs carry `language`).
- **F20 extension gaps:** `.pyw`, `.rake`, `.gemspec`, `.zsh`, `.luau`, `.dpr`, `.lpr`, `.h++`, `.c++`. `.fish` is deliberately not mapped, because fish syntax is not bash and the bash grammar would mis-parse it.

## Limitations

Name resolution across files skips shebang-only scripts: their source language is unknown from the path, so resolution fails closed (M2-01).
