## Limitations

- The fixture is synthetic. Re-measuring against the pilot codebase (report §1) is for the report's owner to do.
- Regex-based extraction is unchanged in kind: route declarations whose structure is built at runtime (loops, closures returning paths) are flagged `dynamic` at best.
- Middleware is resolved from names and Kernel groups only; Laravel 11 `withMiddleware` groups are not read.
