# M2-04 — URL constant, template and conditional resolution

Date: 2026-10-30. Delivered together with M2-05 as one URL evaluator, `src/frameworks/http/url-resolver.ts`, which the scanner's `scanHttpCalls` uses to fill `url` on every D008 record.

## Delivered

**M2-04 (this task):** `evaluate()` handles string literals, `+` concatenation and template literals (including nested `${…}`). It also resolves string constants: `fileConstants()` for `const X = …`, and `collectConstants()` + `visibleConstants()` for named and aliased imports of exported constants, through relative paths or `@/`. Unknown substitutions become `{}`, and a URL with no literal part stays unresolved. Each branch of a conditional URL (split by M2-03) resolves on its own. Arguments are now stripped of comments before evaluation (`stripComments` in `client-calls.ts`); the split-line fixture call has an inline comment inside its argument list.
