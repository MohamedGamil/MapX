# M7-01 report: site scaffold, brand theme and one-command build

Delivered 2026-11-07. Spec: `docs/baton/iterations/M7-01.md`.

## Delivered

- **`site/`**: its own package (`site/package.json`, lockfile) with VitePress 1.6.4 pinned exactly. The root install, `npm run check`, `tsup` and the npm package do not see it.
- **Build:** `npm run site:build` runs `scripts/site/sync-docs.ts` (copies the 11 allowlisted guides and the image files of `docs/images` into the gitignored `site/docs/`, and writes a docs index), then `vitepress build`. `site:sync` and `site:dev` sit beside it.
- **Configuration:** `site/.vitepress/config.ts` and `site/.vitepress/base.ts`. The base is `SITE_BASE` (default `/mapx/`), the origin `SITE_URL`, and the output folder `SITE_OUT` (absolute paths only, since VitePress empties it). Guides render as plain HTML (`v-pre`), because they quote Blade and Mustache `{{ … }}`.
- **Theme:** the dashboard slate palette and brand magenta `#ff02fe` (`brand.css`), the system font stack, and no font preloads.
- **Footer (owner decision, D045):** "MapX is created by Mohamed Gamil · gamil.io · Released under the Apache-2.0 license". There is no About page and no About nav entry (M7-04 is CANCELLED). The footer stays visible on pages with a sidebar, where the default theme hides it.
- **Docs defect found and fixed:** `docs/mcp-integration.md` closed an outer code fence early at a nested indented fence (lines 49 and 69), so every later fence was inverted and `<id>` leaked as an HTML tag. GitHub rendered it wrongly too. Both outer fences are now four backticks.

## Independent review

A fresh reviewer, given the criteria and the diff and not my conclusions, found no P0 and one P1.

- **P1, fixed:** the "nothing internal" test checked file names that could never exist (`docs/baton/index.html`), so it could not detect a leak. It now walks the whole output, asserts the exact set of pages under `docs/` equals the allowlist plus the index, and rejects any path through `baton`, `research`, `reports` or `specs`.
- **P2, fixed:** `docs/images` was copied wholesale, so a Markdown file there would have been published; the copy now takes image files only.
- **P2, fixed:** the theme's unused Inter font was preloaded, which broke the "no web-font requests" decision; the preload is stripped and tested.
- **P2, fixed:** `SITE_OUT` empties the folder it names; it now requires an absolute path and says why. `normaliseBase` accepted URLs and `..`; it now refuses them and has unit tests. The base-path test scanned only `index.html`; it now scans the home page, the docs index and one guide.
- **P2, handed on:** the sidebar footer override has no test until a sidebar exists (M7-02 criterion). Footers at 1440 px and wider are slightly off-centre under the content (cosmetic; M7-02). The tests run bare `npm`, which a Windows runner would not find (no such CI job exists). The build tests are not enforced in CI until M7-05 adds the Site job.
- **Checked and found clean by the reviewer:** the allowlist and links, the `v-pre` wrapper (headings, outline and images still work), the lockfile and `npm pack`, and the footer test.
