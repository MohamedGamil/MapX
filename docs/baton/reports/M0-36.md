# M0-36 — Add the documented --include-members CLI flag to mapx node

Date: 2026-10-30.

## Delivered

`mapx node <symbol> --include-members` (`src/cli.ts`) lists the symbols in the same file scoped to the inspected symbol, using the same rule as `mapx_node include_members`:
- text output prints a `Members:` section;
- `--format json` adds a `members` array.

This makes the CLI match CHANGELOG 0.3.4 and `src/agents/templates.ts:199,455`, which already documented the flag.

Before the change, commander rejected the option (`error: unknown option '--include-members'`), so the test cannot pass on the old code.
