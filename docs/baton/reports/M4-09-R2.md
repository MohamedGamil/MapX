# M4-09-R2 report: tests remove the temp directories they create

Found on 2026-11-02. There were 339 `mapx-*` directories in `/tmp` (58 MB). 270 of them were `mapx-stale-*`, made by `tests/mcp-coverage.test.ts` and never removed. `check-test-cwd` watched only the checkout.

## Delivered

- **`scripts/baton/check-test-cwd.mjs`:**
  - runs the command with a private `TMPDIR`, `TMP` and `TEMP`;
  - afterwards it lists what is left there and fails, naming each entry;
  - ignores the tool caches Node and tsx keep there (`node-compile-cache`, `v8-compile-cache-*`, `tsx-<uid>`);
  - removes the private directory.
- **Review fixes in the check:**
  - the tsx cache is also matched under a user name (`tsx-<username>`, as on Windows);
  - the run and its reports sit in `try/finally`;
  - a leftover that cannot be removed has its folders made writable and is retried, and the reports are still printed.
- **`tests/mcp-coverage.test.ts`:** the staleness test removes its `mapx-stale-*` directory in a `finally`.
- **`tests/check-test-cwd.test.ts`:**
  - a command that leaves a temp directory fails, naming it;
  - one that removes its directory passes;
  - one that leaves only `node-compile-cache` or `tsx-someone` passes;
  - a read-only leftover is still reported (exit 1, named), and no private folder is left.
