# M0-14-R1 — TOON exporter unit and round-trip tests

Date: 2026-10-30. Resolves the disputed completion of M0-14 (I14).

## Delivered

- `@toon-format/toon@^4.4.0` is now a devDependency, as I14 specified.
- `tests/toon-exporter.test.ts` builds a real in-memory `Store` and `MapxGraph` (3 files, 5 symbols, 4 edges), including values that contain `,` and `|`. It decodes the output with the reference `decode()` and checks:
  - files, symbols and edges round-trip losslessly for the default, `comma`, `tab` and `pipe` delimiters;
  - per-file symbol counts;
  - truncation under a 120-token budget (`truncated`, `includedSymbols`, `totalSymbols`).
- **Defect fixed (found by the new test):** with `tab` or `pipe` delimiters the exporter wrote headers such as `files[3]{path,language,…}:`. TOON requires a non-comma delimiter to be declared inside the brackets (`files[3|]{path|language|…}:`), so the reference decoder rejected the output (`ToonDecodeError: Expected 2 inline-form values, but got 1`). A single `header()` helper in `src/exporters/toon-exporter.ts` now emits spec-conformant headers for `languages`, `files`, `symbols`, `edges` and `clusters`.

## Limitations

- Key folding (`--key-folding`) is not covered; the exporter has no such option.
- Clusters are not part of the fixture.
