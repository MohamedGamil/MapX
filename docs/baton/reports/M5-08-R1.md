# M5-08-R1 report: git refs and paths never reach a shell

Found by the independent review of M5-14 (2026-11-03, **P0**, reproduced).
- **The hole:** `getChangedFiles` built `git diff … ${since}` as a shell string for `execSync`. `HEAD^{/.|$(touch PWNED)}` is a valid git ref (a commit-message regex), so it passes `git rev-parse --verify`, and the shell then ran the command.
- **Who exposed it:** the CLI already did, through M5-08 (`mapx arch changed --since`). M5-14's MCP tools would expose it to agents, and `mapx serve --sse` listens on every interface.

## Delivered

- **`src/core/git-tracker.ts`:** every git call is `execFileSync('git', [...])` with an argument array, so no shell parses a ref or a path. `revision(since)` refuses a ref that starts with `-` (`--output=…` would otherwise make git write a file), and puts `--` after the revision.
- **`src/cli.ts`:** `mapx ui --open` spawns the browser opener with an argument array instead of a shell string built from the user's `--host`.
- **`tests/git-injection.test.ts`** (real git, temp repo):
  - three shell-syntax refs create no file;
  - `--output=WRITTEN` is refused and writes nothing;
  - a real ref still diffs.
- **`tests/git-tracker.test.ts`:** mocks moved from `execSync` to `execFileSync`; the argument arrays are asserted.

A search of `src/` for `execSync` and template-string `exec(` finds one other call: the SVG exporter's constant `dot -Tsvg`, whose data goes to stdin. No other command is built from input.

## Mutation check

With develop's `git-tracker.ts` put back, then restored and compared with `cmp`, all 3 injection tests fail. The shell-syntax ref created `PWNED`, which then also broke the third test's diff.

## Limitations

- `mapx check --since` and the M5-14 tool must still validate refs (exit 3 on an invalid ref); M5-14 does that in its own lane.

Changelog: A `--since` git ref, from `mapx arch changed`, `mapx check` or an MCP tool, can no longer run a shell command or become a git option, and `mapx ui --open` no longer passes `--host` through a shell (M5-08-R1).
