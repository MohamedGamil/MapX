The four language apps implement one design:
- **Layers:** Controller, Application (with a private `internal` part), Domain, Shared, Infrastructure, and Reporting, which matches nothing.
- **Policy:** `Controller → Application`, `Application → +Domain`, `Domain → Shared`, `Infrastructure → Domain, Shared`, `Shared → nothing`.
- **Shared** is one more layer than the spec's four: it lets the `+` rule be scored, since Application reaches Shared only through `+Domain`.
- **Ignored** `Domain/Ids/**` is also selected by Shared, so `OrderId` is the multi-layer element.
- **Internal markers:** `LedgerHelper` and `AuditTrail` carry `@internal` in each language's doc form: a PHP docblock, TS JSDoc, a Python docstring and a Go comment.
- **Uncovered:** `support/` is in no layer.

The workspace allows `Frontend → PublicApi` only for `http`. `fetch('/api/orders')` reaches an `Api\` controller (allowed); `fetch('/admin/users')` reaches an `Admin\` controller in `Backend` (a violation).

**`scripts/eval/score-arch.ts`:**
- **Running:** copies each app to a temp directory and runs the real CLI: `init`, `workspaces add` for the two-repo app, `scan`, then `mapx check --format json --output .mapx/architecture-report.json` once `--help` lists `check` (M5-05). It reads that report (AR-09 `ArchReport`); a missing report means no findings, recall 0.
- **Matching:** a reported finding matches a row when:
  - kind and rule match exactly;
  - both ends' files match, and their symbols when labelled; an element name matches by its last segment, so `App\Domain\Order`, `app.domain.order.Order` and `src/domain/Order.ts#Order` all name `Order`;
  - a labelled edge type is the finding's;
  - a layer-level row matches the finding's layer.

  Findings for the same dependency (kind, rule, both ends) count once whatever edge types carry them.
- **Scores:** per-kind recall and precision. Findings on `allowed` or `none` rows are false positives and are listed.
- **Options:** `--json`, `--app <name>`, `--min-recall`, `--min-precision` (shared strict parsing, M4-08). Exit 1 when a threshold is missed, 2 on usage or scan errors.

**The report contract M5-05 writes:** `.mapx/architecture-report.json` with `findings[]` as in AR-09, plus:
- layer-level warnings (`empty-layer`) name their layer in `layer` (or `source.layer`);
- configuration and baseline errors are findings of kind `error` with rule `plus-cycle` or `stale-baseline`, in addition to the `configErrors` strings.
