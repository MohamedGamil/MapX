  - Selectors name the element, never the expression (`ambient: "process.env"` matches nothing). Consistent with M5-24: `true` or a glob/regex, names case-insensitive.
- **Row:** `specifier` is the canonical access (`process.env`, `os.environ`, `$_GET`, `getenv`), `symbol` null, `kind` `call` (so the default `scope.types` covers it; no new edge type), `origin` `ambient`, other attribution null. - **Extraction** (`src/parsers/ambient.ts`, new): syntax-tree walks run while the tree is alive (`parseWithQueries` gets an optional visitor), returned as `ParseResult.ambient` (not a reference, so edge counts are unchanged), carried through the worker pool, turned into external candidates by `Scanner.noteAmbient`, and attributed in `decideExternalRefs` from the candidate's metadata (`{ ambient: element }`), which needs no attributor.
- **Precision:** a parameter, local, loop or catch variable, import, function or class named like the global shadows it (JS/TS); JS `process` from `process`/`node:process` (import, namespace import or `require`) is the same ambient; Python `os`/`sys` must be bound by an import of that module (aliases and `from os import environ` count; function-scope imports are scoped); Go `os` must be the import of `"os"` (alias handled; param/local shadow; `_`/`.` imports do not count); comments, strings, property names and type positions never count; a PHP superglobal in a comment, a single-quoted string or a nowdoc does not count (review: interpolated in a double-quoted string, a heredoc or backticks it does).

## Limitations and decisions to confirm

- **Not extracted:** Vue and Svelte single-file components (their parsers copy fields selectively), `process.argv`, `sessionStorage`, `$argv`, `import { env } from 'node:process'`, other languages. Python `global` declarations and comprehension scopes are approximated.
- **Shadowing is approximate** in Go (a name declared anywhere in an enclosing function) and in JS block scoping of function declarations.
- **Kind `call`** for all ambient rows, including property reads, to stay inside the default `scope.types`. A dedicated edge type would touch the schema, `EDGE_TYPES` and every consumer.
- The worker-pool fallback capture walk (used only when a language parser throws) records no ambient access.
- The existing python fixture had one ambient access (`http_gateway.py:14`); it needed a new label in the delimited block (no existing label changed).

## Review (of 86b86cf)

The review found one P1 and four P2 groups. All are fixed in the same commit.

- **P1, PHP interpolation.** The brief's rule ("`$GLOBALS` inside a string doesn't count") was wrong, as the coordinator confirmed: PHP reads superglobals in double-quoted strings, heredocs and backtick strings. `phpAmbient` now skips only single-quoted strings, nowdocs and comments. **Label change, justified by the language semantics:** `php-ambient/app/Infrastructure/Notes.php:12` (`"the \$_GET array and $GLOBALS"`) was a negative and is now a labelled `$GLOBALS` access (one new row; the escaped `\$_GET` stays text). Docs and the iteration text corrected. Test: "PHP reads a superglobal in a double-quoted string, a heredoc and a backtick string".
- **P2.1, TS signatures.** `function_signature`, `method_signature`, `abstract_method_signature`, call and construct signatures and function types bind their parameter names; `export * as window` names a binding.
- **P2.2, PHP `getenv`.** An unqualified `getenv()` records its namespace; `decideExternalRefs` drops the row when the workspace declares `Namespace\getenv`. A `use function ...getenv` import hides the global in the parser. `\getenv()` always counts. E2E test with a namespaced helper.
- **P2.3, recall gaps fixed:** JS `process["env"]`, `const { env } = process`, `import { env } from 'node:process'` (recorded where written); Go `os.Setenv`, `Unsetenv`, `ExpandEnv`, `Clearenv`; Python comprehension variables are the comprehension's, and `os = None` after a failed import binds nothing; Go `:=`, `var` and `range` names are scoped to their block and apply after the declaration. **Left as limitations:** later uses of a local `env` bound from `process`, Python `global` declarations, Vue/Svelte.
- **P2.4, selector-name trap.** A layer whose `ambient` selector (any depth, `selectors` or `private`) names no element gets an `unsupported-selector` warning: `layer Wrong: selectors[0] uses ambient "process.env", which is not an element name; it matches nothing (did you mean "env"? Element names: ...)`. Globs that match a name, `C`, `ext-*`, regexes and `true` are accepted. Test: "an ambient selector that names no element is reported with a hint". The element list is `AMBIENT_ELEMENTS` in `src/core/external-refs.ts`.
