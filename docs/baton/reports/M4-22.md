# M4-22 — Read-only configuration view

Decision D027: read-only first. Editing would need its own write API, in a later task.

## Delivered

**`src/core/config-report.ts`: `describeConfig(dir, config, env)`**
- **Settings:** each known setting (`maxTokenBudget`, `excludePatterns`, `includePatterns`, `graphExcludePatterns`, `laravelDefaultExcludes`, `parseWorkers`, `php`, `http`, `architecture`) with its description, value, default and source.
  - **`default`:** the setting is absent, or equal to MapX's default.
  - **`user`:** set in `.mapx/config.json` with another value.
  - **`env`:** `MAPX_PARSE_WORKERS` overrides `parseWorkers`.
- **Pattern lists:** sources are judged per entry. `mapx init` merges the defaults into the file, so a list is `user` when it holds any pattern MapX itself never writes. Built-in patterns are the defaults, init's PHP and JavaScript extras and Laravel's; `config.ts` now exports those lists instead of inlining them.
- **Warnings:**
  - an invalid value for any known setting, including `parseWorkers`, as the worker pool's own parser judges it;
  - an unknown setting key, or unknown keys inside `php` and `http`;
  - a repo whose folder does not exist, and a repo entry collapsed as a duplicate;
  - a user language without extensions or a grammar, an absolute grammar path that does not exist, or one named like a built-in language (MapX ignores those).
- **Also reported:** repos (name, path, framework, exists, primary) and user languages (extensions, grammar, queries).

**`/api/config`** (`src/ui-server.ts`): GET or HEAD only. Any other method answers 405 with `Allow: GET, HEAD` and a message naming where to edit.

**Configuration tab** (`src/ui`):
- the warnings, or "No problems found";
- a settings table: name and description, value, and a source badge. Your own patterns are tags; built-in ones are folded under "n built-in patterns";
- the repos and user languages;
- the file's path.

The tab has no form controls. Its templates pass `scripts/ui/check-escaping.ts`, and it is in the smoke, axe, width and keyboard tests.

**Docs:** `docs/cli-reference.md` and the CHANGELOG.
