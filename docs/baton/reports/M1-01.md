# M1-01 — Laravel route fixture and recall/precision scorer

Date: 2026-10-30. Records the 0.3.5 baseline; no detector change.

## Delivered

- `tests/fixtures/laravel-routes/`: a synthetic Laravel 12 app (26 files, all names invented):
  - `artisan`, `composer.json` and `bootstrap/app.php` with `withRouting`;
  - `routes/web.php`, `routes/api.php`, and `routes/api/{users,late,beta}.php`, mounted by `require` inside a prefixed and middleware group, after a duplicate, and inside `if (config(...))`;
  - an unmounted `routes/unmounted.php`;
  - a Billing module provider (`Route::prefix()->middleware()->group(path)`) and a Shop provider (`Route::prefix()->group(fn () => $this->loadRoutesFrom(...))`);
  - controllers for every handler.
- `labels.json`: 41 labels over 14 patterns. These cover every form in report §2, plus 3 negatives (overridden, unmounted) and a conditional mount. Parameter names follow Laravel (`{blog_category}`, `{status}`, `{person}`).
- `scripts/eval/score-routes.ts`: copies the fixture, runs the real CLI (`init` + `scan`) and scores `.mapx/routes.json`. It reports, per pattern:
  - URI found, handler found, exact parameter names, flagged (conditional/negatives) and false positives;
  - URI recall, handler recall, and precision (reported live routes minus unlabelled minus false positives).

  Flags: `--json`, `--min-recall`, `--max-fp`, `--min-precision`, `--strict-params`.
- `tests/laravel-routes-fixture.test.ts`:
  - label well-formedness;
  - 4 scorer unit tests (parameter normalisation, method sets, negatives, conditional flags);
  - a real-scan test against `FLOORS`, which each M1 task raises.

## Limitations

- Handlers are compared as `ShortClass@method`; FQCN resolution is not scored.
- Middleware is not scored yet (M1-09 adds it).
- The `then:` callback of `withRouting` is not in the fixture.
