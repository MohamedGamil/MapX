## Defects fixed in `src/mcp.ts` (`mapx_search`)

1. **Wildcard listing truncated:** wildcard plus file filter, with no explicit `limit`, now returns every match.
2. **`totalMatches` was capped at 20:** it was computed with `searchSymbolsFiltered` and its default limit of 20. It now uses `store.countSymbolsFiltered` (with the kind dropped when the search was broadened).
3. **Truncation was silent unless the caller passed `limit`:** the header now says `Found N of M symbols` whenever results are fewer than matches. A new test checks that searching `fn` reports `Found 20 of 25 symbols`.

`tests/mcp.test.ts` gained a `countSymbolsFiltered` mock that derives the count from the unlimited search, matching the real store.
