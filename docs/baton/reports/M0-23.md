# M0-23 — Scan summary edge count disagrees with stored edges

Date: 2026-10-30.

## Root cause

The count mismatch had two causes:

1. **Overlapping repos (data defect).** `mapx init` registers the workspace root (`.`) as a repo. When `backend` and `frontend` are also registered, the root repo's walk descended into them (`scanner.ts` `discoverFiles` only skipped *unregistered* nested git repos). Every file was indexed twice: first under the root repo, then under its own repo. Because `files.path` is the key, the second scan overwrote the first. Counts and the language breakdown were inflated (`php: 2` for one file), and scan work doubled.
2. **Wrong quantity.** `edgesFound` summed raw extracted references, including unresolved and external ones (e.g. `import axios`), and skipped unchanged files on a re-scan. It was never the stored edge count.

## Fix

- `src/core/scanner.ts` `discoverFiles`: skip any directory that is another registered repo's root.
- `src/core/scanner.ts` `scanRepo` (full scan): when the scan completes, `symbolsFound`/`edgesFound` are `store.getSymbolCount(repo)`/`getEdgeCount(repo)`. Interrupted and incremental scans keep their "found in this run" semantics.
- `src/core/git-tracker.ts`: git calls run with stderr ignored. All of them were already inside try/catch, so a repo with no commits no longer prints `fatal: Not a valid object name HEAD` during a scan.
- `tests/scanner.test.ts` and `tests/scanner-coverage.test.ts`: the mock store factories gained `getSymbolCount`/`getEdgeCount`.

## Evidence

| Command | Exit | Result |
| --- | ---: | --- |
| `npx vitest run tests/scanner-summary-count.test.ts`, before the fix | 1 | summary 4 edges vs 1 stored |
| `npx vitest run tests/scanner-summary-count.test.ts` | 0 | 2 passed |
| Mutation: remove the nested-repo skip, then the same command | 1 | both tests fail (restored afterwards) |
| `npx vitest run tests/scanner.test.ts tests/scanner-coverage.test.ts` | 0 | 30 passed |

Manual check on the two-repo workspace: `Languages: php: 1, vue: 1, javascript: 1`, `Found 7 symbols, 1 edges`, with no git `fatal:` lines.

## Limitations

The root repo still exists as an empty repo in this layout; `mapx init` registering `.` alongside sub-repos is unchanged.
