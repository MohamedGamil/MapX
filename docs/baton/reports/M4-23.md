# M4-23 — Cross-repo HTTP view

Decision D027. Builds on the M2 HTTP pairing (`.mapx/http-calls.json`, `mapx routes --clients`). The pairing itself is unchanged; only the target repo of an `http` edge was fixed, in M2-06-R3 (`cbd766e`), found while building M4-21.

## Delivered

**`/api/http`** (`src/ui-server.ts`):
- **Records:** the records of `loadClientCalls`, the function behind `mapx routes --clients --json`, each with four additions:
  - `callerRepo` and `handlerRepo`, from the index's file-to-repo map, or from the containing repo's folder for files the index does not hold;
  - `callerCode`: the call's line of source, read only from indexed files inside the workspace;
  - `handlerLine`: the handler method's line, from the symbols table.
- **Grouping:** calls are grouped in `pairs` (`from`, `to`, `count`, `calls`) and `unmatched` (`repo`, `count`, `calls`), most calls first, with `total` and `matched`.
- **Scope:** `repo=` keeps calls whose caller or handler is in that repo; an unknown repo is a 404.

**HTTP Calls tab** (`src/ui`):
- **Summary:** calls, matched, unmatched, repo pairs.
- **Flow diagram:** an SVG with calling repos on the left and serving repos (plus "No route") on the right.
  - Link widths are 2–16 px by count, each labelled with its count.
  - Unmatched links are dashed in the danger colour.
  - The diagram has an `aria-label` listing every pair, and `<title>` tooltips.
  - Clicking a link filters the table to that pair.
- **Filters:** method, repo pair (including "repo → no route") and status.
- **Calls table:** method badge and URL as a button, caller location, handler.
- **Detail panel:** both ends:
  - the caller's repo, file and line (a badge that opens the graph there), its line of code and the client;
  - the route (method, path, confidence), the handler symbol, and the handler's file and line (also a graph badge).
- **Escaping:** the templates pass the escaping check. SVG coordinates go through `num()` (`String(Number(v))`) rather than an allowlist of names, the weakness the M4-20/M4-24 review raised.

**Graph (criterion 3):** HTTP edges between repos are cross-repo edges since M2-06-R3, so they carry `crossRepo` and are drawn dashed in pink. The `__mapxEdge` test hook now reports the edge type.

## First full run

- **A real failure:** at 390 px the HTTP tab scrolled sideways; the repo-pair filter's long option text widened its select. Labels and selects now shrink, and take a full row below 640 px. The width test passes.
- **A race in the test:** the switcher test read the options right after the graph was ready, and `/api/repos` (git state per repo) can answer later. It now waits for them.
- **Load:**
  - The 500-file render budget missed once (1,180 ms) at a load average of about 13–17; alone it ran at 318 ms.

  - CI doubles both budgets (`MAPX_UI_PERF_SCALE=2`).
