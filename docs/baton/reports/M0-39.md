# M0-39 — Tests for shipped but untested 0.3.x features

Date: 2026-10-30. The M0-30 inventory found these features shipped with no test. Each test imports the real module and was mutation-checked.

| Feature | Test | What it shows | Mutation |
| --- | --- | --- | --- |
| Prepared-statement cache (`NodeStore.stmtCache`) | `tests/store-stmt-cache.test.ts` | the same SQL returns the same statement object; different SQL a new one | bypass the cache → fails |
| Hub/orchestrator topology signal (`role-classifier.ts`) | `tests/role-classifier.test.ts` (new block, real `Store`) | fan-in 5 and fan-out 10 → `core` "orchestrator"; fan-in 4 → no hub signal | raise the threshold → fails |
| WASM asset root (`findAssetRoot`) | `tests/assets.test.ts` | the source module URL resolves to the package root with `wasm/`; a `$bunfs` binary URL falls back to `~/.local/share/mapx` | drop the XDG candidate → fails |
| Dashboard server (`/api/status`, `/api/graph`, `/api/explain`, `/api/tool-calls`, token auth) | `tests/ui-server.test.ts` | started on an ephemeral port against a really scanned workspace: 401 without the token; status 200; graph contains both scanned files; explain returns `signals`; tool-calls is paged JSON | skip token checks → fails |

None of the features needed a fix.
