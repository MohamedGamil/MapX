# M4-17 — Dashboard look and feel: design system, themes, responsive and accessible

Decision D027; scope from the M4-16 audit (`docs/research/dashboard-ux-audit.md`).

## Delivered

**Design tokens (`src/ui/styles.css`)**
- Token blocks hold the type scale (system UI and monospace stacks, 10–24 px, weights, line heights), the 4 px spacing scale, radii, layout sizes and motion.
- Colours are defined twice: `:root` / `:root[data-theme="dark"]`, and `:root[data-theme="light"]`. Both palettes were checked at ≥ 4.5:1 against every surface (scratch script; dark muted text 4.9–6.2:1, light 5.5–6.2:1).
- **Semantic aliases** keep the old variable names (`--text-white`, `--bg-card`, `--syntax-*`) working for the inline styles in `main.ts`.
- **Shadows** are built from tokens with `color-mix()`.
- **Conversion:** a scripted pass turned the 1,878-line stylesheet's 150 colour literals into tokens. Alpha variants became `color-mix(in srgb, var(--token) N%, transparent)`. No literal was left unmapped. A design-system layer follows for controls, focus, badges and layout.
- **`scripts/ui/check-tokens.ts`** fails on any hex, `rgb()`/`hsl()`-family or named colour outside a token block's custom properties. It passes the new stylesheet, finds 150 literals in the old one, and flags all four planted literals in a synthetic file. `tests/ui/design.spec.ts` runs it.
- **Fonts** come from the system. The Google Fonts links are gone, so the page makes no third-party request.

**Themes**
- An inline script in `<head>` sets `data-theme` before first paint: the saved choice (`localStorage` "mapx-theme"), else `prefers-color-scheme`.
- `src/ui/chrome.ts` adds the sun/moon toggle, which persists. Until the user picks, the dashboard follows system changes.
- **The graph follows the theme:** cytoscape draws on a canvas and can't read CSS variables. Its style became `graphStyle()`, which reads the tokens through `t(token, alpha)`, and a theme change restyles the graph. Language and layer hues stay fixed, as categories.
- **Badges** (HTTP method, hook type, smell severity, file role) are a 12% tint of their colour, with text mixed toward the theme's strongest text. They pass contrast in both themes; the old solid-colour badges with white text did not.

**Layout**
- **Sidebar:** full width at 1200 px and above, an icon rail (64 px, labelled buttons) below 1200 px, and below 640 px a drawer behind a menu button. The drawer has a backdrop, closes on Escape and when a view is chosen, and shows the view's title in the top bar. The closed drawer is `visibility: hidden`, so it takes no Tab stops.
- **Graph tab:** the toolbar is a bar above the canvas instead of overlaying it (finding 7). The details panel opens only while something is selected (finding 13); below 1200 px it floats over the canvas, with a close button and Escape.
- **Tables:** cells wrap long paths and handlers. Headers stick. Low-priority columns (framework, kind) hide below 640 px. The Symbol Explorer stacks below 1200 px and keeps pagination above and below the table (finding 12).
- **Cards** use auto-fit grids. The DSM matrix scrolls within its own focusable region.

**Accessibility**
- **Headings:** the logo is the page's `h1`.
- **Labels:** every graph toolbar `<select>`, the focus search, symbol search and context task have accessible names; nav buttons keep theirs in the rail.
- **Focus:** a 2 px `:focus-visible` ring on every interactive element.
- **Keyboard:**
  - Routes/Hooks is a tablist with arrow keys.
  - File badges are `role="button"`, operable with Enter or Space.
  - Symbol names are real buttons.
  - The scroll regions (`main`, DSM, smells list, tool log) are focusable.
- **Tables:** the DSM's corner header has hidden text.

**Smaller findings**
- **Metrics** (finding 11): breakdowns are bar charts with stat tiles, and language names are spelled properly (PHP, TypeScript, C#…), also in the language filter.
- **Clusters Map** (finding 8): when 60% or more of the files have no architecture layer, the map groups by directory instead of putting them in "Other". A grouping the user picks is kept, and Reset re-applies the rule. On the generated 2,000-file fixture the map shows the directory structure instead of "Other (1800)" (see the screenshots).
- **Graph labels** (finding 10): labels drawn smaller than 7 px at the current zoom are hidden until the user zooms in, and cluster labels are 14 px. Readable labels on about 100 clusters at full zoom-out aren't possible, so hiding beats overlapping.
- **Rate limit:** loopback clients are no longer rate-limited on `/api/graph`, `/api/graph/meta` and `/api/context` (10 a minute per client). Reloading the dashboard eleven times in a minute broke the graph with a 429, and so did the design spec. Loopback is judged by `req.socket.remoteAddress`, never by `X-Forwarded-For`, which the client controls (`isLoopback`, `tests/ui-server.test.ts`).
- **`scripts/ui/shots.ts`:** screenshots of chosen tabs, themes and widths, as a review aid.
- **Docs:** `docs/cli-reference.md` (`mapx ui`) and the CHANGELOG.

## Limitations

- **Details panel test:** it drives the panel by changing the details content, the same signal a node tap produces, rather than tapping a canvas node; Playwright cannot address cytoscape nodes without a test hook. The real flow was checked by hand.
- **DSM cells** remain mouse-only (hover and click for the legend). The matrix region itself is focusable and scrollable; one Tab stop per cell, hundreds of them, would be worse.
- **Unescaped values:** several templates in `main.ts` interpolate scanned values (route paths, handlers, tool inputs, smell text) into `innerHTML` without escaping. This predates M4-17. It is registered as M4-24 and fixed before M4-20. The values this task touched (symbol rows, metrics) are escaped.
