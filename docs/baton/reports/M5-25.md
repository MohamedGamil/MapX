# M5-25 — Go package-qualified composite literals

Planned in `iterations/M5-25.md`; registered 2026-11-02 as a hard dependency of M5-04.

## Delivered

- **`queries/go/references.scm`:** a composite literal of a `qualified_type` (`domain.Order{}`) is an instantiation reference to `Order`.
- **`src/parsers/generic-wasm-parser.ts`:** a qualified `instantiation` reference carries the import path that names its qualifier (`goPackage`), as embedded types have since M0-17-R5.
- **Resolution:** the scanner's existing `resolveGoQualifiedType` resolves it:
  - in a project package: the type declared in that package's directory;
  - in a standard-library or third-party package: no edge.
