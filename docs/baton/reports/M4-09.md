# M4-09 — Tests never write to or delete files in the repository checkout

Date: 2026-10-31. Base: `develop@00407d6` plus the remediation in the working tree. Owner: maintainer. Iteration: `docs/baton/iterations/M4-09.md`.

## Delivered

- **`tests/cli.test.ts`, `tests/cli-coverage.test.ts`:** file-level hooks run each file from a temporary directory (`mkdtemp`, `process.chdir`, restored and deleted in `afterAll`). `cli.test.ts` creates `src/main.ts` there for its staleness tests.
- **`scripts/baton/check-test-cwd.mjs`:** the check described in the spec.
- **Related mock fixes** made during M0-11-R3 (`tests/mcp.test.ts`, `tests/cli.test.ts`): `getChangedFiles` mocks return `{ path, status }` records, as the real function does, and the language mock is inert except in the status tests. The `getStaleFilesCount` tests no longer count the developer's untracked files.

## Mutation check

`.mapx/config.json` and `.mapx/mapx.db` were written into the checkout as sentinels, and `process.chdir` was removed from `cli-coverage.test.ts`. The check then exited 1, listing `changed .mapx/config.json` and `changed .mapx/mapx.db`, among others: the files had been deleted. With the hook restored it exits 0. The sentinels were removed afterwards.

## Limitations

Only the two named files were checked. Whether any other test file writes to the checkout is not checked here.
