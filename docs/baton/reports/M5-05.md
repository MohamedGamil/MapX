# M5-05 — `mapx check` CLI: table/json reporters, exit contract, staleness

Planned in `iterations/M5-05.md`. Sources: AR-16 and AR-17 in `docs/research/deptrac/02-abstract-feature-model.md`, and §3.4 of `03-mapx-gap-and-integration.md`.

## Delivered

- **`mapx check [path]`** (`src/cli.ts`), with these options:
  - `--view`, `--format table|json`, `--output`;
  - `--report-uncovered`, `--fail-on-uncovered`, `--report-skipped`, `--report-allowed`;
  - `--fail-on error|warn`, `--layer`, `--rule`, `--sync`.
- **The run, in order:**
  1. **4:** no index; a registered repo with no completed scan (`last_scan_time:<repo>`); or a stale index. `--sync` runs an incremental scan instead of failing.
  2. **3:** the configuration loads, or its errors are reported as a report.
  3. **3:** `--layer` and `--rule` must name something.
  4. The evaluator (M5-04) runs, the reporter prints, and the run exits by AR-17.
- **Usage errors:** an unknown option or a missing value exits 3 (`exitOverride`); Commander's default is 1.
- **`src/arch/check.ts`:** `selectFindings`, `shownReport` (uncovered, skipped and allowed are hidden unless asked for; counts keep them), `exitCode` (3 > 1 > 2; configuration errors are never filtered) and `CHECK_RULES`.
- **Reporters:**
  - `src/arch/reporters/table.ts`: grouped by source layer; the rule, severity, both elements, the edge type and `inferred`, `file:line` and the reason; a counts line;
  - `src/arch/reporters/json.ts`: pretty, stable JSON.
- **`schemas/arch-report.schema.json`:** the report's JSON Schema. It ships in `schemas/`, which the package already includes.
- **`src/core/staleness.ts`:** `findStaleFiles(store, dir, { walk: true })` finds new files by walking the workspace with the scanner's own file and folder rules (every repo, git or not). The default git listing is unchanged for the other commands.
- **`scripts/eval/score-arch.ts`:** now runs the real `mapx check --format json --report-uncovered --report-skipped`. The fixture score is unchanged from M5-04.
- **Docs:** `docs/cli-reference.md` (`mapx check`: options, exit codes, precedence, staleness), `docs/architecture-rules.md` and the CHANGELOG.

**Plan correction.** The registered command `npm run build` does not exist (the builds are `build:npm`, `build:linux` …). `tests/arch-cli.test.ts` builds `src/` with tsup into a temporary layout that symlinks `node_modules`, `wasm`, `queries`, `VERSION`, `package.json` and `schemas`, so it runs the built CLI and leaves the checkout untouched (M4-09-R1). The verification commands are now `npx vitest run tests/arch-cli.test.ts` and `npm run check`.

## Limitations

- **Older indexes:** an index built by an older extractor is not detected (M5-26).
- **Walk cost:** the staleness walk costs one directory walk of the workspace per `mapx check`, using the scanner's pruning rules.
- **CLI only:** `mapx check` has no MCP tool yet (M5-14), and baselines and `--compare` come with M5-06.
