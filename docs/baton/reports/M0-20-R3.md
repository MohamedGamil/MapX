# M0-20-R3 — NestJS: trailing commas, generic handlers, regex after a parenthesis

Date: 2026-10-31. Base: `develop@00407d6` plus the integrator's P1 remediation patch (`review2.patch`). Iteration: `docs/baton/iterations/M0-20-R3.md`. Findings: review 2026-10-31 (P2 table), `reports/M0-20-R2.md` ("Review", "Limitations").

## Delivered

`src/frameworks/detectors/nestjs.ts`:

- **Trailing comma.** `decoratorCalls()` drops a trailing comma (found on the masked text, so never one inside a string) from the argument text. `@Get(\n  ':id',\n)` now gives `:id`, not `:id',`. Every decorator read benefits: route verbs, `@Controller`, `@Use*` lists, GraphQL and message patterns.
- **Generic handlers.** `findMethodNameAfter()` skips a type-parameter list between a name and its `(` through the new `typeParamsEnd()`. That function balances `<…>`, skips brackets, and an `=>` does not close it. `async list<T>(): Promise<T[]> { return this.svc.findAll(); }` is named `list`, not `findAll`.
- **Regex after a condition's `)`.** `maskCode()` keeps a stack of open parentheses and marks those opening an `if` / `while` / `for` / `with` head (`STATEMENT_HEAD`). After the matching `)`, a `/` starts a regex literal. After any other `)` (a call or a grouping) it stays a division.

## Limitations

- `maskCode` is still a lexer heuristic. A `/` after `}` is always a division, so `if (x) { … }\n/re/.test(s)` as a statement would be masked wrongly. A block end and an object literal cannot be told apart without a parser.
- A method named like a statement keyword (`obj.if(x) / 2`) would be taken as a statement head, so its `/` would start a regex. This is rare and was not seen.
- A class declared inside a handler body (`class Inner { @Get('inner') x() {} }`) still adds its routes to the outer controller (probe `nestedClass`). This was not in the review and is unchanged.

## Findings outside this task

- The separate `maskCode()` in `src/frameworks/http/client-calls.ts` (HTTP pass, Vue template and navigation parsers, `js-aliases`) has the same limitation: `)` is not in `REGEX_PRECEDER`, so `if (s) /'/.test(s)` is read as a division followed by an unterminated string. Not changed here (outside `affectedFiles`).
- `mapx impact maskCode` merges the two unrelated `maskCode` functions by name. It reports HTTP and Vue callers for the NestJS function.

Changelog: NestJS routes keep their path with Prettier's trailing comma in multi-line decorators (`@Get(\n  ':id',\n)`), generic handlers (`list<T>()`) are named after themselves, and a regex literal right after an `if`/`while`/`for` condition no longer swallows the next class (M0-20-R3).
