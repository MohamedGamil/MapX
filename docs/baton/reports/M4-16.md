# M4-16 — Dashboard UX/UI audit with a measured baseline

Decision D027. The findings and the design direction are in `docs/research/dashboard-ux-audit.md`. The raw figures are in `docs/research/dashboard-ux-audit/metrics.json`, beside 26 JPEG screenshots (1.2 MB).

## Delivered

- **`scripts/ui/audit.ts`:**
  1. Builds the dashboard and measures the bundle (gzipped per file).
  2. Scans three fixture workspaces with the real CLI: a `git archive` copy of MapX's sources, and generated 500- and 2,000-file projects (TypeScript, PHP, Vue, Python).
  3. Serves each with `mapx ui` on a free port, and drives it in headless Chromium:
     - **Default graph:** time from navigation until `/api/graph` has answered and the loading overlay is hidden, plus the payload size and main-thread long tasks.
     - **Full Codebase graph:** time until the main thread settles, meaning the end of the last long task, followed by 3 s without a new one. This is a proxy until M4-19 adds a layout event.
     - **Every tab of the MapX copy** at 1440, 1024 and 390 px: console errors, failed `/api` calls, content clipped at the right edge, and axe violations (at 1440).
     - **Screenshots.**
  4. Exits 1 on console or API errors.
- **DOM types:** the script declares `document`, `window` and `PerformanceObserver` within its own module for its in-page callbacks, because the repo's typecheck has no DOM lib.
- **Dev dependencies** (D027):
  - `@playwright/test` 1.64.1 (Apache-2.0);
  - `axe-core` 4.14.0 (MPL-2.0), for tests only and never shipped.
- **Findings:** 6 P1 and 11 P2, each with a screenshot and an owning task (M4-17, M4-18, M4-20, M4-21, M4-22, M4-23, M0-32-R3).

## Limitations

- **No layout event:** the dashboard exposes none, so the Full Codebase times run to the end of the last long task. M4-19 adds test hooks.
- **Clipping inside scroll boxes:** the clipping count includes elements inside scroll containers. The architecture DSM at 1440 px (360 elements) scrolls on purpose. The audit doc names only the real breakage.
