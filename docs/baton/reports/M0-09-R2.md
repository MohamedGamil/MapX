# M0-09-R2 — Agent template deliverables (F17)

Date: 2026-10-31. Decomposed from the M0-03-R1 epic per D010 (implement everything).

## Delivered

- **Claude:** `CLAUDE.md` keeps the stdio (`npx … serve --dir`) stanza and adds an SSE section: `mapx serve --sse --port {{MCP_PORT}} --dir …`, plus a `{"type": "sse", "url": "http://localhost:<port>/sse"}` server entry. The port comes from `--mcp-port`. The `/sse` path matches the server in `src/mcp.ts`.
- **Continue:** `.continue/mapx.yaml` gains `slashCommands` (`mapx-impact`, `mapx-callers`, `mapx-context`, `mapx-sync`), with Continue's `{{{ input }}}` placeholder, next to the existing context providers.
- **Aider:**
  - `AIDER.md` documents `aider --read AIDER.md` and `/read-only`.
  - A new hidden companion template writes `.aider.conf.yml` (`read: [AIDER.md]`), wrapped in `# mapx` sentinels and appended to an existing config.
  - Companions (`ProviderTemplate.companions`) are planned with their provider, so `generate`, `update` and `list` handle them. They are not offered as providers of their own (`hidden`).
- **Zed:**
  - A new `zed` MCP config entry (`context_servers.mapx`, `source: custom`).
  - `agents generate --providers zed` (CLI and `mapx_agents_generate`) merges it into `.zed/settings.json` through `companionMcpConfigs`.
  - `agents mcp --tools zed` and `init` (when `.zed/` exists) do the same.
  - `revertMcpConfigs` removes it.
- **Merge safety (found while doing Zed):**
  - Zed and VS Code settings are JSONC. Before, `JSON.parse` failed on them and the generator **overwrote the whole file** with only the mapx entry.
  - Merges now parse with the existing `stripJsoncSyntax` (exported from `static-file-parser.ts`).
  - A file that still does not parse gets the new status `unparseable`: it is never written, and the CLI warns.

## Limitations

- A merged JSONC file is written back as plain JSON, so its comments are lost; keys and values are kept.
- `.aider.conf.yml` is appended as a sentinel block. If the user's config already has a top-level `read:` key, the result has a duplicate key, and the user must merge the two by hand.
- No YAML parser is available in the repo or environment. The YAML templates were checked by inspection, and the test asserts their structure line by line.
