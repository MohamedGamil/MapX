# M0-17-R6 — Heuristic follow-ups: renamed names in comments, router shadowing, module aliases, factory bindings

Date: 2026-11-01. Base: `develop@42f7225`. Owner: claude. Iteration: `docs/baton/iterations/M0-17-R6.md`.

## Delivered

1. **Rename that survives as text** (`src/core/scanner.ts`).
   - `removedSymbolReferrers` judges "still declared" on `codeOnly(path, text)`, with comments and string literals blanked: `#` comments and docstrings for Python, Ruby and shell; `//`, `/* */` and `<!-- -->` otherwise. Data and markup files keep their text.
   - Callers resolved by name lookup are now re-parsed after a rename whose old name lingers in a comment or a string.
   - Importers were already re-parsed through M2-08.
2. **Vue Router** (`src/parsers/languages/vue-navigation.ts`).
   - **Nested bodies.** `returnTypeParen` lets `nestedBodies` skip a return type of any shape: an object type, a literal union, a function type or a generic. It stops at a statement keyword (`try`, `else`, `finally`, `do`) or a line break, so the ternary of semicolon-less code is not taken for a type.
   - **Shadowing.** `shadowedRanges` finds the functions that rebind a name, by a parameter in a binding position (`boundNames`) or by a local. A `for (const x of …)` header is scoped to the loop's body.
   - **`next` and `push`.** A guard's `next` and a destructured `push`/`replace` are ignored where they are rebound.
   - **Templates.** `v-for`/`v-slot` names hide the `<script setup>` bindings.
3. **Laravel module `@`** (`src/core/js-aliases.ts`). A `Modules/<Name>` app root under an app holding `artisan` falls through to the enclosing app's bundler aliases when its own do not match.
4. **Factory bindings** (`src/parsers/generic-wasm-parser.ts`).
   - **The rule.** `usedAsFunction` promotes a module-level binding to a call, a name or a member only when it is exported (`export const`, `export { }`, `export default x`, `export = x`, `module.exports`, `exports.x`) or called in the file (`f(`, `f?.(`, `f.call/apply/bind(`). In Python, also when the name is public.
   - **Cost.** The called and exported names are computed once per source text.
   - **Effect.** `const app = createApp(App); app.mount()` gives a value.

## Independent review

One fresh agent reviewed the change in its own copy. It confirmed:
- that `codeOnly` errs in the safe direction (more re-parsing, never stale edges);
- that `items.map(x => next(x))`, `if (push) {`, `meta: {…}` and ternary object returns still navigate;
- method-shorthand shadowing, and `v-for` `(item, push)`, `v-slot` and `#default` scoping;
- the `memo(Bar)` render edge, and `module.exports.x`.

Findings:
- **P1:** `export default name`, `export = name` and `exports.default` were not seen as exports, so a default-exported factory (zustand) lost its importers' call edges. Fixed and tested.
- **P2s, fixed and tested:**
  - a ternary in semicolon-less code made `returnTypeParen` hide a guard's `try`/`else` return;
  - a name appearing anywhere in a parameter list counted as a binding;
  - a `for`-header declaration shadowed the whole block;
  - `usedAsFunction` was slow (one regex per binding: 6.4 s against 1.6 s on 8,000 bindings), and is now computed once per file;
  - `?.()` and `.call(` calls;
  - any `Modules/` folder counted as Laravel;
  - plan and spec drift.
- **Recorded:** `codeOnly` misreads some forms (Rust `'a`, `"#"` in Python, `${}`). These only cost re-parses. PHP `#` comments are not stripped, as before.

## Limitations

- **The text heuristics are not parsers.** A name in a string that also declares it (PHP `define('FOO', …)`) counts as gone on each sync, which costs a re-parse.
- **`usedAsFunction` is per file.** A binding shared as a global between classic scripts, neither exported nor called in its file, stays a value.
