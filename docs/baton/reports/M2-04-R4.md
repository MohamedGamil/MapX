# M2-04-R4 — Same-named axios clients in one file keep their own baseURL scope

Date: 2026-11-02. Base: `develop@917a8cc` (started on 5ed5e0b, rebased). Owner: maintainer. Iteration: `docs/baton/iterations/M2-04-R4.md`.

## Delivered

**`src/frameworks/http/client-calls.ts`:**
- **Bindings with block scope.** Clients created in the file (`const api = axios.create(…)`) and factory aliases (`const api = makeApi()`) record the block their binding is visible in. That block is the innermost `{…}` around the declaration in the masked source, or the whole file at top level, which is the rule `fileBindings` uses for constants. One pass over the braces gives every block (`blockScopes`).
- **Declarations in code only.** Declarations are matched on the masked source, so a client written inside a comment or string is not a client.
- **Unbalanced braces.** If the masked braces do not balance, no binding in that file gets a scope, and the file keeps the M2-04-R3 behaviour. This happens, for example, when JSX text such as `Don't` opens a string the masker never closes.
- **Call ownership.** `extractHttpCalls` groups receivers by pattern once, searches each pattern once, and gives each call to the receiver that owns it:
  - the innermost scoped binding whose block contains the call;
  - otherwise a same-named receiver without a scope (an import or a configured receiver);
  - otherwise the first one, as before.
- `createBaseURL` reuses the file's masked text instead of re-masking the whole file for every client.

Before this change, the first receiver whose pattern matched claimed every call. Its `baseURLAt` then made M2-04-R3's scoped lookup evaluate `BASE` in the first function's scope.

`src/core/scanner.ts` is unchanged. It already evaluates a client's base at the client's `baseURLAt` (M2-04-R3). Once the right client owns the call, that gives the right value.

## Limitations

- A non-client binding that shadows a client's name, such as a parameter `api` beside a top-level `api` client, is still taken as that client, as before.
- A call outside the block of every same-named binding, with no import of that name, falls back to the first client, as before.
- In a file whose masked braces do not balance, same-named clients share the first client again, as on base. In the TSX test, the local `api` in `A()` gives `/imported/a`.
- Clients bound by destructuring or reassigned after creation are not tracked.
- `collectProviders` still matches exported clients on the raw content. An `export const api = axios.create(…)` written in a comment can still register a provider, as on base.
- The timing test has a 5 s wall-clock bound, about 100 times the measured time.
