## Delivered

- **`src/parsers/languages/vue-template.ts`**
  - `templateRange` takes only a top-level `<template>`. Any other top-level block is raw text up to its closing tag, as in the SFC compiler.
  - `templateNodes` keeps a stack of open elements (closing tags pop to their match; void and self-closing tags never open). Every tag and interpolation carries `locals`:
    - `v-for` aliases, also destructured (`run: go`, `done = noop`) and with an index, and `slot-scope` / `<template scope>`: visible to the element's own attributes and its children;
    - `v-slot`, `v-slot:name` and `#name` props: visible to the children only.

    `outerLocals` serves the `v-for` source. A `v-pre` element and its subtree yield no node.
  - `templateReferences` drops a handler or call whose name is in its `locals`. Navigation (`vue-navigation.ts`) reads the same nodes, so `v-pre` hides navigation too, without an edit there.
- **`src/parsers/languages/vue-options.ts`**
  - `collectThisCalls` decides by position whether `this` is the component. It is inside functions held by the options literal through objects, pairs and arrays (members, hooks, `watch` handler objects, computed `get` / `set`, inline mixins) and inside arrow functions within those.
  - Every other non-arrow function rebinds `this`, as does an arrow held directly by the literal (`quick: () => this.save()`). Their calls are listed in the new `OptionsComponent.reboundCalls`.
  - `annotateThisCalls` gives those references `vueThis = { own: false, mixins: [] }`, which no rule-6 step resolves, so they get no edge.
  - Before: a callback `function () {}` was left to the generic name lookup (another file). A nested object's `run: function () {}` or `stop() {}` was taken for a component member (its parent is a `pair`).
- **Fixture** (`tests/fixtures/vue-sfc`): new `vue2/src/components/{ReplyList,ReplyTable,ReplyPreview}.vue`, `vue2/src/api/replies.js`, `vue3/src/components/{OrderTable,DataList}.vue`. `expected.json` gets labels v2-110…v2-116 and v3-110…v3-113 (4 positives, 7 negatives). `README.md` lists the new traps.

## Limitations

- **Template scoping** covers the bindings Vue's template syntax makes (`v-for`, `slot-scope`, `scope`, `v-slot`). It does not model JS scopes inside an expression (`items.map((save) => save())`).
- **Binding patterns** are read by text: defaults are dropped up to the next `,`, `}`, `]` or `)`. A default holding a call (`x = make(y)`) would also bind `y`. That only ever suppresses a call; it never adds one.
- **Unquoted attribute values.** An element whose last attribute value is unquoted and directly followed by `/>` (`<Foo a=b/>`) is taken as left open. Its siblings then inherit its bindings, if it has any.
- **Line keys.** A rebound and a component `this.x()` with the same name on one line both take the component's scope (calls are matched by line and name, as before).

## Independent review and fixes

Reviewer L checked v-for, `#slot` destructuring, v-pre and a `<docs>` block holding `<template>`, and found them correct; base was broken by the custom block. One P1 regression was fixed:
- **Finding.** `debounce(function () { this.x() })` and `function () {}.bind(this)` lost their same-file edges.
- **Fix.** `keepsThis` keeps the component's `this` for `.bind(this)` and for functions passed to lodash-style wrappers (`debounce`, `throttle`, `once`, `memoize`, `before`, `after`, `wrap`).
- **Test.** The real-scan test "never resolves a rebound this.x() by name to another file" gains both cases. The mutation fails it.
- **Verification.** The fix is verified by the next round (reviewer M).

Review of the previous round's fix (reviewer M), P2 fixed:
- **Finding.** The wrapper list matched names only: `socket.once(…, function () { this.join() })` was linked to the component. Vue 2's `this.$on(…, function () {})`, which binds the component, had lost its edge.
- **Fix.** Wrappers are narrowed to `debounce`, `throttle` and `memoize`, called bare or on `_`, `lodash` or `underscore`. Vue's `this.$on`, `$once`, `$nextTick` and `$watch` callbacks keep the component's `this`.
- **Test.** The real-scan test gains both cases. Mutations "once preserves this" and "no $on" each fail.
