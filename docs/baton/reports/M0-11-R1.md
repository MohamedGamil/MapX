# M0-11-R1 — Impact, callees, staleness and globals defects

Date: 2026-10-31. P1 from the M0-41 legacy audit (I11, I18, I21). The impact change follows owner decision D010.

## Fixed

- **Impact risk (`impact-analyzer.ts`):** the try/catch downgrade is removed (D010). Risk depends on depth and test files only, as F19 specifies. Before, a direct caller was HIGH → LOW if its body contained `try`, even in a comment. `checkTryCatch` stays exported for compatibility but is unused.
- **Import-only dependants:** files that import the symbol's file without calling it appear as `LOW` (`symbol: <import>`).
- **Callees location (CLI and MCP):** the line is the callee's own declaration (`store.getSymbolLineInFile`), not the call site. Before: `helper @ core.ts:3` for a helper declared at line 9.
- **Staleness (new shared `src/core/staleness.ts`, used by CLI and MCP):**
  - a newer mtime is stale only if the content hash differs (an identical rewrite is no longer a permanent false positive);
  - deleted files count;
  - new untracked source files (via `git ls-files --others --exclude-standard`, filtered by language and configured excludes) are reported as `(new)`.

  CLI `checkAndPrintStaleness` and MCP `getStaleFilesCount`/`getStaleFileNames` delegate to it, which removes duplicated logic.
- **`mapx sync` indexes untracked files:** `git-tracker.getChangedFiles` adds untracked, non-ignored files as `added`. Before, new files were never indexed until committed.
- **Globals blacklist:** applied to `.mjs/.cjs/.mts/.cts/.jsx/.tsx/.svelte` (was `js|ts|jsx|tsx|vue`). `new Date()` in `.mjs` no longer links to a user `Date` class.

## Tests updated for intended behaviour changes

- `tests/impact-analyzer.test.ts`: `caller1` (inside a try) is now HIGH and the recommendation is BREAKING, per D010.
- `tests/cli-coverage.test.ts`, `tests/mcp-coverage.test.ts`: the staleness tests used the MapX repo itself (`'.'`) as the workspace, so the repo's own untracked files changed their counts. They now use temporary non-git directories.
- `tests/cli.test.ts`, `tests/mcp.test.ts`: mock stores gained `getSymbolLineInFile`.
- `tests/git-tracker.test.ts`: unchanged. The untracked listing runs after the staged lookup, preserving the mocked call order.
