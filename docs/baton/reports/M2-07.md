# M2-07 — HTTP pairing follow-ups from the M2 review

Date: 2026-10-30. Covers the P2 findings of the independent M2 review (D009 scope).

## Fixed

| Finding | Fix |
| --- | --- |
| Nested ternary in the consequent mis-split | `urlBranches` tracks nested `?` in the consequent until their `:` |
| Nested templates, `('/api/' + id)` and `const A='/a', B='/b'` unresolved | `evaluate` takes template bodies by position (nested backticks), evaluates parenthesised sub-expressions, and `fileConstants` continues a `const` statement through further declarators (default parameters are not constants). **A latent bug was also found and fixed here:** `splitPlus` shared one depth counter between brackets and template interpolation, so a string inside parentheses never closed and `('/api/' + (id)) + '/x'` evaluated to `{}` |
| Provider shapes missed | `export async function f() { return axios.create() }`, block-bodied arrow factories, `export { default as http } from './http'` re-exports, and `import * as ax from 'axios'` |
| Ties depended on `routes.json` order | A full match beats a suffix match; otherwise the lexicographically smallest (handler file, path) wins |
| `http` graph edges collapsed per file pair | The graph key for `http` edges includes the handler symbol (other edge types unchanged) |
| Quadratic line lookup on huge bundles; bundles scanned | `lineIndex` uses binary search over newline offsets. Files under `public/`, `dist/`, `build/`, `vendor/`, `node_modules/` and `*.min.js` / `*.bundle.js` are skipped (`HTTP_SKIP`) |
| `.env` or `settings.http`-only edits did not refresh records | The incremental (git) and hash-sync paths compare a fingerprint of `settings.http` plus every `.env*` file (path and mtime) with `meta http_inputs:<repo>`, and re-run extraction and pairing when it changed |

## Post-acceptance defect (2026-10-31)

The large-bundle test asserted "6,000 calls in under 1 s" as wall-clock time. In the full suite, with files running in parallel, it measured 1.12 s and failed, although the extraction itself was unchanged. The test now checks **scaling**: 10× the input must take less than 30× the time (a quadratic line lookup takes about 100×), with a generous 5 s ceiling. Found while verifying M0-12-R2.
