# M0-15-R1 — Stop shipping the dashboard source map

Date: 2026-10-30. Decision: D005.

## Delivered

- `scripts/build-ui.ts`: esbuild `sourcemap` is now `MAPX_UI_SOURCEMAP === '1'`, and a stale `main.js.map` is removed on every build.
- `package.json` `files`: added `!dist/**/*.map` as a second guard.
- `scripts/check-package.ts`: runs `npm pack --dry-run --json`, exits 1 if any `.map` file would be packed, and reports the `dist/ui/main.js` gzip size (with an optional `--max-ui-gzip` threshold for M0-15-R2).

## Evidence

| Command | Exit | Result |
| --- | ---: | --- |
| `npm run build:npm` | 0 | `dist/ui` contains index.html, main.js and styles.css (no map) |
| `npx tsx scripts/check-package.ts` | 0 | 234 files, 4,285,806 bytes packed, 39,690,658 unpacked; main.js 690,760 bytes gzipped |
| Opt-in: `MAPX_UI_SOURCEMAP=1 npx tsx scripts/build-ui.ts`, then the check | 0 | the map is written to dist/ui but excluded from the pack |
| Mutation: remove `!dist/**/*.map` from `files` with the opt-in map present, then the check | 1 | `FAIL source map packed: dist/ui/main.js.map` (exclusion restored afterwards) |

Before the change: 6.1 MB packed and 47.5 MB unpacked, 235 files including the 7.8 MB `dist/ui/main.js.map`.

## Limitations

The dashboard bundle is still 690 KB gzipped; the target is M0-15-R2, which is blocked on an owner decision. tsup emits no `.js.map` for `src/` (sourcemap is off in `tsup.config.ts`), so the guard only had the UI map to catch.
