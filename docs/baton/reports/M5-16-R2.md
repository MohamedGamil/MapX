## Delivered

`src/arch/smells.ts` (both marked `source: "rules"`, severity `info`; definitions in `docs/architecture-rules.md#smells`):

- **`orphan-element`:** a file in the scope's paths, in no non-overlay layer, that declares a top-level symbol and that no other file depends on by any stored edge. One per file.
  - Not orphans: role `entry`, `test`, `config`, `scripts`, `docs`, `styles` or `assets`; a conventional configuration name (`karma.conf.js`); a file that declares nothing; a Go file with `func main`.
  - A Go package is judged as a whole, because an import edge names one arbitrary file of the package.
  - The unit is the file, not the symbol: a symbol's callers are not always resolved, so symbol-level orphans would be noise.
- **`baseline-debt`:** per source layer, the number of violations the baseline skips, by rule (`Baseline debt: layer Repository has 2 baselined violations (disallowed-layer: 2)`). A source in several layers counts for each.
  - **By age: not done.** A baseline entry records no date (`BaselineEntry` has fingerprint, rule, ends, edge type and repos), and the task says "by age if the baseline records it". Ageing needs a date in the format; that touches `baseline.ts` and `check.ts` (lane J), so it is a follow-up.
- **Fixture overlay** `tests/fixtures/arch-smells/extra` (synthetic), laid over `arch-smells/ts` in the test.
- **Docs:** `docs/architecture-rules.md` (Smells), `docs/cli-reference.md`.

## Limitations

- No age for the debt (above).
- An orphan is a file, and any edge from another file counts, a test's included.
- Roles are heuristics (`main.go` is `api` in one workspace and `entry` in another), hence the Go `func main` rule.

Changelog: `mapx arch --smells` and `mapx_smells` report `orphan-element` (code in no layer that nothing depends on) and `baseline-debt` (violations the baseline skips, by layer) when `.mapx/architecture.jsonc` exists (M5-16-R2).
