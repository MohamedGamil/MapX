# M0-07-R3 — The MCP server reports the package version

Date: 2026-11-01. Base: `develop@8914c5b` (tag `v0.3.7`). Owner: claude. Found while verifying the 0.3.7 binary install (D023).

## Defects

1. **MCP version.** `mapx serve` answered `initialize` with `serverInfo: { name: "mapx", version: "0.1.3" }`, a value hard-coded in `src/mcp.ts` (`buildServer`). Every MCP client saw 0.1.3, whatever the installed version. `mapx --version` was right (0.3.7).
2. **Installer hint.** The self-extracting installer ended with `Uninstall: /tmp/tmp.XXXX/mapx-0.3.7/install.sh --uninstall`, the path of its temporary copy, which is deleted on exit.

## Delivered

- **`src/mcp.ts`.** `buildServer` reports `VERSION` from `src/version.ts`: the `VERSION` file, or `MAPX_BUILD_VERSION` in a compiled binary, as the CLI does.
- **Installer.** `scripts/make-installer.sh` exports `MAPX_INSTALLER`, the installer's absolute path, before handing over to `install.sh`. `scripts/templates/install.sh` prints `Uninstall: ${MAPX_INSTALLER:-$0} --uninstall`.
