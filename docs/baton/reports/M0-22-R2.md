# M0-22-R2 — CLI mapx search: full file listing and truncation totals

Date: 2026-10-30. This is the CLI side of the F38 fixes. M0-22-R1 fixed MCP and listed the CLI as unchecked; the defect was confirmed on 2026-10-30.

## Fixed (`src/cli.ts`, `search`)

- `--limit` no longer defaults to `'20'` in commander. Without it, a wildcard term (`*` or empty) with `--file` returns every match; any other search uses 20.
- The header says `Found N of M symbols` whenever results are fewer than matches (via `store.countSymbolsFiltered`).
- `--format json` includes `totalMatches`.
- `tests/cli.test.ts`: the mocked store gained `countSymbolsFiltered`, derived from the unlimited search.
